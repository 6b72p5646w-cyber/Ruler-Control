# SA01：旧辅助部署进入七夜模式

本页与[迁移合同](../content/legacy_deployment_bridge_sa01.json)解决旧B01–B08、I16及Q08灯点与TD05布防规则之间的交界。九种能力继续保留设计资格；实际挂法、物理占格和世界处理器仍需适配，运行准入保持关闭。

七夜模式统一读取本合同的阶段、容量和资产寿命，再读取原辅助效果。旧V0.10练习继续原基线，不能把同一物件同时按两套规则加载。

## 营业前准备，营业中使用

购买、安装、移动、回收、升级、补弹、补电、替换都只在班前进行。营业中的短暂安全、远离怪物、暂停或背包里还有备用，均不能重新开放这些操作。某项操作还必须原本就有消费者；阶段合法不代表B08突然能够修复，或无定价的套件能免费补次数。

营业中可以启动已经准备好的有限能力、开关既有灯、让已装装置自动触发。准备硬件和实际启动分开：例如先把遮挡屏安装好，到需要时才用0.3世界秒展开，首次展开才开始20/15秒寿命。不能用收起再展开刷新截止。

免费主机制仍按原合同操作：玩家可以亲取回形针并手撒、拿放任务物、封柜、拾石投石。限制旧付费投放盒的装弹，不限制F12原本的手撒解法。

## 与R系共用容量

- **R系陷阱＋旧辅助安装点，总计最多8件。**
- **旧辅助内部仍最多3个安装点。** B01–B08、I16与Q08灯点共用这个子上限；Q08两处真实灯点各占一个。
- 每种旧B套件及I16最多安装一件，单件Q08的两个原灯点是明确例外。
- 实际地面物理占格合计最多16格，路障仍最多6格；挂墙、挂台的实物经验证后可记0新增地板格，但仍占部署名额。
- 未部署库存不占安装名额；已耗空、损坏但仍留在场上的硬件，在下次班前回收前继续占名额。

所以3件旧辅助＋5件R陷阱可以达到8件总上限；8件R陷阱之外不能再放3件旧辅助。塔的8座上限独立计算。

原地图给出的SO坐标只证明有操作锚点，没有完整声明每个套件的实际安装占格。本轮没有给它们猜测一格外壳。地面安装必须有明确物理格；墙／台挂必须有真实挂法。没有这份地图适配证明，就继续拒绝运行安装，而不是用效果半径冒充物理占格。

## 七夜保留与短时效果并存

硬件实例、位置、等级、余次、余电、已装弹药七夜保留，第七夜结算后周清。硬件一直存在，并不意味着它的20秒、30秒效果一直存在。

未启动的单次能力可以保留到下一夜。已经启动的B02/B07/I16保存原绝对截止与已用预算；自然到期或提前交班都不会在次夜重新给一份寿命。B06已经套到原箱的修正按原截止、实际拆套、目标终态或交班结束，下一夜不会重新有一个免费套件。B03夜结关灯，保留真实余电。

I16需要区分两种资产状态：

1. **未使用、未安装的个人I16**：仍是个人库存，按EQ01跨周保留。
2. **已经班前安装的I16**：原个人物消费一次，产生当周安装实例；回收后仍是这个周内硬件，不能还原为新的个人I16。第七夜随布防资产清除。

Q08装备本体继续是个人装备，周清只移除它本周的安装点与位置。保留原电量，不因拆点或换周自动充满。

## B08与MA01攻击的准确接合

F12、F13已由普通无预告接触改为有前摇的基础攻击，因此B08监听明确的 `F12:BASIC` 与 `F13:BASIC`，不再依赖旧事件名称猜测攻击种类。

只有攻击已经提交、没有被诅咒取消、真实几何已碰到保护圈内玩家、该攻击尚未结伤、玩家没有现存受击宽限、垫仍有次数，而且这次确实会产生正伤害，才消耗一次拦截。成功后取消该次SAN和同次轻伤，垫损坏，并给原来的2/3秒全怪命中框宽限；期限取最大，不相加。

碰撞事实仍然成立，所以不会触发I39“真正躲过整次攻击”。拦截不新增流血，不取消追逐，不代做主机制。受击保护已经挡住的攻击、咒失手、其他怪物近战和普通身体接触，都不会浪费B08次数或扩大它的保护范围。

## 有限验证边界

运行 `python3 scripts/check_sa01_legacy_bridge.py` 可复现阶段拒绝、容量交集、未证明几何拒绝、I16唯一资产归属、有限寿命跨夜、B05真实弹药和B08新命中消费者的正反例。[机器报告](sa01_legacy_validation_report.json)记录输入哈希。

参考模型接收已经验证的几何，不负责证明实际占格、路线和墙台挂法；也没有实现全部九种世界效果、完整怪物AI、供电联动或手机操作。
