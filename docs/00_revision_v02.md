# V0.2 修订依据

日期：2026-11-17。当前权威入口为仓库 README 与 V0.2 内容数据。

## 用户明确修正

1. 可以参考泰国剧《致命规则》。本轮从官方资料找到题材相符的 Viu《The Rules / กฎหลังเที่ยงคืน》，作品中文译名对应关系仍以用户后续提供的具体链接为准。
2. 随机事件需要明显扩充。
3. 一周为周期，每天阶段一致；变化由随机事件与怪物带来。
4. 不采纳上一版怪物；从全球志怪原型重新设计便利店交互。
5. 主角必须有精力、SAN、饱腹、体力管理。
6. 加入临时道具抽奖、装备系统，以及白天学习、休息、购买道具装备宠物。
7. 员工两人包含主角，另有店长；同事和店长可能被假扮。
8. 同步到用户指定的 Ruler-Control 仓库。

## 被替代的内容

- V0.1 的 M01—M60 不进入当前怪物库，不保留同名条目，也不通过简单换名沿用。
- V0.1 的第一夜只收银、第二夜主打补货等不同每日课程表取消。七夜所有工作阶段一致。
- V0.1 的 12 类事件替换为 72 项事件候选。
- 单一侵入值不再承担主角生存系统；四资源成为玩家准备与行动的主要约束。店铺失守以可见异常状态和目标判断表示。
- 新增 F 系列表示基于民俗的新候选；旧 M 编号不得重用，避免后续程序把旧合同误当新规格。

## 保留但重新适配的基础

2D 便利店、00:00—06:00 夜班、通常每小时一主遭遇、20 条渐进店规、条件联动、读档与手机暂停仍然适用。20 条店规在 V0.2 按新系统重写，首次教学与解锁改为里程碑触发，不等于七天必须有不同阶段。

## 事实与提案边界

民俗事实只由 `sources.json` 中对应条目支持。便利店行为、数值、弱点测试、反制步骤、角色资源效果均属于本作原创设计。某一地方传统的变体不能被表述成该原型在全球都一致的设定。外部内容只做短摘要与链接，不复制剧集台词、完整规则清单或现代视觉设计。

本轮新增的平衡、抽奖、装备、宠物和具体事件均为候选，需要通过原型进一步筛选。没有把本轮助手提案表述成用户已逐项接受。
