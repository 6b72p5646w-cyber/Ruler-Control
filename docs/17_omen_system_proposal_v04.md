# Ruler-Control 怪物预告线索与交互规则优化

2026-11-17 · 基于 V0.4（main 分支提交 a3429a6）

> 本文是设计提案，不改动 `content/` 数据和代码；文中“审查 D1”“J4”“R4”等编号指[怪物规则与地图适配审查](16_review_rules_maps_v04.md)。

## 结论与关键决定

结论：把每只怪的到来拆成“远兆、近兆、临门”三段，在它进店前约60秒，用源自原型的线索在店里铺开；玩家用交接本排除候选怪，再花电量、精力和店务时间押一两项准备；进场后只需守住一句反本能禁令、做对一个关键动作。认对了准备就对，认错了不致命，但发作会提前。

本文基于仓库 main 分支提交 a3429a6（V0.4）和上一份审查。全部是设计提案，数值待实机调参。标注“本作原创”的是游戏改编，不是民俗原文。

**七条关键决定**

1. **预告跨小时：** 下一只怪的远兆在本小时最后60秒出现，玩家要边做本小时店务边准备下一只（FNAF 的“同时顾两头”）。
2. **三条预兆，按夜收紧：** 每只怪3条预兆，至少1条是实物证据。第1–2夜全给；第3–4夜混入1条环境假兆；第5夜起只给2条（恐鬼症提高难度时少给一项证据的做法）。
3. **线索分三档可信度：** 实物（永远为真）、感官（为真，但多只怪共用）、人言（可能是假的）。冒名类怪只能伪造人言和感官，伪造不了实物和监控快照，所以快照就是“测谎器”，代价是电量。
4. **一怪一禁令：** 手册每只怪只写一句“不要做什么”，禁的是玩家本能（应声、回头、拽回、丢下、跑、看）。完整流程降为白天可研究的图鉴，进场时只剩一个关键动作。
5. **个性化发作条件：** 借恐鬼症的“狩猎阈值”，每只怪绑定一个来自原型的发作条件（站湿地、喘气、流血、看脸等）和一个 SAN 阈值。只有违禁或 SAN 低于阈值才发作，发作前全店统一3秒灯闪。
6. **准备是有代价的押注：** 四类通用准备（布置、断开、备物、站位）共用每夜12格电量；同组相似怪的最佳准备互相冲突，猜错要付出时间和电量。
7. **数据化落地：** 预兆、禁令、发作条件和准备全部写成约30个条件词组成的 JSON，由一个7状态的通用状态机运行；先做8只怪的可玩切片。

## 一、从《恐鬼症》借什么、不借什么

取它的“先认怪、再对策”推理骨架，不取它的黑暗探索和多人分工。《恐鬼症》的核心是：少数几种证据类型、每种鬼固定三项，玩家用日志排除；鬼有各自的习性和狩猎条件；理智值越低越容易被狩猎。以下机制按该作公开的通用玩法概括，具体数值随版本变化，本文没有引用。

| 《恐鬼症》机制 | 本作怎么用 | 取舍理由 |
|---|---|---|
| 几种证据类型，每鬼固定三项，日志勾选排除 | **采用。** 12种预兆标签、每怪3项；店员「交接本」勾选后自动变灰不符的已知怪 | 把60份说明书变成一个推理界面；完全可数据化 |
| 相似鬼共享两项证据，靠第三项或习性区分 | **采用。** 按族群分组（水系拖拽、水系音律、熟人诱离、冒名同事、追逐、声音反向、契约），组内只差一条 | 认错要有代价，推理才有意义 |
| 专用工具对应证据（温度计、紫外灯、盐、相机） | **采用，用现有道具。** 监控快照=相机，I17示踪粉=擒盐看脚印，Q07偏振检视灯=紫外，Q03铜铃=听声，冷链温度条=温度计 | 仓库已有这些物件，不加新系统 |
| 理智低于阈值才狩猎，不同鬼阈值不同 | **采用。** 每怪一个发作 SAN 阈值（默认50，激进型60，害羞型35），另加一个原型发作条件 | 给现有 SAN 一个真正的用处，而不只是扣分 |
| 个性化习性（怕光、只盯一人、黑暗里更凶） | **采用。** 每怪的发作条件和禁令都从原型来，例如报丧女妖只点名一名员工、僵尸追呼吸 | 原型差异正是本作资产 |
| 狩猎前灯闪、门锁死 | **改写。** 发作前统一3秒当前回路灯闪加提示音；不锁门 | 仓库已定“追逐时门不可锁”，保留逃生路线 |
| 躲藏点 | **改写。** 用“安全格”：柜台内侧（加活板门）、员工室、干区 | 俯视下无法做柜子里的第一人称视角 |
| 高难度少给一项证据 | **采用。** 第5夜起只给2条预兆 | 和上次建议的 R8 逐夜升级合并 |
| 祸福道具只拖延不解决（熏香、十字架） | **采用。** I21应急护身符、I22定界盐包延后一次发作20秒，不解除怪物 | 给失误留一个可买的保险 |
| 鬼魂事件扣理智 | **采用。** 预兆本身轻度扣 SAN（−1），受仓库已有的单怪每阶段上限15约束 | 拖得越久越危险 |
| 大地图黑暗里用手电找鬼 | **不采用。** 只做单个回路变暗 | 30像素一格俯视下全黑不可读 |
| 多人分工、语音触发 | **不采用。** | 单人微信小游戏，没有麦克风场景 |
| 认出鬼就能撤离 | **不采用。** 认对只换奖励和准备优势，店务仍要完成 | 本作的核心是边营业边应对 |
| 狩猎即死亡 | **不采用。** 沿用违规阶梯（警告→重罚→放出追逐或结束当夜） | 保持仓库的公平契约 |

## 二、通用预告线索系统

每只主遭遇都走同一条时间线：进店前60秒开始预兆，前15秒关闭大部分准备。一小时仍是120秒；怪在本小时第20秒到场，所以前40秒的预兆落在上一小时的末尾。

### 2.1 一只怪的时间线

| 时刻（T0=到场） | 段 | 玩家看到什么 | 玩家能做什么 |
|---|---|---|---|
| T−60 至 T−40（上一小时第80–100秒） | 远兆 | 1条世界尺度的感官线索：告诉你“族群”和“在哪一区” | 继续本小时店务；可花1格电拍该区快照 |
| T−40 至 T−15 | 近兆 | 其余2条线索，至少1条实物；初见的怪此时解锁它的禁令页 | 在交接本勾选、排除；做1–2项准备 |
| T−15 至 T0 | 临门 | 入场锚点出现统一的“来客”提示；T−5 部署槽锁定 | 只能做15秒内走得到的准备；走到安全格 |
| T0 至 T+70 | 对峙 | 怪在场，禁令生效；认对时 HUD 显示禁令卡 | 做关键动作，或按仓库已有的保守退出收场 |
| T+70 至 T+100 | 善后 | 结算；第80秒起下一只的远兆已经开始 | 补店务，同时读下一只的预兆 |

开班00:00的怪，远兆和近兆放在22:00–24:00验岗：店长的天气预告、同事闲聊、交接本上的留言。这也给“店长说的话可能是假的”留了位置。

### 2.2 十二种预兆标签

每只怪从下表里取3种，组合唯一。标签是类型，每只怪的表现形式各不相同（同是“湿痕”，河童是拖痕，凯尔皮是蹄印）。

| 标签 | 可信度 | 读取尺度 | 主要承载位 | 核验工具 |
|---|---|---|---|---|
| 声·叫名 | 感官 | 屏幕边缘图标+方向 | 前门、后门、电话 | 快照录音、Q03铜铃 |
| 声·乐曲哨声 | 感官 | 屏幕边缘图标+远近档 | 前门、水槽、后门 | 快照录音 |
| 声·哭号 | 感官 | 屏幕边缘图标 | 员工区、门外 | 快照录音 |
| 声·敲击拖曳 | 感官 | 屏幕边缘图标 | 库房、后门 | 快照录音 |
| 光·回路灯闪 | 感官 | 整区变色 | C1/C2/C3 三个回路 | 配电板记录 |
| 温·升降温 | 感官（HUD 读数永远为真） | 小地图分区温度条 | 冷链、前场、垃圾区 | 温度条 |

| 影·监控异常 | 实物（拍下后） | 监控侧栏 | 5个摄像区 | 快照（1格电） |

| 言·人言便签电话 | 人言 | 对话气泡，带“未核实”角标 | 收银台、交接本、电话 | 排班表、快照时间戳 |

### 2.3 可信度与假线索

- **实物永远为真。** 水迹、足印、称重、快照只会由真实实体或已预告的环境事件产生。这是公平底线，和仓库“时间戳不会回改”一致。
- **感官为真但不唯一。** 同一种哭声可能来自报丧女妖、哭泣女或蓬蒂雅娜，只能缩小范围。
- **人言可能是假的。** 冒名类怪会在交接本写假便签、凒店长打电话；顾客的传言却不会是怪写的，但可能记错。用排班表和快照时间戳核验。
- **环境假兆（第3夜起）：** 导演每小时可加1条由天气或常规事件产生的实物痕迹（例：E010暴雨让门垫变湿）。它是真的，只是不属于怪；验岗时已经预告过天气，听了预告的玩家可以排除。
- **低 SAN 幻兆（需要你拍板）：** SAN<40 时，每小时最多出现1条声音或灯闪幻兆。幻兆永远不会出现在快照、温度条和任何实物上，所以总能核验。它不改写输入、不遮 HUD，符合仓库现有的 SAN 规则，但属于新增设定。

### 2.4 准备动作与代价

准备只有四种动词，全部复用现有模块。每夜共12格电量；电用光时前场照明降一档，部分怪在暗处更活跃。

| 动词 | 例子 | 时间 | 电量 | 精力 | 复用模块 |
|---|---|---|---|---| --- |
| 布置 | 门垫撒示踪粉、铺吸水隔离垫、放定界盐、拉遮挡帘 | 3–6秒+路程 | 0 | 1–2 | MC10 |
| 断开 | 关店内水阀、关广播、断一个照明回路、预锁后门 | 1–3秒+路程 | 锁门2，其余0 | 0–1 | MC03、MC12 |
| 备物 | 肉箱先入冰柜、回形针盒放到门线、交接本副本放柜台 | 搬运时间 | 冷柜强冷1 | 2–4 | MC04 |
| 站位与排班 | 调同事换岗、自己在T0站到安全格、开侧灯 | 路程 | 侧灯每小时1 | 0 | MC09、MC12 |

常规核验也扣电：快照1格。一夜大约够做6–8次有用的准备，不够每只都双保险。

**冲突设计：** 同组相似怪的最佳准备互相拆台。例：关店内水阀能卡死河童的拖拽，却让诺肯的“逐个试水点找源”无法进行，只能再跑回去开阀；开侧灯能让画皮鬼现双层轮廓，却会把雪女引到有光的前台。猜错不会立即失败，只是白花时间和电。

### 2.5 发作、SAN 阈值与违规阶梯

- **发作条件 =** 触犯禁令，或者（SAN 低于本怪阈值 且 原型条件成立）。例：僵尸的原型条件是“玩家喘气”，即体力低于30%在动。
- **发作前3秒：** 玩家所在回路灯闪加统一音效，黑视不能吞掉这个提示。这是全店唯一的通用“危险”信号。
- **违规阶梯（按夜计）：** 第1次触犯任何怪的禁令=警告（SAN−3，怪推进一步）；第2次=该怪发作（追逐、拖拽、占岗等，SAN−8）；第3次=安全撤班，保留知识，不领当夜工资。替换各卡一次性扣 SAN 的写法。
- **拖延道具：** I21、I22 可在发作前3秒内使用，把发作推迟20秒，不解除怪，每夜各限一次。
- **认对奖励：** 在交接本写对怪名=交班时加工资和图鉴碎片，写错不罚；写对后 HUD 显示该怪禁令卡和关键动作提示。

### 2.6 俯视30像素一格的可读性规则

1. 远兆只用世界尺度：整区灯色、温度条、屏幕边缘声音图标。声音一律配字幕和方向箭头，静音玩家也能读。
2. 近兆只出现在固定“预兆位”，变化至少占整格；玩家走到4格内时发亮描边。
3. 细节线索（颈缝、呼吸孔、脚尖方向、镜中脸）只在特写里读，每只怪最多1条，并且必须有免费工具可看。
4. 人言气泡带说话人头像和来源标（当面/电话/便签），右上角永远有“未核实”角标，核验通过后才变绿。
5. 交接本是屏幕侧栏抽屉，打开时世界不冻结（上次建议 R4），所以推理本身也占时间。

## 三、逐怪设计：16只代表怪

先完整做16只，覆盖七个族群；每组至少两只，这样“相似怪靠一条线索区分”在切片里就能测。★ 标的是区分线索。对峙规则尽量沿用现有卡的关键动作，只在不好玩的地方改，改动处单独写明。

| 族群 | 本节成员 | 组内共享 | 靠什么区分 |
|---|---|---|---|
| 水系拖拽 | F05 河童、F24 凯尔皮 | 湿痕 | 拖痕还是成对蹄印；有没有“同事”催你 |
| 水系音律 | F34 鲁萨尔卡、F28 诺肯 | 乐声+湿痕 | 声源在门外还是店内水点；水边有没有多出的旧物 |
| 熟人诱离 | F37 古尔、F43 图恩达、F60 马面 | 冒充熟人、把你引开 | 门外声音 / 店内便签+木足印 / 镜中马脸 |
| 冒名同事 | F02 画皮鬼、F01 狐精 | 冒充员工或送货人 | 员工柜与颜料水 / 称重对不上 |
| 追逐 | F12 不可杀伊、F13 飞头女鬼、F03 僵尸、F32 夜返吸血鬼 | 会追人 | 金属少了 / 生肉升温 / 并脚印+降温 / 有人流血 |
| 声音预警 | F42 哨声亡灵、F21 报丧女妖 | 只听得见 | 压力牌 / 值班板点名 |
| 契约 | F06 雪女 | 有条件的交易 | 前场骤冷+广播杂音 |

### F05 河童（水系拖拽）

- **原型：** 栖于河流池塘，把人或马拖入水中。
- **预兆：** 远兆，后院方向的拖曳声（感官）；近兆，后院沟到库房一条连续拖痕（实物，OS08）；★近兆，一只购物篮或推车被挪到湿区边缘（实物）。
- **禁令：** 东西被拖走时，不要伸手去拽。本能是抢回来，一拽就变拉锯，把你带进湿格。
- **发作：** 玩家站在与水源连通的湿格上并碰到被拖物；SAN 阈值50。
- **最佳准备：** 关店内水阀（3秒+路程，0电），或在拖痕上铺 B07 切断一格。只拖地不断水是错误准备，拖痕10秒后重新出现。
- **对峙：** 水路断开后被拖物停住，从干侧取回。保守退出：放弃篮中商品。
- **区分：** 凯尔皮留的是成对蹄印，并伴随“同事”催你去侧巷；邦耶普在货架区低吼，没有拖痕。

### F24 凯尔皮水马（水系拖拽，兼冒名）

- **原型：** 能化人形，湿发、水草或马蹄露出身份，把靠近的人诱入水中。
- **预兆：** “同事”在交接本上留言叫你去侧巷装车（人言，OS04）；★后门到侧巷的成对蹄印，擦干了又出现（实物，OS07）；库房快照里“同事”的头发一直滴水（实物，CAM4）。
- **禁令：** 滴着水的人叫你，不要跟着走。
- **发作：** 玩家和它站在同一片连通湿区；阈值50。发作沿用现有“粘住手推车”。
- **最佳准备：** 提前擦干门内交接格并把货箱放上去。关水阀是错误准备：水是它自己带来的，关了没用。
- **对峙：** 货留干台，退一步，挂“仅台面交接”并撤员工区权限（与现卡相同）。
- **区分：** 图恩达也冒名同事诱离，但脚印是干的，且一只是圆形木足印；河童没有人来搭话。

### F34 鲁萨尔卡水灵（水系音律）

- **原型：** 水域女性灵体，用歌舞诱人；部分地区有用苦艾或护身布料防备的传统。
- **预兆：** 门外有节拍的人声歌唱（感官，OS12）；★前门门槛湿格随节拍一涨一退（实物，OS02）；顾客说门口有赤脚女孩在跳舞（人言）。
- **禁令：** 歌声停的那一拍，不要迈步。
- **规则改动：** 现卡是“休拍干活、强拍前站回干格”。改为：唱三小节、停一拍，湿边在停拍时扩一格，所以唱歌时反而安全。理由：静音像是解除信号，反过来才是反本能。
- **发作：** 停拍时玩家在移动且距湿边2格内；阈值50。
- **最佳准备：** 在门槛放“苦艾香包”（本作原创，借防备母题，占 I21 的道具位），第一次停拍不扩边；或在门内铺 B07。
- **对峙：** 跟着歌声擦地、移货，停拍站定；擦断湿边即完成。
- **区分：** 诺肯是器乐，来自店内水点，多处同时湿；伊阿拉的歌来自冷柜水槽，伴随奖励券变多。

### F28 诺肯水乐灵（水系音律）

- **原型：** 会变成人、动物或物件引人入水；若干故事中可叫破其名字；与乐声有关。
- **预兆：** 店内某个水点传出琴声（感官，OS06）；水槽、排水沟、冷柜冷凝三处同时出水，只有一处是真源（实物）；★水边多出一件不属于店的旧物，如湿琴盒（实物）。
- **禁令：** 站在湿地上时，不要把一段曲子听完。每段约6秒，曲终时人在湿格上=被引一步。
- **发作：** 曲终时玩家在任一湿格上；阈值45。
- **最佳准备：** 拍一张冷链快照（1电），录音标出真源；或带 Q03 铜铃。关总水阀是错误准备：三处都停，找不到真源，必须回去开阀（和河童的最佳准备冲突）。
- **对峙：** 从干侧逐点关支路，盖住真源。新增“叫名”奖励：对峙前已在交接本写对“诺肯”，它立即结束一段引诱，把原型里“叫名破法”变成推理回报。
- **区分：** 见鲁萨尔卡。

### F37 古尔荒野妖（熟人诱离）

- **原型：** 伪装熟人，夜间叫出住户名字，再逐步后退把回应者诱离家屋。
- **预兆：** 门外有人叫你的名字，声音像店长（感官，OS12）；电话里“店长”让你出门拿东西（人言，OS03）；★门外快照里的脚印全部朝后退方向（实物，CAM5）。
- **禁令：** 门外有人叫你名字，不要应，也不要朝声音走一步。“应”=点对话气泡回话。和泰剧《午夜规则》第2条同类，开局教学最合适。
- **发作：** 玩家越过前门安全线或回应；阈值55（主动型）。发作=它在门槛显出真形，SAN−8，本小时前门交接工作作废。
- **最佳准备：** 把交接本副本放柜台，可以随时查真店长的位置；在门内交接格先放好物品和回执。预锁前门是错误准备：它本来就不进门，白花2格电，还挡住正常客单。
- **对峙：** 把“店长”的催促落实成门内固定格上的物品和回执，不出门（与现卡相同）。
- **区分：** 图恩达在店内用便签引你去后院；马面在店内以背影出现。只有古尔始终在门外、只靠声音。

### F43 图恩达（熟人诱离）

- **原型：** 可以化作亲近的人，引导受害者远离熟悉地点；所选版本一个木足不能随外貌改变。
- **预兆：** 交接本出现署名同事的手写便签“去后院拿一下……”（人言，OS04）；顾客说看见你同事在后院（人言）；★交接垫上一只鞋印、一只圆形木足印，撒示踪粉才看得见（实物，OS01）。两条人言一条实物，故意用来教“人言不可全信”。
- **禁令：** 便签让你一个人去后院，不要去。
- **发作：** 玩家独自从前场进入后院；阈值50。发作=SAN−8，真同事被引走，其岗位空20秒。
- **最佳准备：** T−40 内在交接垫撒 I17 示踪粉（4秒）。开侧灯是错误准备：那是画皮鬼的对策。
- **对峙：** 让“同事”在公共交接垫留脚印，再用排班表交叉核验（与现卡相同）。
- **区分：** 凯尔皮的脚印是湿蹄印；画皮鬼靠员工柜和颜料水。

### F60 马面引路者（熟人诱离）

- **原型：** 先呈现迷人的女性外貌，后显露马头或马颅；引人走向峡谷等危险地点。
- **预兆：** 前场快照里一个“同事”背影停在凸面镜下，排班表上该同事此刻在库房（实物，CAM1）；硬地上响起蹄声，但店里没人走动（感官）；★凸面镜某一档里背影的脸是马形（实物，特写，OS05）。
- **禁令：** 背对你的人转身时，不要看她的脸。复用 RC01 朝向判定。
- **发作：** 转身时玩家在它视锥内且朝向它；阈值45。
- **最佳准备：** 提前在 (19.5, 23.5) 拉上遮挡帘，或 T0 前站进柜台活板门内。跟着“同事”去对质是错误准备：它会把你引向后院垃圾区。
- **对峙：** 在安全站位拨凸镜看真脸，8秒转身预告内拉帘遮断（与现卡相同，只是帘轨要先补上）。
- **区分：** 古尔在门外、靠声音；双重身是正面同脸的两个人。

### F02 画皮鬼（冒名同事）

- **原型：** 通过画皮伪装成人，故事中能换成不同年龄身份。
- **预兆：** 员工柜门开着、少了一件围裙（实物，OS09）；★同一时刻两张快照：门口进来一个“同事”，同事本人在库房（实物，CAM1+CAM4）；水槽边一攤带颜色的水，像洗过画笔（实物，OS06，本作原创）。
- **禁令：** 没在灯下看清的同事，不要把围裙和钥匙交给他。
- **发作：** 在侧灯关闭时完成交接；阈值50。发作=冒名者拿到员工权限进库房，当小时库房工作作废。
- **最佳准备：** 开核验台侧灯（1电），把真同事调到柜台。撒示踪粉是错误准备：它的脚印是正常的。
- **对峙：** 侧灯下看双层轮廓（特写），把围裙交给真同事，冒名者留访客区。
- **区分：** 双重身没有任何实物痕迹，只有交接本里“已完成”的任务实际没做；狐精只在交易里动手脚，不碰员工柜。

### F01 狐精（冒名同事，交易型）

- **原型：** 以人形交往，变化器物的外观与容量；善恶并非单一。
- **预兆：** 送货人说“这箱我同事验过了”（人言）；库房快照里送货人的影子多一条尾巴（实物，CAM4，本作原创）；★货单箱数与离手称重对不上，箱子变轻（实物，只在放秤后显示）。
- **禁令：** 没离手过秤的满箱，不要签收。
- **发作：** 交易型，不追人。触禁=错签，损失货值并计一次违规。
- **最佳准备：** 把秤和量杯提前摆到验收台；留一份已验样品（现卡的“减难”条件）。
- **对峙：** 离手称重，抽一瓶测容量；正确交涉仍给 SAN+2，保留“不全是恶”的原型。
- **区分：** 海亡灵也在到货箱上做文章，但箱子变重（多了压箱石）、箱缝有海草；狐精是变轻。一重一轻，称一下就分开。

### F12 不可杀伊（追逐）

- **原型：** 食铁并不断长大。
- **预兆：** 文具架的回形针、铁罐少了一截，留有咬痕（实物，metal_shelf）；金属被啃的嘘吱声（感官）；★后门铁把手或卸货闸被啃出缺口（实物，OS07）。
- **禁令：** 它追你时，手里不要拿铁器。本能是抄起东西防身，在它看来那是食物。
- **规则改动：** 手持金属（钱箱、工具）时追速从2.3升到2.7格/秒，超过搬重物速度。解决审查 J4 “永远追不上”，但只在触禁时生效，不动用户确定的回形针解法。
- **发作：** 入场即追玩家（沿用）。
- **最佳准备：** 把 B05 回形针投放盒提前放到前门诱离线；把收银铁钱箱锁进柜。预锁后门是错误准备：它会啃门，门坏了反而多一个入口。
- **对峙：** 逐点撒回形针引出门外（不变）。
- **区分：** 飞头女鬼的痕迹全在生肉和门外夜空，不可杀伊的痕迹全是“金属少了”。

### F13 飞头女鬼（追逐）

- **原型：** 与污秽和夜间觅食有关；发光飞头拖垂组织的定型形象受近现代电影影响。
- **预兆：** 门外快照里低空一团光（实物，CAM5）；★库房肉箱那格温度回升、箱底渗水（温度条+实物）；库房里湿滑的拖曳声（感官）。
- **禁令：** 肉被它碰过后，不要扔下肉逃跑。沿用用户确定的“丢肉不回退”，只是把它写成禁令。
- **发作：** 触肉后转追玩家（沿用）。
- **最佳准备：** T−40 前就把登记生肉运进工作冰柜（2–4精力），它只巡视一圈就离开。放回形针是错误准备。
- **对峙：** 沿用 F13 蓝图。
- **区分：** 见不可杀伊。

### F03 僵尸（追逐）

- **原型：** 尸体复起；吸取生命之气与跳跃造型在后世叙事和影视中广为传播。
- **预兆：** 库房方向规律的“咚、咚”声（感官）；冷链区降温、出现白雾（温度条）；★地面成对并拢的跳印，间距一致（实物，撒粉或偏振灯可见）。
- **禁令：** 它在附近时，不要跑。跑会耗体力，体力低于30%会喘气，喘出的雾点把它引过来。
- **规则改动：** 加一个按住即生效的“屏息”键：体力缓慢下降，不产生雾点。现卡的“利用雾点诱导跳跃”保留。
- **发作：** 体力<30% 且玩家在它5格内；阈值50。
- **最佳准备：** 提前把补货箱分成两小段放在暴露通道两端；体力回满再进通道。
- **对峙：** 用雾点引开跳跃方向，分段送货，退进柜台安全侧（需要 OS11 活板门）。
- **区分：** 吸血鬼只盯流血的人，从门外来；僵尸盯喘气的人，从库房降温区来。

### F32 夜返吸血鬼（追逐）

- **原型：** 死者夜间返回侵扰生人；一些传统强调取血。
- **预兆：** ★同事在热食台被划伤，头顶常驻伤口图标（实物）；门外快照里有人一直朝伤者方向站着（实物，CAM5）；顾客说门口那人脸色很白，不进来也不走（人言）。
- **禁令：** 有人在流血时，不要让他守收银台。
- **发作：** 流血的人在收银台或顾客等候位5格内；阈值50。
- **最佳准备：** 提前用 I19 急救贴包扎，伤口图标消失即失去目标；把伤者调去员工区。预锁前门是错误准备：它改从后门来。
- **对峙：** 伤者退到柜台后包扎，用空交接窗口掩护撤岗并关闭服务（与现卡相同；备用收银窗要先补）。
- **区分：** 红帽妖也和血有关，但它追的是地上的血迹路径，吸血鬼追的是流血的人。

### F42 哨声亡灵（声音预警）

- **原型：** 行走时吹哨的游魂；哨声听来远时实际近，听来近时实际远。
- **预兆：** 哨声，字幕如实显示“听来远/听来近”（感官，故意反向）；窗外影子越来越短（实物，CAM5）；★卸货闸旁机械压力牌指针升高，停电也可读（实物，OS07）。
- **禁令：** 哨声听着很远时，不要开后门。
- **发作：** “听来远”期间打开后门或卸货闸；只看违禁，不看 SAN。
- **最佳准备：** 趁“听来近”（实际远）的窗口先卸一批货，不耗电。预锁后门是错误准备：卸货工作就做不完。
- **对峙：** 看压力牌分批卸货（与现卡相同，闸和牌要先补进地图）。
- **区分：** 巨帽夜曲客、雾笛访客也在门外有乐声，但只有哨声亡灵的字幕带远近，并且压力牌会动。

### F21 报丧女妖（声音预警）

- **原型：** 哭号预示特定家族成员的死亡；报信者不是施害者。
- **设计点：** 它本身就是预兆。危险是另一件事：被点名员工的工位将要出设备事故。玩家学到的是“有些怪是帮你的”。
- **预兆：** 员工区方向的哭号（感官）；★值班板上一名员工的名字被水洇湿（实物，OS04）；该员工常驻工位的回路灯闪（感官）。
- **禁令：** 被哭到名字的人，不要让他回自己的工位。
- **发作：** 它不攻击。违禁=该工位设备事故（热食台起火或冷柜跳闸），被点名者受伤；受伤可接出吸血鬼的预兆，形成连锁。
- **最佳准备：** 在柜台交接本副本上调岗（解决审查 D8 的18秒走不完），再给该工位安全停机。
- **区分：** 哭泣女在门外水线边寻子、会引你出门；蓬蒂雅娜是服务台铃自己响。只有报丧女妖点名。

### F06 雪女（契约）

- **原型：** 冰冷气息、守密条件、后来以人形生活的故事（小泉八云《怪谈》）。
- **预兆：** ★前场温度条骤降、门玻璃结霜（温度条，读数为真）；广播和收银提示音变成沙沙杂音（感官）；一位女客点热饮，轻声说“别告诉别人我来过”（人言）。
- **禁令：** 她在店里时，不要开广播，也不要念出她点的东西。本能是按习惯叫号。
- **发作：** 广播或口头叫号泄露订单；阈值50。发作=前场冻结，收银和热饮台10秒不可用，SAN−8。
- **最佳准备：** 提前关广播（1秒，0电），备好纸质小票，开保温柜（1电）。开侧灯是错误准备：她避开亮处，会转到热食台后面等，交付路线变长。
- **对峙：** 用纸质小票完成热饮、保温、密封交付（与现卡相同）。
- **区分：** 雾笛访客也带雾和冷意，但它不喜熟食气味和亮火，要你保留热食灯；雪女要热饮，却要保密。

## 四、其余44只：速查与模板

其余44只先给预兆和禁令，发作与准备套用族群默认值；做到哪只时再按上节格式展开。对峙规则暂沿用现有卡的关键动作。★为区分线索。

**族群默认值**

| 族群 | 默认发作 | 默认最佳准备 | 常见错误准备 |
|---|---|---|---|
| 水系 | 站在与源连通的湿格 | 断水、铺 B07、擦交接格 | 关错阀、只擦不断 |

## 五、数据结构与通用状态机改法

目标：怪物差异全部写在 content json 里，代码只实现一套通用状态机、约30个谓词和约20个固定事件。现有 410 条转移、284 条中文条件不再直接执行，而是逐只改写成谓词。

**5.1 每张卡新增 omen_profile**

```json
"omen_profile": {
  "family": "water_drag",
  "lair_zone": "Z04",
  "omens": [
    {"id": "F05_O1", "tag": "trace.wet", "tier": "hard", "socket": "OS08",
     "lead": [-40, -15], "scale": "object", "verify": ["MC01:CAM4"]},
    {"id": "F05_O2", "tag": "sound.drag", "tier": "sense", "socket": "OS05",
     "lead": [-60, -40], "scale": "zone"},
    {"id": "F05_O3", "tag": "word", "tier": "hearsay", "socket": "OS03",
     "lead": [-40, -15], "line_key": "F05_rumor_1"}
  ],
  "hide_order": ["F05_O3", "F05_O2"],
  "taboo": {"text": "东西被拖走时，不要伸手去拽。", "verb": "grab",
            "target": "tag:dragged", "when": "state:ENGAGE"},
  "trigger": {"san_below": 50, "pred": "on_wet_connected(player, F05)"},
  "preps": [
    {"id": "valve_off", "verb": "cut", "target": "water_valve",
     "cost": {"power": 0, "energy": 1, "seconds": 3},
     "effect": "block_wet_spread"}
  ],
  "confusers": ["F24", "F56"]
}
```

- tier：hard（实物）/ sense（感官）/ hearsay（人言）。每只怪至少一条 hard。
- lead：相对到场时刻的秒数窗口；导演在窗口内随机落点。
- hide_order：后几夜按此顺序隐藏预兆，第5夜起只剩两条。
- scale：object（单格可见）/ zone（整区特效）/ hud（只进交接本），保证30px格子里能看清。

**5.2 谓词与事件**

谓词约30个：on_wet_connected、in_zone、facing、distance_lt、carrying(tag)、holding_metal、stamina_lt、bleeding(actor)、light_on(circuit)、door_open、door_locked、valve_open、broadcast_on、san_lt、violations_ge、timer_ge、receipt_exists、evidence_count_ge、journal_named、snapshot_has、item_placed(socket)、answered(line)、paid(order)、seated、awake_alarm、counter_drawer_open、customer_present、colleague_claims、hour_is、night_ge。

固定事件约20个：omen_emit、omen_hide、arrive、taboo_warn、taboo_break、trigger、flicker_warn、chase_start、grab_item、drain_san、steal、block_door、withdraw、resolve、reward、journal_unlock、decoy_emit、hallucinate、safe_retreat、report。

**5.3 通用七态机**

DORMANT → OMEN_FAR → OMEN_NEAR → ARRIVE → ENGAGE → TRIGGERED → RESOLVED / WITHDRAWN

- OMEN_FAR、OMEN_NEAR 只由导演按时间推进，玩家行为不能跳过，保证总有准备时间。
- ENGAGE 内部允许怪物自定义子状态（如 F12 的 stalk / chase），但子状态只能用同一套谓词与事件。
- TRIGGERED 前统一插入 3 秒回路灯闪（flicker_warn），给最后一次反应机会。
- 违规阶梯在状态机外统一结算：第一次 taboo_warn（SAN−3），第二次 trigger（SAN−8），第三次 safe_retreat（安全撤班，本夜结束）。

**5.4 导演层**

- 每小时开场排一只主怪，到场时刻=整点+20秒，远兆落在上一小时末尾（重叠出压力）。
- 第3夜起每夜加1条环境假兆（decoy_emit），从 E 系事件抽取，标签与当晚主怪的某个相似怪重叠。
- SAN<40 时 hallucinate 只生成声、光两类幻兆，永不写进快照与交接本。

**5.5 校验脚本要加的检查**

- 转移条件里出现中文即报错（迁移期可白名单逐只放行）。
- 每条预兆的 socket 必须在 maps.json 里存在；新插槽 OS01–OS12 要先加进地图。
- 每只怪至少一条 hard 预兆；三标签组合全表唯一。
- 同一 confusers 组内任意两只至少差一个标签，且最佳准备互相冲突。
- F12、F13 改写成数据后必须继续通过 check_rule_core.mjs。

**5.6 迁移顺序**

1. 先加 omen_profile 和谓词表，不动旧转移，导演只负责发预兆。
2. 把切片里的8只改成谓词转移，跑通。
3. 其余怪按族群批量迁移，族群默认值兜底。
4. 全部迁完后删掉中文条件执行路径。
