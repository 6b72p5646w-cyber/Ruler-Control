## 1. 如何复现，测到了什么

在含仓库内容的目录运行：

```bash
python3 scripts/check_td04_balance.py
```

只依赖Python标准库。输入场景见[balance_scenarios_td04.json](../content/balance_scenarios_td04.json)，战斗参考计算见[td04_reference.py](../scripts/td04_reference.py)，库存与周边界见[td04_economy_reference.py](../scripts/td04_economy_reference.py)。报告记录输入和模型哈希。

统一使用世界秒、区间`[0,T)`；恰在T到期的攻击属于下一段。塔已真实装填就绪，狙击仍需0.3秒瞄准。除明确的低血群例外，目标无限生命且显形合法，命中、位置、驻留和电网合法图边由场景输入。它们是用来分离机制差异的模型，不能把理想伤害当实际击杀时间。

狙击在短窗明显领先永久毒；持续投资60秒后，成熟毒反超。0.1秒采样的首个交点是48.0秒，但狙击是一阶一阶的单发包，附近会短时互相反超，因此不能把首交点说成从此每一刻都必胜。永久毒只有前8秒命中、随后52秒丢失射线，仍因已经附着q与支付过的成熟预算累计到330.4伤；不会继续虚构新主击或新毒剂。

75%物理护甲下，狙击的35个百分点来源穿甲使24秒直伤为230.4；它不把灵性防御也穿掉。75%灵性防御会明显压低永久毒与火场，而不影响纯物理狙击。这是选择目标与支援破防的理由。

八个18HP低血独立池、全部已在合法射界的直接伤害例：狙击最后击退在22.7秒，贯道钉列在8.1秒，分轨清签在9.68秒。该例只比较过量伤害和已成直线的穿透，不模拟自动选敌、移动或飞行时间；贯道若没有排成线，就拿不到这个收益。

广烧在六个合法受击池上，24秒自身伤害534；另有总计30 DPS的正常友方火力平均打这六池时，烧伤易伤额外贡献109.5。额外收益单列，不把友塔本来会打出的720点冒认成广烧伤害。它的价值随真实后续火力而变。

小炉对一池驻留0.75、2.25、6秒的原始场伤分别9、27、72；不含烧伤。六池全程满足有效驻留、24秒含自身烧伤的理想结果为1646.4。半径1.2并不保证六只怪一定同时留住，实际AI、碰撞和控制决定驻留比例。

## 3. 群咒按减压贡献衡量

五个普通敌人各每2秒进行一次20点直接攻击，第一击在第2秒，24秒窗口内每池11击，无咒总量1100。T08.A1从真实命中建立咒印及厄运后，期望承伤806，期望减少294，约26.73%。

这不是26.73%的全局伤害免疫，更不是每个预告都被取消。咒印只减合法直接攻击，厄运按同一个已提交攻击ID抽一次；未算恐惧、订单惩罚、已发射投射物倒流，也没有同时偷算冻结取消掉的攻击。玩家仍须躲危险招式。

## 4. 电器共振必须计入真实反馈

最终模型采用D=2.5、5荷触发、每波反馈总预算2、反馈效力0.75；普通一跳每个来源相位一条，普通弧也回填电荷。24秒感应例使用T09.B1真实1.8秒周期。以下图边由夹具明确给定，空间断线是单独的比较条件。

| 场景 | 全部电伤 | 过载波数 |
|---|---:|---:|
| 1池+2设备，24秒 | 49.69 | 3 |
| 3池+2设备，24秒 | 595.15 | 15 |
| 6池+2设备密集连通，24秒 | 2805.68 | 25 |
| 两组各3池+1设备，互不相连 | 834.62 | 24 |
| T09.B1设备停电，无感应脉冲 | 0 | 0 |
| 4池经设备中继，仅初始5/4.5/4.5/4.5荷 | 98.12 | 4 |
| 8池初始各5荷、无新增输入 | 1600 | 8 |

六池两设备理想密集场的2805.68是同六池全驻留小炉1646.4的约1.70倍；它需要真实供电、先铺电及连接关系。拆成互不连接的两组后，局部倍率与串联机会下降；设备断电时B1没有合法感应发射源，输出为0。单池即使靠两设备，伤害仍低于狙击，不是万能单塔。

第一候选D=4、每波返4，在**未计普通弧**时已经达到6797.70/56波；最终D2.5/返2同一无弧诊断为2334.52/20波，再把正常普通弧加回后为2805.68/25波。调整的是每份过载效力与反馈注入量，保留完整连通传播和每个受电者继续叠层。

四池通过设备串起来、仅种子满5而其余4.5荷的例子，远端也受第一波，随后反馈推出四波真实接力；没有新输入最终停止。八池各5荷的压力例释放八波后也自然停止。各例满足`外部注入+反馈=已消费+已过期+剩余`。

预约反例还验证：预约中的早期限部分失效，即使总荷仍7也取消旧队列资格，重新排队；另一只更早就绪的怪应先放电。保留未消费的两单位时，原期限不变。这避免叠层在满层或切源时悄悄丢失。

## 5. 连续跨区与真实转场是两种计时规则

四个6伤有效格：连续首次经过24，冷却内立即走回0；真实转场即使遇到旧冷却也收24，并把这些格截止改为抵达+2秒。另一次真实转场可再次收费，同事件重放0。柜体占了一格时只有18；未覆盖空隙也不计。

扫描使用真实坐标，不使用“距离向上取整”。中途擦角不造格；实际起落点的半开格各计一次。零位移或已取消预告不产生有效回执。连续轨迹以一次线段或120次采样提交得到相同计伤；冻结到同格会减少跨区收益，不会凭空制造运动。

T10.B1四格转场为24、普通完整跨越12；T10.A1八格完整新路线也为24，但覆盖更长并有开关周期。T10.B2三格合格预约落地为3+3+8=14，换到真实束缚1秒/精英0.6秒。它不把位置束缚冒充冻结停攻。
