# 固定日夜循环（V0.9）

当前门店机制见[门店玩法](20_store_gameplay_v05.md)，当前怪物玩法见[60怪机制派生](21_monster_gameplay_v05.md)。本页保留七天相同阶段，当前实际接入说明见[运行集成审计](27_runtime_integration_v09.md)。网页切片提供F12/F13两项同图实操与白天规划，完整六波夜班、其余怪物和微信发行包仍未接入。

## 核心体验

玩家是午夜便利店的夜班员工。每天都要做同一套工作，却不能沿用同一套处理顺序。主线张力由三个问题产生：现在来的是什么、我还有什么资源、眼前的同事或店长是否可信。

便利店是夜间交易的交界。不同地域的访客通过货运、旧物、仪式与夜行路线来到店内，逐周开放不同来源的主题组合。不会在首夜把全球所有传统随机混成没有关联的大杂烩。守护者、交易者和危险实体都有自己的动机，不能根据地域或外貌一概判为恶意。

## 参考作品

本轮检索到与便利店规则题材相符的官方作品为 Viu《The Rules / กฎหลังเที่ยงคืน》。官方介绍提及便利店夜班、13条规则，以及服务习惯被转化为危险条件的设计。[TV01](../references/README.md#tv01)、[TV02](../references/README.md#tv02)。本轮核对的是官方介绍，未声称已经完整观看全剧。

吸收的设计原则：熟悉的工作流程成为危险的触发环境；顾客的合法到店身份不等于安全；生活压力让角色必须继续上班。具体20条游戏店规、人物关系与60个访客交互重新设计。中文名称《致命规则》与该作品的对应暂按题材匹配处理。

## 当前练习与正式日程

[网页版实操](../prototype/playable_v09.html)可以从首屏直接进入F12或F13，不必先消耗六个白天行动格。它复制进入时的个人资源、物品、绝对游戏时间和咖啡债务，在独立练习中计算结果；返回原白天规划时不带回物品、消耗或收益，不发正式工资和奖券。练习中的一段120秒预算不等于已经完成一整夜。使用方法见[试玩指南](28_playable_slice_v09.md)。

正式日程仍按下表执行。资源适配器已经能够结算六格、整备、通勤和夜间资源；交班适配器也可运行有限核验与结算，但网页尚未串成包含真实顾客、店长、所有工单和六波怪物的完整夜班。

## 每天都相同的阶段

| 游戏时间 | 固定阶段 | 可变内容 |
|---|---|---|
| 06:00—08:00 | 交班结算、早餐与回顾 | 工资、损耗、证据、角色关系与事件后果 |
| 08:00—20:00 | 白天自由安排，共6个2小时行动格 | 睡眠、学习、恢复、兼职、采购或宠物照料 |
| 20:00—22:00 | 采购与整备 | 商店轮换、装备选择、消耗品、抽奖与宠物出勤 |
| 22:00—24:00 | 出勤与验岗 | 天气预告、私人班前约定、同事状态、店长授权 |
| 00:00—01:00 | 开班核验与收银 | 入口访客、支付方式、身份事件 |
| 01:00—02:00 | 验货与补货 | 送货来源、货物、仓库与搬运干扰 |
| 02:00—03:00 | 热食与冷链 | 饮食禁忌、温度、食物诱惑与资源压力 |
| 03:00—04:00 | 清洁与废弃物 | 水、污秽、后门、回收与路径变化 |
| 04:00—05:00 | 盘点与补单 | 库存、契约、客流与真假指令 |
| 05:00—06:00 | 结账与交班准备 | 证据补齐、人员核验与天亮诱导 |

日历统一记录绝对游戏分钟。白天一格推进120游戏分钟；夜间每2秒营业预算对应1游戏分钟。日历由实际已完成动作和已提交营业预算推进，不是另一只在暂停中自行运行的计时器。咖啡在实际饮用后60游戏分钟到期，不按下一个整点提前结算，也不在06:00清空债务。

七天完整复用该表。每段主工作之外，收银仍持续，同事可以承担已授权的工位。周次只改变候选内容、解锁知识、合理压力和剧情；不改变每日阶段顺序。

白天事件必须嵌入这张时间表。学习、睡眠、兼职等选择占用或替换现有的一个2小时行动格；一个格不能同时获得两项完整活动的收益。顺路通知、折扣和已有活动的修正不另扣一格。20:00—22:00整备共120游戏分钟，其中60分钟预留基本补给、装备和出勤准备，其余60分钟供明确标价的可选整备。E048公交绕行可以占用这60分钟弹性，不能扣除半个白天行动格，也不能侵占22:00—24:00的必要验岗。事件选择界面必须显示使用哪一格或多少整备分钟，没有额外的隐藏时间。

## 夜班节奏

标准夜班先按每游戏小时120秒阶段工作预算设计，六段合计720秒。地图操作实时消耗预算，安全特写按预先明示的工作成本结算；阅读、暂停与特写停留会使实际一局时长浮动，12分钟不再等于严格现实时长。阶段内包括营业预兆、主遭遇、处理、善后。一天的白天安排采用行动格结算，通常2—4分钟完成，不按现实18小时等待。

通常每小时一个新主遭遇。大型事件替换主遭遇；小事件消耗额外环境预算。上一小时未处理完的威胁先占预算，不强行叠满。20条规则是全局岗位规程，60个原型通过不同特征让规程的实际执行发生变化。

事件的允许小时、处理秒数和最迟完成点见`content/events.json`。夜间处理预算包含操作、核验、行走和善后，必须与当前工作共同放进本小时120秒内；不能靠暂停世界外的工作计时、跨过阶段边界或在结算界面补做来成立。天气等持续状态与处理动作分开记录，跨小时残留需要提前预留下一小时负担。

百鬼夜行只在01:00、02:00、03:00、04:00的阶段起点开始，完整占用120秒。当前阶段的验货、分装、清扫或盘点逐项嵌入巡游流程：80秒服务段中预留40秒执行关键工作，另有最多24秒用于两笔特殊交易，其余时间留给移动、恢复和操作余量。只有实际完成并产生验收物的动作才计入工作进度。开班核验和05:00后的收尾不被巡游替换；原有关键工作无法纳入此预算时不投放巡游。

## 结算与重试

到真实06:00时先提交恰好完成的合法动作及该次QTE的实际SAN结果，再冻结到期契约资格并释放其占用；然后检查未解除的关键威胁与任何活动恐慌。通过后才进入有限交班模式，允许已有记录及预声明柜台核验、钥匙账目交付，不推进战斗与资源时钟。普通店务和客单决定评级与工资，不能在确认界面补做。当前顺序见[条件合同](../content/condition_lifecycle_v06.json)和[集成合同](../content/integration_v09.json)。F53资格只从同一保留容器中的原两瓶得到，不允许旧单物示例与双瓶消费者各自判断；SAN+5仍在已核验交班后支付。

店长在预算700（05:50）的排程到场，只打开实际核验机会。它不证明眼前身体就是真店长，也不自动完成交班。有限交班适配器要求班前实际基线、当前身体的两类独立比较、仍连续的当前观察，以及向同一已核验身体交付原钥匙与账目。正式工资和奖券按稳定的`campaignId + nightId`去重；换一次尝试的`runId`不产生第二份奖励。完整身份画面和实际交接动作仍需世界执行器接入。

原型预排每小时2笔基础客单，全夜12笔，其中6笔窗口预订单、6笔必须实际入店的浏览单；六张主工单完成且合法交易至少8笔是A级目标。安全交班即完成该夜；经营不足降评级，仍领取扣减后的工资。工单至少完成4张且实际交易至少6笔才取得该夜奖券，防止整夜不经营仍拿满成长收益。符合条件的特殊客单可以计入，同一交易凭证只算一次，同事完成的交易正常计数。以上均为待试玩数值。

当前可启用的营业模式为正常营业与窗口服务。普通交易分别需要1.5秒、3.5秒；正常营业关闭迎宾语音时也需要3.5秒，窗口不重复叠加静音成本。顾客耐心24秒，翻牌不刷新。短时加固/shutter保留历史枚举，但其brace_door动作因缺少已登记实体推门消费者而停用：当前不显示入口、不扣电、不产生加固效果。任何可用模式保留紧急退出，普通手动闭门不用电。整夜只做窗口最多6单、最高B级，A级至少需要2笔实际入店的交易；特殊单替换基础名额，不额外添单绕过这项取舍。切模式或迎宾声道会取消正在进行的结账，保留顾客原耐心并按新方式重新开始。

营业牌不能让已经进店的怪物消失，柜台也不是对所有怪都有效的安全区。声音、湿路、冒名、休息位异常各依自身条件作用。未完成普通主工单只产生最多一张、保留到下一阶段末的店务债；不补做则每张扣5币，整夜本类扣款封顶20币，不制造第二轮待办或额外怪物。安全撤班专指玩家主动退出或关键危险尚未处理，不能拿少卖几单替代危险判定。

七夜结束按完成班次数、证据链和角色关系评价本周。下一周保留已学知识和合法长期资产，改换主题遭遇池与条件组合；完整新实体的补充优先于同一原型连续重复。第一周不保证见完60种，也不以集齐全部图鉴作为通关条件。

正式版失败重试当前夜，保留已学知识与图鉴；当前网页提供独立练习重开，不把它当成正式战役重试。消费、抽奖、物品使用和结算应共同写入明确检查点。当前有限模型已保存同物消费、咖啡债务、日领记录与结算去重账；生产环境仍需将这些账与战役存档原子持久化，才能保证中断或回滚后不会保留效果又退回物品。挑战模式使用固定种子，基础模式可以在整夜重新开始时切换可见的新种子。

## 移动端交互

2D俯瞰单店采用大地图、工位面板和局部特写三个尺度。移动、保持朝向、取放搬运、洒诱饵与入柜在大地图完成；扫码、计量和简修复用局部特写。低SAN显式缩小QTE判定区并造成黑视，可信HUD与记录保持清楚。详见[便利店交互基础](10_interactions_v03.md)。

规则本、已取得的证据阅读与系统暂停冻结所有计时，暂停期间不产生新动态信息或回复资源。实时监控观察、快照采集和世界操作持续运行；追逐时不允许全屏监控，退出操作始终可见。安全特写只运行本地QTE计时，退出一次结算工作成本；追逐中禁止进入这种特写，关键拾取和入柜保持实时短按。后台切换保存并暂停，退出特写不补算离屏追逐或隐藏伤害。

## 预兆怎样进入同一小时

常规主遭遇在本阶段第20秒到场。远兆位于上一阶段第80秒，近兆位于第105秒，临门提示位于本阶段第5秒；首只怪的预兆放在班前验岗。最后一小时不再生成不存在的第七只预兆。跨阶段预兆只是在已有物件上显示线索，必要准备时间必须一起计入当前预算，不能把上只怪的善后和下只怪的准备各算成免费时间。

预兆只提供异常现象，不自动翻到正确怪名页。初见给出本场景的危险动作提示，例如“货正沿湿线移动，先别伸手抢”，解法可由已学的擦断湿路与干侧取物推导。识别怪名不作为解除条件，预兆本身不扣SAN。后续夜晚主要改变事件、物件和已学机制的组合，不删除唯一必要线索。
