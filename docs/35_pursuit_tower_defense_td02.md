## 一 游戏目标与版本变更

玩家扮演会经营、会布阵的夜班店员。正常人类是营业对象；非人异常一旦显形进入战斗，默认追逐并打击玩家。伪装期保留真实识别，部分原有善意原型在被稳定后转为有限帮助。怪物的血条统一解释为本次显形稳定度，归零表示驱逐、净化或稳定本次投影，不代表杀死不可杀或神话本体。

| 项目 | 当前仓库基线 | 本方案 |
|---|---|---|
| 正确应对 | 部分动作提交后直接解除遭遇 | 提交真实弱点事实；封能力、破防、改变移动或取得控制窗口，由防御完成驱逐 |
| F12与F13 | 出门诱离、同肉入柜分别可直接成功 | 保留取物与动作身份，明确改写成功终点；提前封肉使其弱态登场 |
| 攻击对象 | 许多怪属于交易或有益访客 | 显形战斗态默认敌对；稳定成功后才可转为有限辅助 |
| 部署物 | B01至B08辅助物，固定槽，最多3件 | 新增6塔族与12陷阱；旧附件按实际功能迁移 |
| 动态路障 | 当前不改导航、不允许硬路障 | 允许具有耐久的相位栅，使用怪物专属可破坏导航边 |
| 经济 | 工资币及既有个人资源 | 工资币加灵能；交易、击退、升级均有唯一真实回执 |
| 四个人体资源 | 精力、SAN、饱腹、体力 | 保留；SAN承担玩家承伤，不新增第五条常驻生命资源 |
| 实现边界 | 60张卡不等于60个运行AI | 新设计独立验收；旧22套检查不能证明新塔防已通过 |

《王国保卫战》官方资料中的分工与功能性升级作为参考；本作使用设施挂载、自由追逐、真实店务与规则削弱。资料和具体借鉴边界见塔树文档第6节。

## 二 单场遭遇怎样运转

预兆出现时，玩家决定在哪个区域作战、要先操作哪个设施、是否增加或更换陷阱。异常显形后追逐玩家；玩家可以边移动边诱导，也可以用纸偶、路障和短控制换取执行规则的时间。弱点提交后，现场必须立即出现可见变化，如水路消失、外甲张开、飞头降空、镜出口被锁。塔在真实射界内持续压低显形稳定度，归零后停止该实例攻击并结算。

| 阶段 | 玩家实际行为 | 世界必须兑现 |
|---|---|---|
| 预兆 | 观察现象、读取既得记录、安排设施 | 至少一条关键线索免费可达；不开隐藏真名答案 |
| 显形 | 躲第一轮预告、选择站位与路线 | 出现敌对标记、稳定度与主要能力提示；至少1秒进入缓冲 |
| 应对 | 拿放原物、关指定设备、遮线、核验或诱导 | 最多3个主要步骤；成功项留下持久事实，不因一次失误全清 |
| 压制 | 把怪引入塔射界，利用陷阱和纸偶 | 射程、遮挡、移动层、状态持续时间按同一世界钟结算 |
| 终止 | 稳定度归零或有效的预防收束 | 一次性奖励；取消后续未提交命中的攻击；同批已提交命中按37号合同结清；残留环境按自己寿命结束 |
| 善后 | 继续交易、维修陷阱、为下一阶段准备 | 实际交易才进账；新遭遇不无限追加 |

每只怪采用一个主要危险与一个主要规则破解目标。基础普攻和移动之外，首周每只普通怪最多带一个特殊移动能力与一个明确环境依赖；精英再增加一个变化。难度来自选择与组合，不靠把多个计时小游戏压在同一秒。

正常交易和战斗可共处，但顾客不会成为玩家必须肉身挡刀的保护目标。怪物默认攻击玩家；普通地面怪会攻击正在拦截自己的纸偶和挡路相位栅；只有封停塔模组需要怪卡明确写出的特殊破坏技。正常顾客不受塔、灵性陷阱或怪物的玩家锁定伤害，也不参与挡弹与血源。危险靠近其营业位置时会退避，造成可见的营业损失。

## 三 规则削弱必须分成三种状态

| 状态类别 | 例子 | 恢复规则 |
|---|---|---|
| 本场破解事实 | 登记肉已封存；同一许可已撤销；一件原货已救回 | 本实例内单向前进。状态到期、暂停、读档、临时断电均不撤销已合法提交事实 |
| 临时战斗效果 | 减速、失衡、破甲、耗散、封下一次跃迁 | 各自按世界秒到期，不倒退主规则进度 |
| 当前环境条件 | 当地有阴影；某镜仍可用；活血迹未干；支流水路连通 | 只随实际灯、镜、血、阀和物件改变；不能从一次历史事实推断永久存在 |

例如列希的归苗事实可以永久拆掉本场林影护层；照明塔只暂时关闭其照区内的阴影节点。灯被暂时封停时，该局部节点可恢复；已拆掉的护层仍不恢复。飞头女鬼封肉后永久失去本实例的觅肉、高速高飞与吸食回复，短时失衡结束后仍只有低空基础追击。

| 通用效果 | 灰盒起点 | 叠加与边界 |
|---|---|---|
| 减速 | 单源20%至40%，总上限60% | 只取最强，不连乘；基础移动仍至少40%，不改变瞬移预告时长 |
| 持续耗散 | 典型每秒4点，持续4秒 | 各来源保留自己的绝对截止，同族取仍有效的最强剂量；弱者不续强者，终态停止，详见37号合同 |
| 破防 | 典型物理armor削20个百分点，持续5秒 | 同族取最强；规则破层单独记录；防御最低0，总减伤最高75% |
| 硬控制 | 普通每次不超过1.5秒，精英不超过0.8秒 | 同一连续硬控段从首次开始计算，总长普通不超1.5秒、精英不超0.8秒；重叠与续接不能推迟这个终点，位移也计入；结束后3秒抗硬控 |
| 封技与锚定 | 典型1.5至3秒 | 封明确能力标签，不封基本步行与普攻；通用来源每滚动8秒最多3秒，结束后3秒抗再封 |
| 规则封印 | 由真实主规则完成触发 | 可永久关闭本场某能力；不受通用封技预算抵消，但必须保留合法移动、可受击形态和基础攻击 |

同时触发两块陷阱时，先计算本次可接受的控制余量，再原子扣除真正发挥效果的充能。没有产生任何有效作用时不扣次数；伤害与附带控制混合陷阱只要伤害已生效就正常消耗。攻击被控制取消后进入自己的恢复与冷却，不允许一醒来补打此前的无预告命中。 次数触发型装置须离开再进入才可触发下一次；只有明示的持续区域场按时间作用。因免疫未耗次数，也把本次进入记为已处理，不能原地等免疫结束就自动重新夹住。

## 四 玩家操作与公平受击

沿用3格每秒基础步行；普通重物2.4格每秒，任务肉2.6格每秒。新冲刺起点为4.5格每秒、每秒消耗12体力，恢复继续沿用基础每世界秒6点及2秒恢复延迟；这些新冲刺参数需与手机操作一并调校。零体力仍可步行、拾取、放下、开关、包扎和进行主要规则操作。

SAN继续承担承伤：普通接触技建议10至15点，明显重击18至25点。同一伤害瞬间只取一笔有效主命中，获得0.75秒受击保护；同一次attack_id不多次结算。普通SAN伤害不自动生成伤口。玻璃接触等已登记切割来源才产生90秒流血，移动每2格留下30秒血迹；包扎停止新迹，旧迹按擦除或到期消退。[2]

SAN归零仍进入一次20世界秒恐慌，使用现有8秒可边走安定流程，受击或工作中断保留进度；同一恐慌不因重复归零重置倒计时。每夜免费安定次数沿用当前1次，完成恢复至15。新战斗预告、落点边界、可信HUD与紧急按钮不受黑视遮盖。

统一攻击分为起手提示、锁定区域、命中、恢复。普通近战起手至少0.8秒，重击或突进至少1.2秒，瞬移与跨区落点至少1.5秒；落地至少0.8秒恢复。具体条件必须满足：最慢允许移动速度能离开危险区，再加0.3秒反应余量。无法满足时改落点、缩小攻击区或取消本次攻击，而不是要求玩家必有冲刺。

怪物命中读取命中时的真实位置与无遮挡关系。已经锁定的攻击方向、瞬移落点不能追着玩家偷偷修正。多个怪的重击不同时封死全部出口；锁点已开始后，地面落点被占或封闭则取消位移并在当前合法点恢复，不无提示换落点。所有离屏预告提供方向、危险形状与倒计时。

## 五 移动家族与反制

| 移动家族 | 建议速度及动作 | 能做什么 | 对应策略 |
|---|---|---|---|
| 慢重步行 | 1.8至2.2格每秒；转向和重击长预告 | 沿可通过身体宽度的地面路径追逐 | 引诱开甲，侧翼射界，有限路障延长输出 |
| 普通步行 | 2.3至2.7格每秒 | 持续逼近并绕设施切角 | 减速线、纸偶、短控制与规则破防 |
| 冲刺或跳跃 | 平移2.1至2.6；短冲4.2至5.0格每秒 | 锁定短路径后爆发，随后至少1秒恢复 | 躲锁定区域，把地面陷阱放在恢复点 |
| 飞行 | 2.2至2.8格每秒；俯冲另有锁点 | 越过低台、地面栅；不能任意穿墙和高货架 | 基础对空输出，压空网，规则迫降；低空不自动算地面 |
| 预告瞬移 | 位移前至少1.5秒，落地0.8至1.2秒 | 在已登记合法点间转移；基础冷却至少7秒 | 预摆落地陷阱、锚定、封下一跳；无合法出口改步行 |
| 阴影跳跃 | 实际阴影节点间移动；过渡至多0.6秒 | 只使用当前有效暗节点，不能在玩家脚下造节点 | 局部开灯、切节点、保留一条可预测出口 |
| 镜面穿梭 | 登记镜间转移；显形窗至少1.2秒 | 只用有可见状态的镜面和固定外侧落点 | 封部分镜面、出口绊索；全部封镜后在当前地面退相 |
| 湿路或短相位 | 依真实连通水图或指定相位通道 | 可以绕过部分地面拦截，但每周期须有可攻击窗口 | 断真实支流、迫到岸边、灵性输出与定点锚定 |

高低设施必须新增明确标签：收银台、热食台、冰柜为低台；封闭墙和高柜、主要货架为高障碍。普通飞行越低台、不越高障碍；飞越某种高架若属于专属能力，必须在怪卡和预告中单列。原地图没有完整高度导航，因此表中的规则属于需要新增的设计，不能由现有遮挡布尔值自动推导。

不存在永久无敌的镜中或影中状态。基础岗位塔能攻击所有已经显形的地面、空中与相位出口投影；短过渡阶段可以不可选敌，但每轮必须回到可命中窗口。附体怪在显形时必须提供与真人分开的灵影目标，不允许对员工试射验真。

镜面穿梭已完成共享能力设计，但当前60怪中并无必须强行追加的原型。F60马面原来的镜子是安全观察工具，主方案不改成镜中传送；镜穿首先由无原型测试体验证，后续再给明确适合的新原型或专门变体使用。

巨体不是能挤穿所有过道的放大图标。巨魔按真实宽度使用宽通道；海坊主、吞世巨兽等以有限投影或局部攻击载体追踪玩家。所有部位共享一个显形稳定度与奖励实例，不因为一个头和一个手分别被压制而掉两份钱。

## 八 十二类地面陷阱

地面装置先开放1乘1、1乘2、1乘3、2乘2、2乘3五种足迹，可旋转90度。全图最多8件、总足迹最多16格，其中相位栅最多6格；这些上限是第一版负担控制起点。尺寸决定覆盖、成本和占地，升级默认不改变足迹。视觉上它们使用灵性媒介，正常人踩过不触发、不受控、不耗充能。

R12为相位结界，明确允许人类穿行；它不是一箱只有怪物看得见的实体纸箱。第一版不同时引入实体箱柜路障，以免混淆导航。飞行与指定相位穿行可越栅，普通地面怪必须能够用基础攻击打坏栅栏；无路时先比较绕行时间和破障时间，选择可执行路线，不能原地罚站。

所有陷阱L3必须先有L2；任何陷阱升级都在平静区进行，用2世界秒完成。增加容量只增加上限，不补满剩余次数。R01从容量4升6、剩余1次，升级后仍剩1次。补充单次充能的费用固定为L1建造金币除以L1初始容量，向上取整；例如R01每次3币，L2缺5次补齐收15币，用2秒完成同一笔补充。维修每次恢复最多最大耐久的25%，收费为L1建造金币的10%向上取整，用2秒；缺损不足25%仍按一次收费，满耐久时不接受维修。所有消耗与增量只在实际完成时一次提交。

回收与搬动保留剩余耐久、充能、绝对到期和每目标冷却，重新架设后仍有0.3秒武装时间。已经命中的耗散、破甲、短封技按各自剩余寿命结束；装置维持的照明或区域场随源失效停止。末次充能要完整生效，不能因装置变成0次而把已附着状态删掉。 耗尽但未收回的装置仍占件数和足迹；实际被毁并清除实体后才释放占位。正常完成夜班后的停机检修允许下夜攻击和纸偶重组冷却回到就绪，但不免费恢复可破坏装置耐久或陷阱充能，不能用失败重开与卖买重复领取。

## 九 建造与防堵路合同

塔与1乘3、2乘2、2乘3装置在班前或所在区域平静时建造、升级。塔装配4世界秒，大陷阱2秒；轻型1乘1、1乘2陷阱允许追逐中在玩家1格内用1秒架设，再经0.3秒武装。确认先预留资产，实际完成后扣款并启用；取消释放预留，不生成半座能挡路的塔。 平静区定义为玩家与目标装置各5格内都没有显形敌怪，两者没有被当前招式或落点锁定，且目标装置最近5秒未受击；从开始到完成持续检查。危险进入即中断。轻型战中架设可被受击打断，未武装前没有碰撞或效果。

建造菜单可以真正暂停，世界、班次、塔射击、交易、冷却、持续伤害、怪物与纸偶全部冻结。暂停期间只选方案，不完成装配、不补出电量、不采新线索。恢复后以当前状态重新检查占位和有效预算，再执行真实装配。

| 必须拒绝的摆放 | 原因与处理 |
|---|---|
| 覆盖当前身体、工位站位或唯一取放点 | 避免把人物卡进装置，或让规则物不可领取 |
| 覆盖门槛、原型诱饵保留区、已锁定瞬移落点 | 保留实际交互与预告语义；可以在周边设置作用域 |
| 足迹有一格落在墙、货架或不可走面 | 不能只检查装置中心点 |
| 玩家不能到达必需工具和应急出口 | 先预览到达路径，再允许付费 |
| 普通地面怪既无通路，也无法打通栅栏 | 按真实身体宽度与破障能力检查，不只看点导航 |
| 一堵路障使原型物件送达永久不可能 | 不能用动态墙摧毁该场唯一规则解 |
| 战中修理被攻击栅栏 | 防止修理速率反超伤害形成永久囚笼；平静时才维修 |

固定图仍有宽度不足3格的后场连接，新设计不把旧图谎称为处处宽道。大体型怪投放需要专门的宽度图；塔锚点落在设施内的静态检查，只证明坐标与基座匹配，不能代替射界、动态体积和所有怪物路线验收。

## 十 建筑交易与双经济

金币用于基础建设、普通升级、补充、维修及现有生活用品；灵能用于塔专精与高阶陷阱功能。原12格应急电保持有限战术资源，可选择对一座塔超载6秒，输出加30%，每次1格、全局20秒冷却；不加快纸偶重组，不改变控制上限，不影响基础冷链和普通射击。零电仍能完成主要规则与基础防御。

| 营业设施 | 基础功能 | 与防御的取舍 |
|---|---|---|
| 收银台与服务窗 | 有真实订单和商品时自动8秒交易；玩家亲自1.5秒完成 | 自动服务给追逐留手；亲自处理提高窗口内吞吐 |
| 商品货架 | 实际库存、浏览路线与上架动作 | 同一排的塔选择决定绕圈射界，货架仍要能正常取货 |
| 热食台 | 有限热食订单，真实原料和温度记录 | 高收益手工单可选；不能变成生存资金唯一来源 |
| 冰柜与冷柜 | 冷链、任务肉与封存 | 基础必要功能独立于塔，不因装防御模块失效 |
| 验收与提货设施 | 有限预订单及实物交付 | 窗单与入店浏览单保留不同路径；全窗口最多完成相应6单 |
| 核验台 | 当前物件与人员证据操作 | 塔不代替免费核验，核验位不能被陷阱占住 |

正常顾客退避采用软碰撞与预设安全边界，不在狭道堆成人墙。当敌对怪距当前服务位4格以内时自动暂停该位交易，顾客退避；耐心至多冻结12世界秒，之后恢复消耗，离店只损失本单收入。服务位恢复安全则继续同一单，不能通过退避重置订单或反复收钱。

普通订单建议每单净分成6币；货款与货本由店铺账清算，玩家获取的是已完成交易的分成。仍为每夜6单窗口预订与6单需要实际入店的浏览单，共12个有限来源。基础6币可由自动服务获得；首版不额外叠一套人工手续费，特色订单另有固定报价。建设一个建筑本身不会每秒印钱。

| 来源或消费者 | 建议值 | 何时结算 |
|---|---|---|
| 初始金币 | 120 | 开局一次，沿用基线 |
| 岗位基础镇契机 | 1台T02 L1 | 不可出售或复制，计塔容量；必要教程工具随岗位保证 |
| 正常交易 | 6币一单，最多12单 | 同一订单实际交付与收款后一次 |
| 普通主遭遇驱逐 | 12币与4灵能 | 主实例稳定度归零的终态一次 |

分身、幻像、召唤物、拆出的身体部位与同源再显形共享主奖励池。若以后杂兵需要掉落，从已预留池扣除，不另造无限收益。奖励唯一键至少包含战役、夜号、遭遇实例与奖励类型；练习副本不写回正式财产。

首夜算账例：120币买T01投射器35、T05纸偶岗45、R01胶带12、1乘2相位栅20，总花112，剩8。免费T02仍在岗。完成8个普通订单得到48币，击退6个主遭遇得到72币与24灵能，其中4个正确破解再得8灵能。交班前余额为128币与32灵能；安全交班加80币后为208币。表现奖金未计入，也未把未来工资当作夜内现金。

若白天补充与用品花24币、T05升L2花30币、再升L3花35币与12灵能，仍有119币与20灵能可作后续采购。该例证明收支有可执行路径，不证明七夜平衡已经成立。工资、订单数量、实际射界与升级速度需要一周灰盒经济回放。

双经济的底线是基础伤害不靠逐发消费，主要破解不需要先买稀有塔。玩家买错或布错会损失效率，但不会进入没有伤害来源、没有金币、怪物永远追着而又无法结束的悬置局面。

建设和升级在七夜内保留，消耗性充能与耐久不按换夜免费补满；合法班间检修只整理非消耗冷却。若金币和灵能长期累积，仍受8塔、16格地面占地和专精互斥约束，防御不能无限铺满地图。

| 夜次 | 新增学习负担 | 难度增长方向 |
|---|---|---|
| 第1夜 | 1个追逐者；渐进开放T01、T02、T05与3类陷阱 | 基础步行、F12诱导、F13高低空；不同时教多种移动 |
| 第2夜 | 仍1个追逐者；开放灯、纸偶、网与锚定 | 加入跳跃、水图和真实遮挡；保持单怪读懂时间 |
| 第3至4夜 | 最多2个已验证兼容追逐者 | 交错进场与两处射界，增加功能选择，禁止共享唯一工具死锁 |
| 第5至6夜 | 开放剩余塔和分支；每怪特殊能力仍有限 | 明确精英变体和可破坏装置，不根据临场买塔数量偷偷加甲 |
| 第7夜 | 最多2个主战斗实体；大事件替换主槽 | 用已教过的规则组合检验布阵，新增原型另开下一内容阶段 |

各夜的稳定度、攻击和奖励预算在班前按公开难度档固定；不能见玩家选对塔就暗中补抗性。完整七夜的火力增长仍需经济与实机回放；若高阶阵地使规则被跳过，应先检查射界驻留和升级收益，而非追加必须解题才允许伤害的绝对护盾。

## 十一 隐藏身份与跨系统语义

必须分开碰撞、触发与选敌三套掩码。只有已进入可攻击显形态的异常才参与防御选敌。正常人和未显形来访者经过地雷时，都不使它转头、亮身份灯、消耗次数或改变攻击按钮状态。由真实线索或已预告期限触发显形，之后才默认追打玩家。

| 容易混同的两件事 | 本方案定义 |
|---|---|
| 灯光与玩家注视 | 塔灯不等于玩家目光；不自动破坏F22、F59等不注视条件 |
| 广播脉冲与应名 | 塔声不替玩家答应合同或回应真实姓名；与订单叫号分不同声道 |
| 灵性火霜与真实热垃圾或湿路 | 不自动产生食品、流血、脏点、火灾或任务水；只有明确登记的适配才改变环境 |
| 纸偶与员工 | 纸偶没有员工身份、不持真实钥匙、不流血、不作为历史核验来源 |
| 战斗诱饵与原型物件 | 诱饵盘不能冒充F12回形针、F13原肉或F26真实血迹 |
| 怪物稳定与合同履约 | 击退不提前完成尚未交付的顾客订单或F53交班保留承诺 |
| 低空与地面 | 低空仍需要高度覆盖陷阱；只有真实着地才触发ground层夹具 |
| 不可杀本体与显形投影 | 稳定度归零结束本次显形，不宣称消灭传说本体 |

## 十二 代表性战斗与组合

例一，不可杀伊：玩家取真实纸夹，在货架端部射界内逐点撒下。首次完整停食1.5秒提交本场永久破壳，以后移动时护甲也低于原始值；每次停食另开更大的临时接缝。每场配给6次真实纸夹，已触发部分消耗、未使用部分才可回收；纸偶与相位栅延长经过火力区的时间，长钉塔攻击接缝。绕圈硬打仍能磨掉投影，但未破解时高防和切角使所需时间明显更长。新设计不强迫它去塔够不到的旧门外终点。

例二，飞头女鬼：未封肉时高飞绕过地面栅，扑击有锁点；玩家利用压空捕网或怪物扑击后的恢复间隙争取搬肉时间，在柜1格内0.6秒把同一登记肉存入并合盖。其本场觅肉、高飞与回复被封，转低空基础追击。价签塔可继续打空，捕网在合法地面迫降后，才允许地夹与对地炮加入。提前封肉会让它以弱态登场。

例三，列希与阴影：真实误收树苗产生有限影节点。玩家归苗可永久封这场林影；也能只用灯带封两个节点，把剩下出口留在火力区。怪物的落点先锁，不能因为看到盐钉阵就临时换到玩家脚下。影节点全部失效时，从当前合法位置退相并改步行。

例四，泽西恶魔：第二次同窗线索开始8秒锁窗计时。玩家把原遮板放正确槽并离开冲击带，怪物撞板产生3至4秒低空失衡，此时仍可缓慢移动，不属于3至4秒完全硬控。对空塔负责常态输出；压空网在合法地面迫降后，对地炮才可加入这一轮集中伤害。错窗仍可撤离保命，但不会得到完美挡击与最强火力窗。

例五，水路怪的不同解：河童依赖冷区支流，断该支流与取篮能迫出水影；塔尼瓦需要维护独立主渠与清除堵物，乱关总水反而妨碍应对。两者共用水图底层但读取不同来源，因此不能让同一总阀成为所有水怪的答案。

例六，镜穿测试体：三面已登记镜构成候选出口。玩家可封两面，把最后一面外侧纳入塔射界并布绊索；也可封完，迫使它从当前合法点退相步行。封镜动作不能在已锁点的同帧无提示把敌人改落到玩家身后。该例用于验证机制，不把它冒称为现有F60的原有特性。

## 十三 对直接绕圈路线的定量要求

为同一合法火力配置定义两个目标：首次成功执行规则后，典型总处理时间约35至50秒；不执行主要规则、只走位用塔，典型约80至100秒。复杂搬运型允许更长，但必须在本场时限内留一次失误与恢复。上述为测试目标，不是已观测数据。

算术例采用360稳定度、有效基准火力每秒20点。硬绕时射界驻留65%、目标减伤65%，实际每秒4.55点，预计79.12秒。假设前12秒同样受塔攻击，随后规则使驻留提高至80%、减伤降为30%，后段每秒11.2点，预计总39.27秒。优势来自真实破防与覆盖变化；这份算式尚未模拟移动、弹体或操作。

防止两种退化：若一个正确动作之后怪物毫无行动只能等射死，规则和塔防的配合过于单薄；应保留清晰的基础追击并让玩家利用持续窗口。若堆塔能无条件秒掉所有未破解怪，规则会变装饰；应优先检查总火力容量、站位与收益节奏，不能用全程绝对免疫强迫固定解答。

同一怪至少应支持两种有效布阵：例如高输出配走位，或控制与拦截配较低输出。专精设备可以大幅省时间，不能把第一只飞行、镜穿或相位怪变成买不到某塔就必死的关卡。

## 十四 六个遭遇槽与交班截止

每夜仍有六个主遭遇槽，每120预算秒释放一槽。当前设计明确撤掉旧的普通120秒、跨阶段180或240秒自动终止规则；阶段切换不删除怪、不重置稳定度、不抹掉弱点和冷却。唯一整夜硬交班点是预算720。临时攻击、订单、血迹与局部状态仍按自身世界秒期限运行。

为保证最后一场硬绕圈也有真实窗口，普通定时遭遇改为阶段起点给临门提示、约第10秒显形，预兆与必要准备提前在上一阶段末提供。第六槽在600释放，通常610显形，留下100秒保守作战和10秒收尾。610之后不再强塞未经验证的完整战斗。此改动替代旧第20秒普通到场时间。

前两夜最多一个主动追逐者，第3夜起最多两个。已进入临门显形倒计时的实体也占位；远兆只保留预约，不提前占整段战斗名额。无名额则下一槽等待，不加旧怪速度、不缩短预告，也不补发一堆敌人。主动拖延会用掉公开的剩余夜班时间，使后续预约无法处理，不能靠挂机跳过六槽。

每槽必须有真实来源、必要工具、合法进入方式和已教学且不依赖缺失历史的候选。班前检查整夜资源与后备候选，实际到场再核对；无血就不选追血怪，无旧回执就不选核旧账怪。后备卡所需物件只能由岗位或该次来访实际带入。导演自己的准入失败不记玩家过错，也不能补造伤口、交易史或故障来凑六场。 若运行中确认导演配置错误而已无合法入场窗口，本次标为配置无效，恢复该夜开班快照，不计玩家失败、不损失物资、不伪造第六份完成回执；对应未验收组合退出正式投放。

| 槽状态 | 能否计入完成 | 结算方式 |
|---|---|---|
| 显形已被驱逐或稳定 | 可以 | 12币与4灵能；真实主要破解额外2灵能 |
| 真实预兆中的响应源已消失 | 可以，记PREVENTED | 同一主槽12币与4灵能；主动有效预防再加2灵能，自然消退无额外奖 |
| 尚未真实成立的候选 | 不可以 | 无预防奖励；选择同槽合法后备，不占一个凭空成功 |
| 等待名额或仍在战斗 | 不可以 | 保留真实进度，无提前结算 |
| 候选因系统条件错误不可入场 | 不能归咎玩家 | 属于导演配置失败；修正合法候选，不能以此扣工资或增加威胁 |

提前准备分两类。F13这种已经登记的异常实例，封肉只使其弱态登场，不跳过战斗。F26或F32这种依赖真实血源的响应实例，若必要源在显形前消失，确实失去入场资格，则只对已经发生预兆并预留的那一槽记真实预防；不立即补怪。显形以后再止血，封追血与回复而不直接删掉怪。相同基础收益避免玩家故意放任伤口来多赚钱。

合格交班要求六槽都有有效完成回执、没有活动战斗或恐慌、玩家存活，并通过当前身份和原钥匙账目交接。零普通订单也能安全交班，只损失营业分成与评级。610时仍有因玩家拖延而未入场的预约，提前明确提示该夜无法正常交班；不在720时突然宣布。

主动撤班不发完整80币工资；到720仍在危险中为失败，不表现为日出自动清怪并领奖。首版重试统一回到该夜开班快照，包括金币、灵能、设备、充能及物品，失败尝试的新收益不带回；因此不能打一只怪撤班重复刷取。若以后允许带损撤班继续战役，必须另做已提交收益与绝对夜号规则，不能混用两种存档语义。

## 十五 开发边界与验收

第一灰盒先对照T01A/B与T03A/B的频率和覆盖，再接T02A、T04A、T05A的代表作用。使用R01、R02、R03、R04、R07、R12以及F03/F05/F12/F13/F40/F50；有限子体和镜穿使用无原型测试体，不在本轮增加正式怪卡。通过后补齐全部分支和60卡，不先做正式美术。

第一和第二夜仍最多一个主动追逐者；此切片通过后再开放两怪组合、T06、其余陷阱及分支。怪卡数据齐全不代表运行开关自动开启。已经有精确来源的60张卡先完成迁移，SCP约45项再复用经过验证的能力；为SCP新增的门店设施也要接受相同的来源、路径、预算与反制合同。

| 验收问题 | 通过条件 |
|---|---|
| 正确规则是否真有价值 | 同配置对比，明显减少处理时间或受击；反馈能说明被封掉的是哪种能力 |
| 直接绕圈是否真能赢 | 无主要破解、基础合法配置，在当前世界与阶段时限内有可重复胜法 |
| 是否只有唯一塔解 | 代表怪至少两种不同布阵可行；基础岗位塔在自然显形窗能造成伤害 |
| 会不会把地图堵死 | 各种尺寸、宽体、飞行、全封镜、全亮灯、破障与收回均不出现无路罚站 |
| 能否永远控制 | 多塔多雷交替硬控和封技不能突破统一预算 |
| 能否骗奖励与重装 | 重放回调、分身、暂停、升级、回收、换分支均不多钱、不补满 |
| 能否合理处理双怪 | 共享物件、相反灯态、同时注视、工位时长和攻击区不产生强制无解 |
| 失败能否解释 | 提示清楚显示漏处理的威胁、失误原因、可用补救和结算边界 |
| 手机是否可操作 | 保持至少12乘15视野；预告不被黑视遮；搬运、锁朝向和1秒架雷可舒适完成 |
| 何时可以做美术 | 代表切片实机通过，基础攻击轮廓、移动层和反馈尺寸稳定后再制作正式资源 |

数据接口至少需要 EncounterSpec、MovementSpec、WeaknessSpec、AttackSpec、TowerSpec、TrapSpec、FacilitySocket、PlacementPolicy、RewardLedger 和 DirectorContract。每个弱点写清生产者、原物身份、可观察线索、可达操作、永久事实、临时效果、失败恢复和终态。每个装置写清足迹、作用体积、目标层、次数、耐久、冷却、升级和回收语义。

同一时刻的结算顺序固定：已合法完成的玩家动作提交；更新规则事实与效果；合法位移和接触触发；塔与怪物命中批次；终态及奖励资格；到期与环境变化；最后才判断阶段或06:00。死亡或稳定度归零的实体不再补发该实例未命中的攻击，已发生的命中与真实代价不回滚。 命中批次内已经到时的攻击同时提交；塔同刻驱逐怪物不倒扣该批次已经合法发生的受击。玩家规则动作若明确中断当前招式，则因先于命中批次提交而取消该招式。 临时状态采用包含开始、不包含到期时刻的半开区间；清理顺序不能延长有效性。响应血源恰在显形时到期，准入按已失效核验；已合法完成的玩家原子动作仍先提交。

|---|---|---|

物理读取armor，灵性读取ward，每个伤害包只用一个通道，各有效减伤封顶75%；R07与T03B破防只改armor。普通破防、主要规则破层和来源穿甲分别计算。火、毒、冷不自动创造真实环境任务物。AOE按独立生命池计伤，根遭遇只结一次奖励；后期预留2主槽与最多6子体、全场8敌上限，非每场必满。详见37号合同。
