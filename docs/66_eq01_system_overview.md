## 核心决定

- 六槽：手持、灯具、制服、鞋、护符、包；每槽一件。36条目录中34条为设计候选，Q03/Q11继续归档。
- 每件给明确基础属性和核心能力；固定命名侧向选择，无装等、耐久、重复叠数值或随机洗词条。
- 所有人默认有短时奔跑；鞋提供更快短跑、两段折返、持续步速或搬运等区别。0体力仍能正常走路和完成必要机制。
- 开班时锁定六件与一个战术主动；移动能力独立一键，既有检查/照明仍是实物工具操作。两快捷道具栏与4件特殊道具额度，调度工具包最多6件，真实容量另外检查。
- 18种新消耗品负责状态铺垫、持续伤害强化、走位反制、真实窗口和塔攻击时机；营业中不能补货或变成现场布陷阱。
- 每个品质50%装备、50%特殊道具；普通道具给同种2件，其他1件。重复装备选同品质道具包，原品质更新保底一次。
- 一晚安全交班一券，保留开局1券；七晚赚7券，首周共8次基础机会。个人装备/库存/券/保底跨周，原塔陷阱和当周钱灵仍周清。

## 玩家实际怎么用

整备时选一个核心方向：例如先拿头灯完成搬运，或围绕积毒收银机拿催账算盘；装备卡显示它现在能配合的真实塔。开班后主要操作仍是移动、识别和处理机制。少量主动能力帮助抓住窗口，特殊道具决定本夜要带哪几次强力应对。

抽奖得到的是可使用的能力或有限强化，不发规则答案。所有必要任务工具都有原免费来源；未接入的处理器不能用一张设计卡冒充可用物品。
