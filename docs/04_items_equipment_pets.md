# 临时道具 抽奖 装备与宠物

全部属于游戏内系统。基础反制物资可确定获得，抽奖提供额外方案与惊喜。首版使用夜班赚取的奖券，不接入真实货币抽奖。

## 临时道具与抽奖

每完成一夜得1券，开局1券；额外事件可得碎片或特殊选择券。每次1券、一定获得物品。24项临时道具分12普通、8实用、4稀有，基础层级概率60%、30%、10%，同层等权。因保底，长期实际层级频率会高于基础稀有概率，不把基础概率冒充含保底的最终频率。

连续4次普通后，第5抽保证实用或稀有，二者按75%与25%抽取；连续9次非稀有后，第10抽保证稀有。稀有保底优先；获得稀有同时重置两个计数，获得实用重置连续普通计数并把连续非稀有计数加1，获得普通则两个计数都加1。

两个保底计数在同一存档内跨夜、跨周持久保留，交班、失败、换周及重新进入游戏均不清零；新建独立存档才从0开始。每次扣券、授予结果和更新计数以同一次保存提交，再展示结果，重复恢复不会重复扣券或发奖。奖池、概率和当前保底可查。

临时道具用后消耗；装备长期占槽；宠物是单独伙伴位。它们不能混成同一无限叠加背包。背包满时选择存仓、可安全使用或替换，不能自动销毁稀有物。基本食物、应急光和最低隔离工具不会只在奖池里出现。

## 六个装备槽位

手持、照明、制服、鞋、护身物、包各1件。共24件候选，稀有度代表策略复杂度与特殊用途，配套明显代价，不只增加通用数值。标价是调参起点。岗位标准工具是独立基础设施；没有买装备仍可用基本处置流程。

主角自带4格普通随身位，无需购买背包。只叠加当前装备包的附加容量：Q21额外2格普通位，总计6格；Q22额外2格普通位和2格保温食品位；Q23额外2格普通位和3格封存证据位；Q24额外6格普通位，总计10格。关键岗位工具不占这些格子；未装备的其他包不会继续提供容量。换包后超出的物品须先存入工位或仓库，也可取消换包，不自动销毁。

## 宠物

一次携带1只，P01—P06基础每夜各2次主动辅助，P07纸灯灵与P08布偶守夜者各1次；每只的`uses_per_night`为准，不再用全局2次覆盖个体。每日只显示一项主要照料需求，避免又多出四条宠物资源。疲惫则休息，不永久死亡。普通购买与明确救助任务均可获得；升级主要增加技能选择或减少一次使用的代价。

全套照料消耗一份对应用品，占白天1格、即2小时，精力-2、SAN+5。照料用品属于独立的固定商店目录，不进入24项临时道具奖池，也不依赖随机商店轮换；采购整备时可预购，照料行动确认时也可按同价补购，不额外占格。各宠物所需用品和价格如下。
