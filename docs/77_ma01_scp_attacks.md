# MA01：45只SCP改编怪物攻击目录

基线 `6445d758b9d1b63afad0afb7d75bc422e0d900a6`。本页是攻击设计补充；全部运行接入仍关闭。原主机制、HP/防御/基础移速、分裂召唤预算与三种结局继续由MD01负责。

## 全局读法

伤害单位为玩家SAN。每次攻击先显示完整预告；前摇、有效段与收招均按世界秒。冷却从起手计算，下一次还必须等当前有效段与收招结束。每个实际攻击ID最多命中一次，身体接触、部件、双射线和残留不重复扣伤；全怪共享2秒受击保护。

同一源物不是怪物。S27红池支口、S32陶瓮没有本体攻击；真正独立子体另有自己的攻击实例。S12触须、S21九尾、S37头身、S39骨片、S44双投影仍各属一池。真实移动的高度与转场审计不改变。

本轮不把S11正视退行改成投石仪式，也不让S34固定声源为了追击而长出移动能力。投石仪式由适合的民俗施法者承担。S12棘束、S30银丝承担SCP侧的有限缠绕；S23焰眼与S44影幕承担固定射线。

### 石掌合拢 · `S01:BASIC`

两臂发白并向锁定位置合拢；只有玩家未直视且1.2格内才准备。重新直视即取消未提交抓取并锁住身体，不在凝视中继续挥手。

判定：提交时以玩家半径0.25的真实占位检测锁定几何；有接触但被保护、失攻或取消不算真正空间闪避。 实体墙、当前真实关闭的隔断与声明可阻该高度的货架裁切；不穿墙、不移货架、不把普通顾客当靶。

玩家应对：恢复直接视线或横移；关笼操作可保持面对它。；所列安全工作窗优先于任何攻击选择；正确机制按原三种结局处理。

机制后：主机制完成立即停攻并进入本卡原离场/收容流程。 本招取消。

**原机制操作窗**

**时序与旧设计衔接**

- 观察限制是行动条件而非额外攻击。重新直视取消未提交抓取；真正笼内收容回执优先停攻。

真实主机制完成时按原离场/收容流程撤销所有待发与活跃攻击；所有从属攻击按原root_cleanup处理。
