# V0.5：从门店机制派生的60种怪物玩法

2026-11-18。先定义可操作物件，再让怪物原型改变其条件。当前权威数据为[encounters_v05.json](../content/encounters_v05.json)，共60张设计、120个事件变体；全部客户端开关关闭。

普通店务、应急电、四资源、信息可信度与结算以[门店机制](20_store_gameplay_v05.md)为准。地图绑定见[机制补图](22_map_mechanics_v05.md)；[F12/F13详细蓝图](11_encounters_v03.md)保留最高优先级。旧V0.4卡仅供历史推导，不直接混合加载。

所有禁令、预兆和解法都是本作的游戏改编，民俗原型与资料出处沿用[原型目录](../content/monsters.json)和[资料索引](../references/README.md)。不要求玩家先填对怪名；不把“识别出来”当作自动完成，也不把同类怪强塞进一个终态。

每张以一个主机制、最多两个辅机制组成。中文完成条件用于审阅，不可通过eval执行；客户端仍需为实际状态和可见反馈编写适配。时段表示可投放阶段，不把热饮、擦地等通用动作锁死到某一小时。

## 完整卡片

### F01 狐精

**机制：** SG07 归属与交换、SG09 容器封存与交付、SG04 持物与目标诱导。**阶段：** N02、N05。

**工作里的问题：** 验收台上的满箱货物一离手就显出空位；补货变成辨认哪些货能真正留下。

**核心禁忌：** 没离手显真的货，不要送上售货架。

**预兆：** 它持箱时的满箱影像与放秤后固定重量不符，时间戳不会回改。（world）；透明量杯可复核同标量饮料液面差异；计量工具提前陈列。（closeup）。

**玩家怎么处理：**

1. 把幻货箱放秤并退手，观察重量与满箱影像分离
2. 将一瓶移入量杯槽，封存显真的货；不算找零和利润
3. 把真货交入上架槽，幻货放退回槽

**完成条件：** 本箱全部分入已验货槽或整箱退回，假货不再占据待售槽。

**取舍：** 看着满箱很想直接补完；复核占一次绕路，贸然上架会出现空货格。

**免费基础解：** 所述基础操作使用本店常备工具与已登记任务物件；不要求购买、抽奖、宠物或应急储备电。可选交易的食材成本须事先公开且保留主角保底餐。

**犯错与补救：** 错上架时该格先闪出狐影而暂停售卖；把同一箱撤回隔离盘重测，不扣整夜收入。

**事件变体：**

- F01-V05-1 / E027：未验箱改放后门收货位。 应对：先搬回验收台再计量。
- F01-V05-2 / E002：现金交易无法足额找零。 应对：先用已有店内记账券结算，实物数量校正照常。

**地图绑定：** 入口 EP_FRONT_VISITOR；基础位 receiving、packing、goods_shelf、verification_desk；机制附件 使用基础物件。

**实现边界：** low；组件 MC01、MC04、MC05、MC09。客户端未实现，动态路线与合并预算仍需准入验证。

### F02 画皮鬼

**机制：** SG08 岗位身份与权限、SG03 光电与设备取舍、SG02 注视与遮挡。**阶段：** N01、N06。

**工作里的问题：** 换班时一个同事要你脱下围裙休息，侧光却照出第二层皮缘。

**核心禁忌：** 没核实身份，不要交出钥匙和围裙。

**预兆：** 侧灯照出颈边与衣领不同步的双轮廓。（world）；同一腕扣和站位在围裙遮挡前后不变，面容却变化；入口记录没有第二人。（closeup）。

**玩家怎么处理：**

1. 把交接钥匙留在员工侧，来者停在公开核验位
2. 从基础侧光看皮缘，再读公开围裙领取与本班作业的连续记录，两个来源分别核验
3. 将其留在访客权限并把围裙交给已核实真人

**完成条件：** 异常来者未获员工权限，交接物仍由真实员工保管，事件收场。

**取舍：** 去核验台会离开柜台，保持待核可以继续低风险营业；不靠不停扣SAN逼迫误判。

**免费基础解：** 所述基础操作使用本店常备工具与已登记任务物件；不要求购买、抽奖、宠物或应急储备电。可选交易的食材成本须事先公开且保留主角保底餐。

**犯错与补救：** 误递围裙先给可见越线预告；撤回权限并把钥匙收柜可止损，未核实就等待不罚真人关系。

**事件变体：**

- F02-V05-1 / E032：来者带真工牌要求免检。 应对：工牌放物件槽，按原流程采集皮缘与连续换貌。
- F02-V05-2 / E019：固定侧灯失电。 应对：在核验台启用基础应急灯后采集。

**地图绑定：** 入口 EP_FRONT_VISITOR；基础位 receiving、monitor_terminal、staff_locker、power_panel、verification_desk；机制附件 OBJ_VERIFY_READER、OBJ_VERIFY_KEYS、OBJ_VERIFY_LAMP。

**实现边界：** medium；组件 MC01、MC09、MC12。客户端未实现，动态路线与合并预算仍需准入验证。

### F03 僵尸

**机制：** SG06 声源与动作节拍、SG04 持物与目标诱导、SG02 注视与遮挡。**阶段：** N02、N04。

**工作里的问题：** 补货通道出现呼吸白雾，僵尸只朝最后一次吐气的位置跳。

**核心禁忌：** 僵尸蓄跳时，别在暴露通道急喘冲刺。

**预兆：** 暴露格吐气产生短暂雾点，下一跳指向最后有效点；安全侧雾点不传出。（world）；起跳前地面标记1.5秒，落地后停顿1秒才能转向。（world）。

**玩家怎么处理：**

1. 在干侧看起跳标记，把一次吐气留在远离搬货路线的格
2. 用最多4秒游戏内屏息穿过短通道并放下一箱，离开再正常呼吸
3. 分两段送完货，退到已有遮挡线后让最后雾点失效

**完成条件：** 两个本阶段货箱到槽，最后外部雾点失效，僵尸退回入口。

**取舍：** 短屏息限制迫使你分段搬货；安全点只屏蔽呼吸目标，不是所有怪的无敌格。

**免费基础解：** 所述基础操作使用本店常备工具与已登记任务物件；不要求购买、抽奖、宠物或应急储备电。可选交易的食材成本须事先公开且保留主角保底餐。

**犯错与补救：** 被扑到只掉当前箱并产生一次轻伤；箱留在可达点，落地停顿足够退回重新规划。

**事件变体：**

- F03-V05-1 / E018：暴露格屏息后的体力恢复延迟增加2秒。 应对：把两次搬运拆开，在安全侧喘息。
- F03-V05-2 / E025：后门不能作为绕行捷径。 应对：使用已标记货架内回路分段搬运。

**地图绑定：** 入口 EP_AISLE_MANIFEST；基础位 aisle_loop、goods_shelf、safe_counter、front_door；机制附件 使用基础物件。

**实现边界：** medium；组件 MC01、MC02、MC03、MC07、MC08。客户端未实现，动态路线与合并预算仍需准入验证。

### F04 鲛人

**机制：** SG09 容器封存与交付、SG07 归属与交换、SG04 持物与目标诱导。**阶段：** N02、N03。

**工作里的问题：** 湿纱离开水盘后自己收紧，拿得越久越想变成一团。

**核心禁忌：** 湿纱没有合盖保湿前，不要一路抱着它去结账。

**预兆：** 纱线在手中自行织出连续纹理，不是普通湿布。（world）；物件卡显示保持湿润的蓝色刻度；封闭托盘可止住下降。（closeup）。

**玩家怎么处理：**

1. 先给店配透明保湿盘加水
2. 在安全特写展开湿纱对齐一次量尺，立刻放回盘中合盖
3. 端封盘到寄售槽，交出有真实长度的纱

**完成条件：** 湿纱已量过、保湿盘已合盖并放入寄售槽。

**取舍：** 要先准备容器再取货；照普通干货顺序做会被纱缠住，不能用更多力气硬拉。

**免费基础解：** 所述基础操作使用本店常备工具与已登记任务物件；不要求购买、抽奖、宠物或应急储备电。可选交易的食材成本须事先公开且保留主角保底餐。

**犯错与补救：** 纱收紧时把盘放回湿台即可松开重试，已验长度保留；不要求制造眼泪。

**事件变体：**

- F04-V05-1 / E015：水槽无供水。 应对：使用店配应急清水瓶灌盘。
- F04-V05-2 / E010：地面湿连接已激活。 应对：在隔离台合盖后再移动，避免形成新连接。

**地图绑定：** 入口 EP_REAR_DELIVERY；基础位 receiving、packing、sink、isolation_cage；机制附件 使用基础物件。

**实现边界：** low；组件 MC04、MC05、MC07。客户端未实现，动态路线与合并预算仍需准入验证。
