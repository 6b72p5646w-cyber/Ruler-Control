## 1. 怎样阅读适配

有利表示在所写真实条件下具有策略收益；条件适配需要额外站位、规则或其他来源；短板表示相对低效，并非绝对免疫。不能根据怪名自动赋予元素克制、镜穿、召唤、回血或某种移动轨迹。每条推荐仍须检查实际生命池、射线和高度。

现有名册为60个已核实民俗条目，F14继续默认关闭。群体、电网和接触传染的极端密度先用具名测试场景验证，不把原型的多个工具模型或身体部位擅自当成独立眷属。

## 3. 群体与空间测试场景

以下为测试体，不加入正式怪物数量：

| 场景 | 必须看到的差异 |
|---|---|
| 三个独立生命池在同一范围内 | 广域烧伤/咒印可同时铺底；三池都能承受合法AOE |
| 六个生命池经过两个真实电器 | 按每个受击者局部N+E计算；过载排队逐波重读，不能把上一波密度永久快照给后续波 |
| 同一巨怪三个共池部位 | AOE、毒、咒、电、分区均按同一池去重，不得到三倍收益 |
| 高速连续地面冲刺 | 中途跨过的真实有效区均计费，不能被低帧率漏掉 |
| 同起终点的真瞬移 | 仅实际端点可触发，不能补出穿墙的中间区域伤 |
| 冻结于一个小圈内 | 驻点炙烤与曝光收益提高，移动分区的跨格次数减少 |
| 一次非致死分裂 | 先结本批伤害，再分配剩余生命、毒、待成熟预算、电荷和截止，不克隆历史投资 |
| 一台电器接两条铜轨 | 仍计一台设备、共用设备接触冷却；远端铜轨不把设备坐标搬入另一爆发范围 |

## 5. 优先灰盒顺序

第一组先实现T01.A1狙击、T02.A1永久积毒、T03.B1冻结、T07.A1广域烧伤、T07.B1小范围持续、T08.A1群咒、T09.A1/B1电容与设备感应、T10.A1/B1分区与真实端点，配T05.A1基础拦截。它们足以对照主要攻击方式；完整40叶已设计，灰盒实现分批进行。

先固定单目标、双目标、三池群体、八实体候选上限四组受控场景，分别测试站桩、连续冲刺、短显形、真转场与共池部件。记录首击、1/2/4秒有效伤害、累计毒量、状态建立时间、实际跨区数、过量伤害、控制空档、工作操作成功率和营业损失。电网另记录每波N/E、实际设备ID与各次准备消耗。

随后接F03/F05/F12/F13/F40/F50，保留它们真实原物与操作，比较先破解再集火和不破解硬绕两条路线。新增分裂/眷属只作为无原型测试体；需要正式加入哪一怪时，再单独设计来源、预算与预告。

通过上述空间与异常反馈之后，再实现剩余分支并开展手机输入、性能和七夜经济试玩。正式美术应能明确区分待触发层、持续状态、固定场、分区冷却与真实电器连接，避免只用不同颜色表示所有效果。
