# V0.9两怪规则实操指南

本文件说明[独立HTML练习](../prototype/playable_v09.html)的实际内容。它把两种怪物和便利店工作接到同一张地图上，用来检查路线、取放、追逐、资源和恢复是否闭合。**当前没有完整七夜战役，也没有微信发行包。**

## 打开与构建

下载`prototype/playable_v09.html`后，在支持Canvas与JavaScript的桌面浏览器中打开。文件内包含本轮使用的数据、样式及脚本，不需要额外下载字体、图片或运行依赖。GitHub代码页显示的是源文件，需下载HTML后使用。

修改源文件后，在仓库根目录构建：

```sh
python3 scripts/build_playable_v09.py
python3 scripts/validate_integration_v09.py
node prototype/check_practice_session_v09.mjs
```

构建清单见[playable_build_v09.json](playable_build_v09.json)，包含模块和数据SHA。HTML是生成产物；应修改同目录的`playable_v09.mjs`、`playable_v09.css`、`playable_v09.template.html`或相应核心模块，再重新构建。

本次环境无法完成真实浏览器操作验收：原生浏览器输入接口未连接，云浏览器不允许本地文件协议，因此没有宣称图形界面、手机触控或微信兼容已经通过。构建校验、源代码审查和无画面模拟的结果另见[验证说明](09_validation.md)。

## 地图与基本操作

练习使用现有`MAP_STORE`：店内30×30格、跟随玩家的12×15格有效世界视野，面积约五个手机屏幕；沿用正门前场、后门和外侧连接。货架和墙有碰撞，关闭的门会挡住路线。相邻工位才能操作，不会因点击任务名远程完成。

| 操作 | 桌面 | 触摸入口 |
| --- | --- | --- |
| 移动 | WASD或方向键；点击可达地面寻路 | 按住方向按钮；点选地面 |
| 当前工位操作 | E；点击高亮交互按钮 | 靠近工位后点交互按钮 |
| 洒回形针 | F或“洒回形针”，再点1.5格内空地 | 同一按钮后点选范围内空地 |
| 放下生肉 | F或“放下生肉” | 同一按钮 |
| 锁定朝向 | Q或“锁朝向” | 同一按钮；移动不再自动转脸 |
| 暂停 | 空格、Esc或右上暂停 | 右上暂停 |
| 查看规则、日间安排、背包 | 对应按钮 | 对应按钮 |
| SAN归零后的安定 | “安定呼吸” | 同一按钮，可同时按住方向移动 |

方向、主要行动和应急按钮采用至少44像素目标；低SAN只收窄世界画面，不缩小HUD或按钮。这个布局要求已写入样式，但真实手机命中面积和竖屏适配仍需设备验收。

工作动作会显示进度，移动可中断。暂停、阅读、进入日间安排或切到后台时，世界、怪物、资源、咖啡债务和恐慌一同冻结；暂停会清除尚未完成的移动指令，回到地图后需要重新给出方向或目的地。恢复不会额外重置已经完成的工作或敌人状态。

## 练习一：门外的金属声

1. 沿过道走近文具架，在1格内取回形针。主盒6份、另有一盒有限备用；不是无限补给点。
2. 在1.5格内的可见、可走空地撒放。每次0.25世界秒，场上最多3堆，每堆15世界秒；通过少量连续诱饵改变它的真实目标。
3. 沿正门方向持续诱导，必要时走近并操作门。怪物完整进入原蓝图的正门外区域，满足原保持时间才解除。

默认追逐玩家。单纯自己跑出店外不会胜利，撒到不存在的后门成功区也不算。最后一堆门外诱饵消失时，怪物能沿合法门口路径返回；备用盒为一次有限补救，不会重建主盒或重开已完成实例。

当前坐标模拟有四次撒放、剩余2份的完整成功见证；其用时是确定指令下的验证结果，不是给新玩家设定的过关时间要求。

## 练习二：不要碰那箱生肉

1. 前往库房，取起登记生肉箱。普通步行和本任务必要取放允许零体力，不会因体力耗尽失去唯一免费解。
2. 沿实际过道把原肉箱运到主冰柜。怪物先追原肉箱，触肉后转为追人；把肉放下不能清除已触发怒态。
3. 在有效冰柜旁执行同一次“入柜并合盖”。对象必须仍是这箱肉，柜子需要功能、可操作性和预留空间均满足。

提前入柜可以预防。若已经触肉、被追或途中放下，只要原物仍可取回，就可以继续真实搬运补救。同一帧合法入柜合盖完成先于随后攻击结算；成功后普通开柜或断电不能让已完成实例复活。

练习不会让肉箱被吃掉，也不会让同名新肉代替原任务肉。没有额外点答案确认，实际工作完成本身就是解除条件。

## 资源与低SAN

精力、SAN、饱腹、体力都读入当前日间状态。实际追逐命中改变同一SAN，并同步画面和恐慌控制器；快捷栏中的已核验原物按各自声明恢复，不会由多个模块重复加一次。

SAN归零后进入20世界秒恐慌期限，每轮练习一次免费随身安定，累计8世界秒，允许边走边做。实际受击或工作会中断，但保留进度；完成临界时刻先提交。真正晚于期限的完成失败，暂停不会偷偷推进期限或免费积累安定。

两项练习主要考移动和取放，没有加入人为QTE门槛。完整设计中的低SAN精度判定缩小已有规则参考；当前网页展示低SAN黑视，尚未提供精度QTE工作台界面。

背包在当前工作进行中或练习结束后禁用消费，并显示原因。其他使用失败保留弹窗、暂停与原物；成功才返回地图恢复计时。定心茶和便当需要安全工位条件，当前快捷栏不会把它们当成瞬时恢复品。

## 白天安排与补给

点击“白天安排与补给”进入本地日间计划。08:00开始，六个2小时行动格；可执行现有睡眠、浅休、散步、短工和指定方法页学习。20:00进入采购整备，随后完成出勤验岗。学习须选择仍未学过的页，学完后不重复扣格；本网页没有真实案例采集入口，因此不提供A04整理按钮。

岗位工作餐包含两份真实个人物品，同一个实际营业日只领取一次。采购只在规定整备时段可执行，支付真实金币后获得同物实例。使用、消费标记和日领标记一同保存；若浏览器拒绝本地存储，界面会说明只能保留当前页面内进度。

咖啡立即加精力12，每份在实际使用60游戏分钟后扣精力8及SAN2。它不是下一整点，也不因跨06:00、睡眠或刷新而消失。保存中包含尚未结算与已经结算的咖啡债务。

“带当前状态进入练习”创建独立副本：四资源、背包、消费限制和债务被复制，练习内的使用不回写日间计划，胜利不发正式工资或奖券。重新安排本地计划会重建本地日间测试状态；这不是正式战役重试或反回滚方案。
