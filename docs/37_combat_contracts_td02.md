# TD02 统一伤害、状态、强化投资与群体合同

> **TD03版本说明：** 本页保存TD02历史方案。塔树、异常状态、陷阱与分支推荐已由[TD03重构](40_td03_system_rework.md)及41—44号文档更新；营业、设施与原物操作仅在未被明确改写的范围继续沿用。旧检查结果不代表TD03运行器已实现。

2026-11-19。本文件约束[塔树](36_tower_specialization_td02.md)、[结构化塔表](../content/tower_defense_td02.json)及以后接入的追逐执行器。**当前为设计合同；没有实现或验证完整战斗运行器。**

## 1. 三类状态与两个防御通道

本场主规则事实、短时战斗状态、当前真实环境分别保存。封好登记肉、归还原物、消除真实血源等事实不因减速到期而撤销。塔技能不能提交这些规则成功回执。

物理伤害读取`armor`，灵性伤害读取`ward`。每一伤害包只选一个通道，不能连乘两次防御。有效减伤分别限制在0—75%。投签、炮弹冲击、纸偶近战默认物理；灵毒、灼烧和符印默认灵性。寒意本身只控制，不额外送伤害。

计算顺序：已完成主要规则改变基础防御；同族通用破防取最强；再扣本来源明确的穿甲；钳制后结算该伤害包；最后应用当前有效通用易伤。通用易伤同族取最强，最多20%。

R07和T03B的20个百分点破防只作用于物理armor。T01A的25个百分点穿甲只帮助该来源的合法物理包，不变成所有塔共享的减甲。主规则破层与上述通用效果独立记录。

例：100点物理包，规则处理后的armor为65%，R07破防20个百分点，本来源没有穿甲，则实伤55；不能再乘一次ward。相同DPS的高低频攻击通过同一百分比护甲时，长期减伤比例相同，大单发并不天然破甲。

## 2. 攻击周期、首击与攻速

`interval_s`表示相邻正常发射之间的完整周期。T01A的0.25秒瞄准包含在1.8秒周期中，不能额外串成2.05秒。新目标第一次建立瞄准可以有该延迟；已稳定锁定目标的后续攻击保持规定周期。

攻速增益通过正常攻击进度速率生效，不将已有装填进度直接归零或补满。默认只加速普通发射、纸偶普通攻击和光束伤害脉冲；不加速DOT总伤支付、效果到期、封技充能、纸偶重组、热爆公共冷却和曝光升档所需的真实持续时间。同族广播取最强，最高30%，不是10%再加30%。

高频塔热印爆发受2.4秒公共冷却，攻速主要提高主攻击和成层速度，不保证爆发频率同比增加。候选10%、25%、30%加速档需检查总收益单调；不得只检查面板发射数。

T05B交错截击不再使用额外1秒目标冷却。只有非阻挡的另一偶，按自己的真实正常近战周期和攻击包触发一次，既防同塔双算，也避免1秒间隔被加速成0.909秒后反而隔次丢附伤。

## 3. 合法目标、射线与高度

选敌只包含已显形可攻击目标。普通顾客和未显形来访者不触发陷阱、不被塔转头识别、不参与爆炸目标计数。

地面、低空、高空和不可选中转场是不同状态。T03A/B只命中地面；低空不等于地面。R03或明确原型动作造成合法迫降后，地面装备才生效。冻结不改变高度，不能把飞头冻在空中后当作落地。

所有新命中检查实际射线和当前高度。固定落点炮弹不追踪目标；弹体飞到位置时按真实占位结算。爆炸中心到目标也检查墙/高遮挡，不能通过爆炸半径穿过封闭墙体。

附着的有限DOT和热印不会因目标换高度或短暂影行自动清空，仍用同一世界钟到期。不可选中只阻止新锁定/新命中，不能回溯取消已附着效果；跳字和余辉不得泄露隐藏新出口或允许隔墙续射。

## 4. 主命中、次级伤害与批次顺序

一次正常攻击可产生主命中；一发AOE可对多个合法独立血池各产生一次主命中。每攻击阶段、每血池只一次。弹丸模型的多个碰撞面和同一怪的多个身体部位不能增加触发次数。

回程签、子罐、爆发附伤、毒跳、灼烧跳、侧击附伤属于次级效果。次级最多一代，不产生新热印、连锁技能、完整DOT复制或额外金币。指定阈值消费可从一个主命中同时派生爆发与一笔灼烧；二者同级，不是爆发伤害再触发灼烧。

持续光束以明确0.25秒伤害脉冲、至少0.5秒的技能命中采样运行，不能按渲染帧数触发技能。纸偶命中携带所属塔ID，不能用两个纸偶冒充两座来源突破技能合同。

同一时间批次按以下顺序处理：

1. 提交已经完成的真实玩家动作与永久规则事实。
2. 结算已提交的主攻击基础伤害，消费此前批次留下的脆冰。
3. 加入合格状态，记录寒意消费前快照。
4. 按时间、来源ID、攻击ID稳定顺序裁决本批技能申请，使用提出申请的塔实际已购买等级。
5. 原子提交冻结消费、标记、公共冷却，以及最多一代的次级伤害。
6. 整批伤害完成后才判断分裂、终态和根遭遇结算。

生成脆冰的同批攻击不能消费这枚新脆冰。敌人已经提交且本批到达的攻击不会仅因同批被塔击退而被追溯删除；提前完成的真实规则打断则按其事实处理。

## 5. 热印：有界贡献与合成剂量

热印按`health_pool_id`共享，最多8枚；每枚独立保留4秒，贡献2.25点原始物理爆发。不同塔命中共同积累，但不是每座塔各自8层。

每个合格主命中先清理过期热印，再在未满8枚时加入本次一枚，随后检查阈值与冷却：本次刚加到第8枚且共享2.4秒冷却已结束，即原子消费8枚并产生一次18点爆发，不另等第9次命中。冷却中最多存8枚；满层时的新命中不增层、不刷新已有截止。冷却结束不自动爆炸，仍需一次合格主命中；若此时已满，只消费原有8枚。满层等待期间各枚照常到期，没有新命中就没有额外攻击。

若热印带有焦痕技能，消费时先把8枚已付贡献相加，再生成唯一`composite_dose_id`灼烧剂量。例如4枚I级与4枚II级贡献为`4×0.25+4×0.375=2.5点/秒`，持续3秒。不能拆成两个1和1.5的剂量后误取1.5，也不能取最高级3点给所有层。

不同爆发形成的合成剂量各自保留截止，和其他灼烧剂量同族取强，不相加、不相互续命。贡献者只负责溯源，不改变唯一剂量身份。

热印跟原血池，不随塔切目标迁移到下一只；剩余层数不发奖。对共享身体同一攻击不能多加层，独立子体各有自己的计量。

## 6. 持续伤害、回复抑制与冰火

burn与poison各自保存有限来源记录。每条记录包括来源/剂量ID、已购买等级快照、强度、施加时间、绝对截止。该族最终伤害取所有未到期记录的最高强度。

弱塔只能刷新自己的记录，不能把强毒无限续住。例如A为8点/秒剩2秒，B为4点/秒剩5秒：先按8点支付2秒，再按B支付剩余3秒。升级不追溯提高旧剂量。

回复抑制独立归并所有仍有效的毒剂。即使4点毒伤不是最高毒伤来源，它携带的40%抑复仍可生效；另一座6点毒伤但没有抑复的塔不能使怪物恢复回血。毒伤取强与减疗取强使用同一批未到期剂量，但分别计算。

DOT每个有效时间段读取目标当前防御和永久弱点，后来完成主要规则能改善余下伤害；来源强度保持施加时快照。到期前已累计的最后一段伤害要结清，但不得把效果延长到截止之后。真暂停冻结全部世界计时，终态取消余下DOT。

已命中的附着状态可以在源塔被封停后继续到自身截止；依赖塔持续维持的照明、声域和光环随源停止。源恢复不重新施加旧剂量。回收、移动、升级和换型不刷新旧状态。

火与冰默认并存：灼烧不清冻结，冻结不清灵毒或热印。它们是显形载体上的不同战斗约束，不自动产生真实火灾、食物腐败、任务积水或血源。本版没有“火塔自动融掉友方冻结”的隐含反应；后续若加反应，须单列有限附伤和公共冷却。

## 7. 寒意、脆冰与统一控制

寒意每枚6秒、目标共享4枚，每枚8%减速。同族新增至少间隔0.8秒；达到上限时只替换最旧一枚，不整体刷新旧截止。寒意与胶带等减速只取最强，总减速上限60%。

买了冷凝封冻的当前命中塔，才能在已有或本次达到4枚时提出冻结消费，使用自己的技能等级。没有该技能的塔只添加/替换寒意，不能调用远处另一塔的最高等级。普通冻结0.8/1.2秒，精英0.6/0.8秒。

每血池共享8秒冻结尝试冷却，申请失败也消费并记冷却。普通连续硬控段从第一次开始计最多1.5秒，精英0.8秒，重叠和续接不能推迟终点；击退导致的失控也计入。结束后3秒抗硬控。

进入任意硬控或抗控时清掉冻结储备；这段时间冷炮合格命中改为24%减速、2.5秒的冷痕，不攒下次冻结。冻结尝试冷却期间，在非硬控/抗控时最多存3枚。这样控制结束后不能立即兑现一轮历史积累。

脆冰技能读取本次更新后的消费前寒意快照：达到2枚，或已有本族冻结/24%冷痕，即可申请一枚4秒脆冰。每目标本族4秒一次。冻结清层不取消这次脆冰资格，购买冻结不会降低另一条技能的触发频率。冷痕只满足脆冰资格，不储冻结层。

下一批合格物理主命中消费脆冰并追加12/18点物理次伤；毒跳、回返和子罐不消费或生成脆冰。每枚标记只兑现一次。

通用封技/锚定每滚动8秒最多3秒，结束后3秒抗再封；只封明示能力，保留基础移动与普攻。永久规则封印独立存在，不因公共预算到期恢复。

## 8. 群体兼容：身份、总量与终态

本节只为后期群体预留塔接口，本轮不新增完整怪物卡。候选上限为2个根遭遇槽、6个额外子体、全场8个敌方actor；每根同时最多3个额外子体，累计最多6个新子体。子体不能递归生育。它们是上限，不是每次必须生成的配额。

| ID | 负责内容 |
|---|---|
| `actor_id` | 位置、碰撞、当前攻击实体 |
| `health_pool_id` | 扣血、附着状态、热印/寒意、每目标冷却 |
| `root_encounter_id` | 遭遇槽、谱系、主规则事实、唯一奖励 |

AOE按生命池去重。F54多个部件共池，一次主爆只扣一份；三只独立眷属有三池，一次范围攻击可各扣一份。不能用根奖励ID错误去重，让真实眷属只有一只受伤。

四类关系必须分开：

| 关系 | 母体变化后的行为 | 结算 |
|---|---|---|
| 共池部件 | 跟随原生命池，无新增总血量 | 主池一次终态 |
| 依附召唤 | 母体真终态后停攻、崩解，取消未提交生成 | 崩解不触发击杀链或子奖励 |
| 独立制造 | 母体真终态后停止制造，已存在的子体仍需清理 | 有效血池清完才关闭根槽和结奖 |
| 真分裂替换 | 原actor移除但根未结束，子池接续余下预算 | 全部有效分裂池结束后只结一次 |

分裂必须先扣完当前整批已命中伤害。归零则不分裂；非致死时子池当前稳定度之和不超过实际剩余。不能先分裂再丢掉致死过量伤害或同批其他塔的攻击。

旧DOT剩余原始伤害预算、热印/寒意数量与贡献要按份额分配，绝对截止和公共冷却继承，不给每个孩子完整复制一份。防御、子攻击并发、移动与清理时间也计入原遭遇预算；仅证明血量守恒还不能证明有效耐久没有翻倍。

生成预告先预留名额与合法落点。容量不足就本次不生成，不让母体进入无敌等待，也不无限排队到最后一刻一起出生。独立子体未清时根仍占主槽，导演不能把母体死亡误当空位再塞一个主遭遇。晚班新增群体必须有足够的完整预告、处理与撤离时间。

所有子体、蛋、分裂体和身体部件共享根奖励池；无每命中、每毒跳、每冻结、每子体击退的金币/灵能收入。根规则完成事实继承到本次谱系，不能靠分裂抹掉玩家已做对的事。

## 9. 强化、换型与耐久

每个强化槽I/II同价，白天付费换分支只变更当前启用能力，两个槽的已付等级不复制、不退款。出售仅按可计入资产的实际金币投入计最多60%，灵能不退；维修、补充与换型费不进入退款本金，免费岗位塔的初始造价也不计入。

T05改变纸偶数量时，要求旧队全部存活并离战3秒；仍有死亡/重组中的纸偶就等待，不提前扣费或复活。通过后按全队当前耐久/旧总上限的比例映射新总耐久，再平均分配；继承旧攻击/技能最晚截止。相同数量的耐久上限升级也保持比例，死亡与重组进度保留。正常交班检修若恢复单位，只能由独立的一次检修回执触发。

升级、移动或更换目标均不能预充T01A首发、填满公证充能、预热灯光或重置纸偶。T01A只在确实无合法目标时积累2秒蓄能；有目标但手动停火不积累。这样不存在“每发额外等0.2秒就恒定×1.5”的最优漏洞。

## 10. 灰盒必须验证的反例

- 多座速贴同帧满层：只消费一次，共享爆发冷却，混级灼烧合成正确。
- 强毒过期、弱毒持续：强毒按原截止消失，抑复仍由各有效剂量独立归并。
- 子罐杀子体：不二次爆炸、不复制灼烧、不多结奖励。
- 夹具先触发、霜炮随后命中：不能把旧寒意藏到抗控结束立刻再冻。
- 冻结与脆冰两技能同购：消费前快照、冷痕资格和后续攻击批次一致。
- 纸偶获10%、25%、30%攻速：正常攻击与夹击总收益不反降。
- 灯在敌人准备中途升至最高曝光：仍能在剩余可打断窗口尝试快门。
- 多部位与独立眷属同处炮区：去重键正确、目标上限正确。
- 同批致死伤害穿过分裂阈值：先伤害后分裂，没有丢伤或免费子体复活。
- 纸偶半血/死亡后升级与换型：不补满、不绕过重组。
- 不执行主要规则：仍有合法可伤窗口；满树也不能永久封住全部能力。
- 有规则成功回执：T06B只响应当时有效且未消费的回执，不通过升级补发历史增益。

这些反例是执行器接入的验收要求。本轮静态交叉检查和算术核对不能代替实际手机追逐、寻路、命中与一周经济试玩。
