# MD01：店内抽奖机方向

这一步只确定机器、券、奖励用途和营业边界；怪物设计是本轮主要交付。既有工资券概率和保底沿用，尚未制作美术，也没有把随机采样器接进运行器。结构化方向见[抽奖机数据](../content/lottery_direction_md01.json)。

## 一轮就是完成一晚正式营业

**00:00–06:00撑完正式班次并成功交班，固定给1张券。** A/B/C评价继续影响各自工资与表现，但这张基础券不再要求高评级。每只怪、每个小时、每个子体都不另算一轮。七晚全部完成便有7张基础券；失败或练习不发本晚新券，也不没收已有券和保底。

“成功交班”仍要求真实06:00、关键威胁解除、当前店长身份核验和原物交接。把未解锁怪压在1点血或暂时压制到天亮不算完成；安全拒绝且对方实际离开可解除威胁，但不领取该根成功奖。

复用正式交班的唯一回执，工资和券一起保存。同一夜重新读档或重复交班不会再领。旧E065真实可选工作保留每夜至多1碎片、3片换1券的额外来源；它不计入7张基础券，完成条件和根奖励去重继续保留。

## 放在店内，服务交班与班前准备

机器占一格靠墙位置，另留一格交互站位，位于交班/休息区；不能占主过道、货架挂点或怪物必须使用的任务槽。准确坐标留到地图接入时确认。可在06:00–08:00交班休整或20:00–22:00采购整备使用，营业中关闭。每次1券、15准备分钟，剩余时间不足便不能开始。

营业中机器断电，不属于TD05战斗电器节点，也不是塔挂点。抽奖不会额外增加电器共振倍率；不能砸机器取奖。池为空、品质保底无有效候选或当前客户端没有奖品处理器时，既不扣券也不动保底。

## 奖励分工

| 奖励 | 方向与已有例子 | 主要取舍 |
|---|---|---|
| 手持/照明装备 | 检视镜Q02、头灯Q06 | 间接观察须有合法视图；占手或电量形成代价 |
| 追逐/搬运装备 | 轻步鞋Q14、搬运靴Q15 | Q14只把空手步行3.0提到3.15，仍慢于常规3.3怪；一鞋位二选一 |
| 信息与携带装备 | 证据包Q23、护袋Q18 | 保留已获得证据、扩特定容量，不生成答案或任务物 |
| 一次性个人补给 | 葡萄糖片I03、薄荷糖I04、核验封签I18、急救贴I19 | 消耗同一实物；看实际目标、耗时和当前效果，不能无目标偷领收益 |

装备沿已有六槽，追求操作余裕和不同打法。核心规则用品、怪物关键物件与基本反制始终免费可得；不会要求先抽到某件物品才能让某只怪可解。

停用的I22/I23/Q03/Q11仍不入池。新SCP出现声音、污染等概念，也不自动让旧物品获得尚未写明的能力。22件候选装备和22件候选道具还要通过实际处理器与消费者检查，才是某个构建的可抽池。

同名装备首版不叠加、不合成永久数值等级；重复时拟换一次明确普通个人补给选择，具体补给表下一阶段定。重复不是重新随机抽：中奖品质、物件与重复判定在亮结果前固定，保底只更新一次。装备的standard/special等旧稀有度映射，以及各品质内装备与消耗品占比，也留到奖池阶段统一，不把尚未定义的分布写成已完成。

## 概率与保底保留既有基础

| 项目 | 规则 |
|---|---|
| 基础品质 | 普通60%、少见30%、稀有10% |
| 非普通保底 | 连续4次普通后，第5次至少少见；强制非普通池中少见75%、稀有25% |
| 稀有保底 | 连续9次非稀有后，第10次稀有；与前条相遇时稀有优先 |
| 保存 | 票、奖品、保底计数同一事务，先保存再亮出；跨夜、跨周、失败、读档不重置 |
| 满包 | 留机器领取箱或个人仓库，或安全使用/手动替换；不自动销毁 |

券只来自游戏内已完成回执，没有真钱购买入口。概率是沿用的设计基础；没有声称本轮已实现随机抽样器或验证真实出货分布。

## 与班前陷阱、七日清空的边界

TD05地面陷阱必须预购并在上班前布置，营业后不能新放、补弹、修复。个人道具能否在追逐中使用，沿其原有占手和世界耗时，但它们不能变成陷阱补给旁路。I07旧部署修补不作用于新R系陷阱；I06不能给R系充次数；I16及旧固定部署进入TD05模式时也需班前预置。

七日清空的是塔、陷阱、对应库存与周建造资源。个人装备、个人消耗品存量、工资券和保底继续按原战役保存。第七夜先发工资与券，再清周布防资产，不能把刚获得的券清掉。抽奖物也不兑换为可循环套利的周建造币/灵能。

下一阶段再敲定完整奖池、重复补给表、机器交互和美术；本轮先把105项遭遇的机制和结局落稳。
