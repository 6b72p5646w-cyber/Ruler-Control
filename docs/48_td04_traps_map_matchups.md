## 1. 一周保留与付费边界

标准七夜防御模式中，塔与陷阱的位置、已购分支和等级、剩余充能、当前耐久在本周各夜保留。换夜不免费补充或维修。第七夜结算后清除本周防御实例、升级、充能、耐久和本周建设资金/灵能；下一周以120建设金币和免费T02基础岗位塔重开。图鉴、方法知识等长期记录保留，此模式不暗改旧运行器的个人长期账户。

升级增加的是容量上限，当前次数不补满；耐久保持当前比例。搬动、换型、读档保留合法回执与绝对到期。全图仍最多8件、16格足迹，其中栅栏最多6格。件数和面积限制使廉价小工具、大覆盖板与耐久墙都付出实际位置代价。

## 4. 位移税与连锁电击怎样协作

真瞬移、影跃、镜穿都沿实际已提交起终点的直线审计有效伤害格：中段正长度相交格，加上实际起点和落点各自所属的半开格，合并去重；中途只擦到一个角不计格，真正端点的归属格仍计。一次真实转场在每个格只付一份，忽略这些格原有的普通冷却，然后把该格下一次普通伤害截止设为抵达世界时间+2秒。固体占位不算有效格；跨墙后另一侧已经部署的合法格仍能被审计。取消转场、零位移、重复事件都不产生新税。普通连续移动继续遵守2秒旧区冷却。有效格快照在真实抵达及显式R09付费启场后取得；抵达前已合法武装的格均可参与，不要求转场开始前就存在。

R09允许该相位审计先原子消费一次充能启动场，再结算同一事件。因此第一只纯位移敌也能触发专门的位移惩罚。虚拟连线只服务分区税和明确的过路奖励；R02夹具、R04锚钉、R16电器接触、R13持续场都要求真正的实体接触或驻留。它不会在瞬移中段替怪“走”过所有陷阱。

过载从满层种子沿所有实际合法边搜索带电敌与通电电器，能经中继连接更远单位。每个受击池按自己邻接的一跳带电池数N（含自己）与真实电器数E结算 `D×(N+E)`，基础D=2.5。电器不掉血，但能成为中继；同一电器多个面、槽、铜轨均只有一个ID。单位之间、单位与电器、以及电器之间，都要满足真实2.5格距离、适用高度与遮挡；相同电路ID不等于跨店直连。

每次实际正电伤继续叠层：设备接触4伤给1层，普通一跳3伤也给1层，可使接收者满层进入后续过载。一次过载消费5层，对m个实际受伤池分别回填`min(1,2/m)`，总量不超过2；反馈的D贡献继承本波并衰减为0.75倍。这样链条会真的续发，闭合电网也会耗散停止。铜轨延伸接触联合域，不扩大电网边长或局部E计数半径。

R04/R05/R06封下一跳，能降低危险但也减少下一次位移税；R10/R11把怪引过新区或真实电器边界，可能减少其在小火场的停留。这些是玩家能看懂的主动取舍，不把所有控制都设计成与所有输出无条件同向增益。

T10.B2预约截停另有明确到达控制：公开预告落点提前武装且目标真实到达合法可控高度，落格8伤替代3，并申请普通1秒/精英0.6秒束缚固定位置；遵守共享硬控预算、抗控和每目标8秒门槛。其价值是立刻延长本次落点火力窗口，不是只封本来仍在长冷却中的下一次瞬移。R04等封下一跳工具仍保留自己的能力规则。
