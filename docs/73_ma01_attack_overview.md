# MA01：105只怪物的攻击设计

本轮基于EQ01主分支 `6445d758b9d1b63afad0afb7d75bc422e0d900a6`，为既有105条怪物/异常补齐攻击层。主机制原物与成功条件、三种结局、HP、物防、灵防、原移动方式和子体总预算沿原目录；攻击准入与衔接时序的明确修订写在逐卡覆盖中，包括F03的等待适配与F47的非战斗例外。仍为设计与有限参考模型，没有启用完整AI或制作美术。

## 设计目的

追逐把玩家从工作位逼走，攻击让玩家读出不同应对：侧移躲直冲、利用货架遮束、绕开已发亮的危险体表、投石打断长仪式、被丝带命中后主动挣脱。不同攻击也产生不同塔窗口：狙击抓收招、持续场抓驻留、积毒抓长战、群咒减压、电系利用真实聚群、跨区惩罚真实冲刺与转场。

每只怪都检查“攻击前能看懂什么、哪里会伤人、命中/落空后做什么、完成本怪机制后哪一招失效”。不会因为名字里有影、镜、飞，就擅自增加瞬移、独立生命池或穿墙权限。

## 一个必要例外

F47水歌伊阿拉沿原自愿封袋竞赛：未接受可拒绝，失手只停止后续加码，不新增SAN处罚。MA01明确它不准入攻击；保留原规则离场与真实委托结算，仍占导演名额。S27/S32仅子体攻击、F14停用人类宿主战斗也继续保持。

## 统一节拍

追逐/原行为→公开预告→提交→实际伤害体积→收招→重新追逐。基础预告至少1.5秒，保留原更长预告；F12/F13保留3秒基础周期。伤害是现有直接SAN损失，普通多为8–14、精英可到18，子体保留原较低值。

同一攻击的冲刺身体、长肢、射线帧、连段、反射与残留区共用攻击ID，最多有效命中一次。所有怪共用玩家2秒受击保护；保护挡伤时也挡新缠绕，但该次几何接触不能算“完美躲避”。

普通追逐接触仍不伤人。只有明确预告、发亮且有截止时间的危险体表会造成接触伤害。随体体积是显式例外；冲刺、射线、落点和连段仍按预告锁定几何。
