# TD05：八行为、少怪电链与七夜库存调校结果

2026-11-19。本版主检查 **718 项通过、0 项失败**。结果来自 [check_td05_balance.py](../scripts/check_td05_balance.py) 及其明确范围内的参考模型；完整输入哈希、轨迹、终态、库存与逐项结果见 [td05_balance_report.json](td05_balance_report.json)。检查数量不代表实战场数，当前参数未接入 V0.10 运行器。

## 1. 本轮怎样避免误判

电击的主调校先放一只、两只有限生命目标，再引入提前死亡、断桥、停电和群体。180、45、360等生命值是明确标注的校准靶体，并不是声称当前60怪已经全部实装了这些生命值。电击报告把实际扣血与溢出伤害分开，下一波只读仍活着的图。

狙击、毒、烧伤和持续场另保留8/24/60秒的名义积分，方便看短长窗差别；这部分不冒充追逐AI或实际击杀时间。控制看真实时间窗、攻击提交和期望减伤；区域看实际有效格/驻留；全70节点分别保留合适指标，不要求所有塔同DPS。

## 4. 易感的层数、效力与等待请求

已有7热时合法获得易感，立即消费7个真实印记产生一次烧伤，没有新造印记；七个同源2DPS/25%印记仍给2DPS/25%，不按7/8降威力。三份25%与四份15%来源得到约19.286%混合易伤。

已有3咒时易感触发厄运，基础减攻击仍仅12%，真实第4咒才到16%；重复易感不会绕过8秒触发间隔。已有3寒也按新阈值请求冻结，但在尝试冷却中再来的寒意不储存出立即连冻。毒没有爆发阈值。

4电池在易感下可以准备，若结算前易感过期则不能发波；补第5电后按新请求发波。易感一直有效时4电正常消费，D仍6。过期不取消此前已支付完成的烧伤/冻结。

## 5. 面积补偿与追逐验证

12个货架/柜台真实挂点，以名义半径1、参考身体半径0.3测量：原有效中心域约1.9675格²；11处扩到1.30、1处扩到1.325，达到约3.105–3.1725格²，即名义π面积的98.8%–101.0%。无遮挡r1仍r1；可达狭道在1.5倍上限仍不足时拒绝投影；墙后和不可达区域不计入。不同实际体型、动态障碍与客户端碰撞仍待实现验证。

追逐模块220项通过。玩家3.0，普通怪3.3，从6格到1.2格起手距离16秒；沉重3.24为20秒，敏捷3.45约10.67秒。一次真实纸偶阻挡1秒延至27秒；两层冰持续6秒延至26.56秒。理想每6秒都能成功阻挡的均速2.75是玩家布防收益，允许形成局部安全线，不后台提速抹掉。

F46特别保留4秒节点停留，不为凑通用均速而扩大跳距；破解后进入预先定义的1.2格/秒实体步态，不奖励敌人3.3的追逐升级。F10/F54锚定例外、F14关闭、F60无镜穿、同池部位不增数量均保留。详见[60条对应表](55_td05_chase_monsters.md)。

现有地图579个室内可达格心，在单个锁定1.5半径危险圆、身体0.3、默认门且无新路障/其他怪的参考中均有2格四向脱圈路，所需约0.667秒，小于1.5秒预告。这里只验证这一几何余量，没有宣称所有双怪夹击或实机输入均已通过。
