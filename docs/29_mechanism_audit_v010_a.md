# V0.10 机制闭环复核 A：F01—F30

## 结论与边界

本文件只完成第一步现有民俗遭遇机制收口，不加入或研究 SCP。F01—F30 的实际来源、免费可行操作、失误后原物恢复、到期分支、预约与清理均已在 [有限动作片段](../content/mechanism_cases_v010_a.json) 给出可执行的状态与动作。不能再用“已能生成怪物”代替“玩家能把这次遭遇处理完”。

这仍是设计合同与有限模型证据。四邻接地图上的行程、离散动作和局部计时已有验证；除了既有 F12/F13 世界切片，新增卡没有因这份文件就成为已交付的微信客户端。所有正式 `runtime_enabled` 仍为 false，F14 的正式候选仍关闭。F12/F13 只增加附加见证，没有修改 [canonical 蓝图](../content/encounter_blueprints.json) 的字节和玩法。

## 共用规则固定下来

1. **先有物件和真实回执，再有条件。** 班前物资不是“已经做完的历史”。来客自带物只到场创建一次；伤口只来自真实危险接触；脚印/血迹只来自实际移动；已发生原销售可以跨班引用，不能用自由文字伪造。
2. **普通移动和关键取、放、开合不设体力硬门槛。** F11比赛是明示可选成本，始终有食品/未接受拒绝分支。四资源走统一时钟；旧怪物表中的整套成本不得和本片段动作再扣一遍。
3. **强制威胁没有“拒绝即清怪”。** 可选请求拒绝不领奖；F03/F05/F10/F12/F13等活动威胁最多占原阶段和下一阶段，未解除到原最大期限/真06:00是失败，不能在120秒后静默删怪。`240`以所在阶段起点为上限，绝不从晚到场再另送240秒。
4. **精细特写只收明示预算成本，世界冻住。** QTE失败/取消已开始操作仍收费一次；世界伤口、冷却、追逐不在特写后台补跑。低SAN只按统一QTE缩区/黑视，不篡改输入。F12/F13追逐关键操作仍在世界中。
5. **资源预约不等于物件传送。** 新增F05/F10真实领干布；F26如果未实际带清洁套/空袋，必须把领取路线计进≤24秒响应，否则不投放。工具/赠品/原商品还在别的容器里，释放导演锁也不抹真实位置。
6. **完成和领取分开。** F11/F23/F29安全结束后，原赠品可保留在已预约领取槽，背包满不会软锁。后置仅允许 `reward_scope` 领取/检查；同物一次，真06:00后不发起新取物。未领奖不会重新占一只主怪或阻止交班。
7. **一只主追逐者。** F03/F12/F13/F26占同一个追逐预算；水路/身份/手部等局部约束仍需共享导演检查。血源同事故只有一个消费者，不以失败刷第二只怪或奖励。

### 每卡操作、失误与结束

#### F01 狐精

**实际做什么：** 放箱离手称重 → 在打包台对照两件实际容量 → 分入已验货槽和封闭退回槽。

**可恢复的错误：** 放箱离手称重 → 未计量就把原箱送上货架 → 停售该格并取回原箱 → 在打包台对照两件实际容量 → 分入已验货槽和封闭退回槽。

**判定与到期：** 两件原物分别处于已验货槽与封闭退回槽、误上架限制已清；或同一整箱实际退还。计量不产生额外商品。 原阶段到期来客结束幻货委托，物件按当前位置挂未验/待退标志，不凭空退货或上架。未验货继续禁止销售，属于普通隔离任务；不发成功回执。

**保持好玩与控制实现量：** 识别同批两件实物、分槽与补货顺序。 两件固定货样、两个局部计量槽；不做幻术材质模拟或市场利润系统。

#### F02 画皮鬼

**实际做什么：** 手压侧灯观察双皮缘 → 核对已经发生的公开交接和当前身体 → 锁妥交接物并目送未授权者走出公开出口。
