# V0.3 修订依据

日期：2026-11-17。

## 用户新增的方向

1. 低SAN使QTE判定区域减小，并产生黑视。
2. 处理应结合便利店的真实操作；怪物提出规则，随机事件形成动作题变体。
3. 空间条件可包括不能直面、保持距离。需要考虑程序复杂度。
4. F12不可杀伊改为默认追玩家；玩家从货架拿回形针、洒地引出店外即胜利。
5. F13飞头女鬼先找库房生肉；接触后追杀玩家；玩家将生肉转入冰柜解除。
6. 先设计完便利店工作交互，再据此设计怪物规则。
7. 2D俯瞰中，部分细节可通过特写完成，需要明确交互尺度。
8. 宠物应有通用辅助和针对特定怪物的特殊作用。
9. 即时道具与店内材料应提供有效帮助，参考《躺平发育》的部署、防守与升级思路。

上述方向替代V0.2与之冲突的机制。七天固定阶段、四资源、两名员工加店长、世界志怪来源、20条店规、白天准备、抽奖和装备继续采用。

## 本轮设计决定

- 10个动作原语、16项店务、三层交互尺度、3种精细QTE与8种规则组件。
- F12/F13分别使用四个有限状态，关键取放与撒物保持大地图操作且无额外QTE。
- 12项事件到工作模板的映射案例；变体只调整明确参数，不悄悄变更胜利目标。
- 8只宠物各有通用与专属辅助，共用原有限次；新增8项固定节点部署套件，13项现有即时道具补充可操作用途。
- 编程顺序从便利店公共系统开始，首轮仅一个主动追逐者。其余58个志怪保留候选，逐项映射后再实现。
- 新增无画面JavaScript参考逻辑与边界检查，覆盖缩区、朝向、距离、两怪状态和交付原子性；未实现渲染、导航和微信适配。

以上参数、价目、宠物技能细节、设施清单与制作阶段属于本轮设计提案，不标作用户逐项审定或实机平衡结果。

## 参考作品边界

《躺平发育》官方介绍将其归为塔防，并描述点击建造、拆除、升级等操作。[GA01](../references/README.md#ga01)。本作采用“经营获得资源—布置辅助—争取工作时间—再调整准备”的思路，设施具体外观、数值和能力为原创设计，不复制现成游戏资产。
