## 1. 本轮改变了什么

TD02的烧伤与毒主要靠持续时间、频率区分，塔树也容易落入重击与连射两类。本轮把攻击投放方式、持续条件、目标关系、触发异常和空间用途分别设计，使玩家真正选择如何组织这场追逐。

塔采用严格的**L1基础→两个互斥L2特化→每个L2再选两个互斥L3**。共10塔族、20个L2、40个L3终点；每座塔当时只启用一条路线，不同时叠四个终点，也不再叠加TD02的24条I/II技能购买线。L2已经改变玩法，L3在其父路线内进一步特化。

五种异常各有职责：烧伤附易伤，毒负责长期累积掉血，寒意先减速再冻结固定，诅咒先减攻再概率失攻，电荷把真实电器与带电敌人联系起来。低频狙击、贯通直线、分目标连射、永久毒、接触感染、范围减益、小范围持续场、连续曝光、接触阻挡、推拉、移动分区与转场伏击形成不同的布阵理由。

## 3. 五种异常的共同语言

| 异常 | 建立阶段 | 触发或长期结果 | 主要价值与取舍 |
|---|---|---|---|
| 烧伤 | 8枚有效热量，每枚6秒 | 一份4秒烧伤：基础2点灵性DPS与15%易伤；特化易伤最高25% | 广域给敌群创造集中输出窗口，自身尾伤较小；同族不无限乘算 |
| 中毒 | 每次真实命中/有限装置追加毒负荷q | 原始毒DPS=0.5q，本遭遇内不自然到期、无层数硬顶 | 低频小伤转为不断增长的持续压力；起效慢，不能立即处理短命冲脸目标 |
| 寒冷/冻结 | 4枚寒意，每枚6秒、8%减速 | 冻结固定位置、朝向与当前高度，停止未提交动作 | 为狙击、小持续场与工作操作留窗口；会减少移动分区的跨区收益 |
| 诅咒/厄运 | 4枚咒印，每枚10秒、降低直接攻击伤害4% | 厄运4秒，每次真实攻击普通30%/精英20%概率失攻，8秒触发冷却 | 降低攻击压力；玩家仍要躲预告，不能把概率当必然取消 |
| 电荷/过载 | 5枚电荷，每枚8秒；有电荷即带电 | 经过合格电器放电，普通电击最多跳一次；满层按每名受击者自己的局部N+E结算 | 强调先铺标记、聚集位置与真实供电；群散或远离设备时收益降低 |

烧伤易伤与真实规则协作易伤独立分组，组内取强、组间相加，最高25%+15%=40%。本轮T06.B1提供可达的规则协作来源，所以火系收益不会被广播覆盖。永久毒读取当时防御与易伤，但毒量本身不被易伤乘大。

## 4. 攻击模式怎样产生选择

| 模式 | 玩家要创造的条件 | 不利条件 |
|---|---|---|
| 单点低频狙击 | 一个价值高、可见且能完成瞄准的目标；已知短破绽 | 诱像、多个方向的小敌、长装填时错过窗口 |
| 贯通直线 | 将不同生命池引到同一条无遮挡窄线上 | 并排分散、货架遮挡、孤立重甲 |
| 高频分目标火力 | 多个残血对象、减少大额过量伤害 | 高护甲、需要一次集中重击 |
| 永久积毒 | 多次实际命中、足够长的遭遇寿命 | 急需当场击退；新来的敌人没有旧毒投资 |
| 接触感染与遗单 | 独立生命池接近、有限传播许可或同根清理顺序 | 单体、共池部件、相隔过远 |
| 广域减益 | 较多目标将接受后续友塔伤害或攻击纸偶 | 缺少后续输出，仅靠减益塔独自收尾 |
| 小范围持续场 | 冻结、阻挡、诱饵把敌人留在小圈内 | 高频离场、真转场、场与目标高度不同 |
| 连续曝光 | 同目标真实射线维持足够时间 | 转角、反复换目标、隐相 |
| 分区移动伤 | 快速穿过多个真实有效区，或合法推拉改变路线 | 长时间停在同区；尚在冷却的旧区重复往返 |
| 转场端点/落点伏击 | 已公开的起点/终点、足够完成投影调整的预告 | 未知出口、不可选中过渡、无效高度 |
| 电器网络 | 标记敌人在真实通电设备附近形成局部邻接 | 设备停电、隔墙、目标分散或没有有效导电关系 |
| 接触与阵地协作 | 纸偶真实站位、可执行推拉、有效规则回执 | 不能阻挡/推动的形态、没有后续火力的空阵地 |

敌人的移动方式必须决定这些条件。步行、地面冲刺和推拉有真实连续路径；真瞬移、镜穿和影跃没有可虚构的中间地面轨迹。地面阵不能按高飞怪的平面投影逐格收费。空中被冻结也仍然在原高度。

## 5. 分区与电网的可读反馈

分区使用固定世界格。每只怪在每个有效格里独立记一次2秒截止：同一秒走过四个可触发格，承受四份区伤；立刻返回旧格不会再付。不同怪各有自己的记录。重叠塔对同一格取本次最强合法来源，多铺塔的主要收益是延伸路线。

界面要画出当前有效分区、该目标尚未冷却的区，以及实际转场落点。持续小场则显示明确小圈和剩余时间。两者不能都画成相同的大范围光圈，让玩家误以为效果等价。

电网显示带电标签、当前合格电器与一次跳电路线。过载预览按各目标的局部数量显示倍率，不能只给全店统一数字。第一版只有热食台、主冰柜、饮料冷柜三个已核实电器进入候选登记；收银POS需新增实体与接线，当前关闭。塔、灯带、插座和铜轨不增加电器数。

## 6. 升级、经济和设施

塔L2统一追加25币+4灵能，L3追加40币+10灵能。一条完整路线共追加65币+14灵能，再加该族L1造价；同族各路线同价，避免付费换型后出现价差套利。首台T02免费岗位资产继续保留，后续升级照付。塔仍只能装在合法设施锚点，12个可选锚点、同时最多8座，工作面和原物取放位保持可达。

白天换路线收已购买特化金币投入的20%向上取整；保持已经支付的阶段等级，立即停用旧形态。换型、移动、升级不重置攻击装填、状态截止、电网准备、区域计费、毒量、耐久比例或纸偶重组。新增加的弹仓/充能槽为空，旧充能按可继承的实际份数保留。改变纸偶数量要求旧队全部存活并离战3秒，保持全队耐久比例。

陷阱保持较短的决策树：L1→L2 A或B→对应方向L3成熟升级，每类两个最终方向。共16类、32个L2方向和32个对应L3升级。用户要求的每塔四个L3终点用于设施塔；陷阱以尺寸、位置、次数和方向选择控制操作负担。陷阱升级费用和R12按格耐久见43号文档。

金币仍来自实际完成的订单、根遭遇击退与正式交班；灵能来自根遭遇及真实破解资格。普通塔射击、毒跳、电弧和状态触发不逐次收费。子体、部件和分裂不新增无限收益；失败重开不复制正式财产。

## 7. 群体、分裂和规则破解

灰盒采用2个根遭遇槽与最多6个额外子体、全场8个敌方actor的候选上限。这个数用于控制首轮空间、输入与性能测试，不表示每次遭遇都要填满。后续提高密度需同时重测电网平方量级覆盖收益和真实可走通道。

actor负责位置与碰撞，生命池负责伤害和叠层，根遭遇负责规则事实、名额与唯一奖励。独立眷属是多个生命池；同一巨怪的几个部位共池。分裂先结完当前整批已命中伤害，非致死才分配剩余生命、永久毒、未成熟毒预算、有效层与绝对截止，不能复制一整份状态给每个孩子。

“不破解而绕圈消耗”和“破解后集中击退”继续作为两条设计要求。所有敌对怪都必须有合法受伤机会；正确处理原物与规则应真实降低追逐、攻击或移动优势，改善阵地覆盖。不能为了逼玩家使用新塔而暗加全程无敌，或见玩家选对塔就临时提高抗性。

## 8. 本轮交付边界

完整40个三级分支均给出参数、功能和短板；16陷阱给出尺寸、触发、耐久/充能与两路升级；现有60条名册保留原操作身份并重新适配。没有为凑群体而擅自给既有怪增加召唤、分裂、镜穿或电器操控能力。

独立的静态/算术检查用于排除拓扑缺项、不可达阈值、重复计费、历史毒复制、同设备多算、状态相互覆盖等具体错误。实际移动AI、手机输入、全部命中/遮挡、完整七夜平衡和美术尚未验收。具体复现命令、已运行结果和下一轮灰盒顺序见44号文档。
