# TD02 六十种既有怪物的塔分支适配

2026-11-19。基线为`96c74f2`。本表只为已核实的F01–F60增加塔适配，不代表60个战斗AI已实现。F14继续默认关闭。约45项SCP保持后续计划，本轮不新增编号。

推荐指满足所列条件后的效率优势，不能看见怪名就自动赋予破甲、迫降、回复或新召唤。两条不同路线至少能完成代表性灰盒：玩家先破解再集中击退，或合法基础配置硬绕消耗。

## 1. 每个分支的目标与短板

| 适合原型 | 成立条件 |

| F12 不可杀伊 | 第一枚纸夹完成永久破壳后，在后续1.5秒停食接缝期集中单发。 |

| F50 泽西恶魔 | 能打空，长射程覆盖俯冲/低空窗口，不需要把它伪判为地面。 |

|---|---|

F48为河海豚化人客，不能误写成河豚。F01的R07只破甲，不提供留人控制。F21的打断仍受公共预算。T04B是长时间同目标曝光，未经主要规则限制转场的短窗瞬移怪不属于无条件优势对象。T05B投签需要购买且只有2.5格，不赋予空中阻挡。T03A/B默认只地面，低空必须经R03在合法地面迫降才接地面伤害。

## 4. 数量多时的预留边界

后期最多2个根遭遇槽、6个额外子体，全场敌方actor不超过8；每根最多3个子体在场、累计最多6个新子体。这是待灰盒校准的上限，不是每场固定数量。分裂、独立眷属和共血部位必须分别登记。F08旧工具、F51织影、F59工队等可作为未来取材方向，此处不新增它们的变体能力或触发来源。

AOE按health_pool_id去重，独立子体可各受一次伤害，共血部位只扣一次；root_encounter_id仅管槽位、规则事实和奖励。母体退出后的清理依依附/独立/分裂关系处理，不能一律凭空消失。
