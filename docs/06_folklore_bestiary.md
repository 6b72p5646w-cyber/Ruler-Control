# 60 个志怪原型与便利店交互

**V0.1 的 M01—M60 已全部撤回；本表使用新的 F01—F60。** 60 项是设计候选，F14 附身分支默认关闭，因此当前默认候选池为 59 项。它不应偷偷混入普通假扮事件。

“怪物”是内容分类称呼，来访者可敌对、可交易、可协助，不能把所有地区的守护传统都改成无差别杀人者。角色以普通顾客身份出现时，先按行为和客观证据判断。

每条分开记述原型资料与本作改编。店内的解法、弱点、数值和证据设计都不声称是传统禁忌。不同变体的来源强度写在各条末尾；来源列表见 [资料目录](../references/README.md)。
