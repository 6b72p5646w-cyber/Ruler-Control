# V0.2 验证记录

日期：2026-11-17。

## 已完成

- 新内容库为60个志怪候选、72项事件、20条店规、24个临时道具、24件装备、8个宠物方案和18组联动案例。
- 资料库登记57条民俗来源与2条影视官方来源。所有怪物均有来源引用、至少两项可观察证据、主要交互、保守应对及加难和减难条件。
- 七天使用一套日夜阶段；事件已明确允许时段、处理预算、截止点及工作计入方式。百鬼夜行的120秒流程包括实际工作，不能自动清任务或延长夜班。
- 四资源的职责、岗位免费饭食、抽奖保底跨周、装备实际占手、宠物主动次数及照料费用已对齐文档与配置。
- 同事与店长的假扮、真实身份、玩家证据和权限分开。人员异常事件只绑定已获准F实例，不能绕过实体上限另生成一个怪物。
- 移除封签万能认证；拆分过于相似的怪物解法；将未食用食物的支出改为扣库存；F14附身默认关闭。
- 本地 `python3 scripts/validate_content.py` 通过，检查编号、来源与联动引用、配置不变量、阶段预算、抽奖权重和内部文档链接。

## 尚未验证

当前仓库交付设计与内容数据，未实现游戏客户端，因此没有进行微信实机运行、触控体验、帧率、随机调度仿真或数值平衡测试。文本中的秒数、收益、阈值和价格均是原型提案。

校验脚本能发现悬空引用、概率总和错误和已声明的结构冲突，不能证明所有怪物组合一定有解。导演实现后需要基于真实动作耗时、可达区域和资源状态检查可解性；手机试玩再决定体验是否成立。

## 复现

在仓库根目录执行：

```sh
python3 scripts/validate_content.py
```

脚本只使用Python标准库，成功时输出 `status: PASS` 及内容数量；失败返回非零退出码并列出问题。它不联网、不修改设计内容，也不会操作GitHub。
