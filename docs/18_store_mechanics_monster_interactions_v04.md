# Ruler-Control 便利店玩法机制与怪物交互设计

2026-11-18 · 基于 V0.4（main 分支提交 5b6dcd8）

> 本文是审查意见与设计建议，不改动 `content/` 数据和代码。它建立在[怪物规则与地图适配审查](16_review_rules_maps_v04.md)（下称“审查”）和[怪物预告线索与交互规则优化](17_omen_system_proposal_v04.md)（下称“预兆提案”）之上：预兆三段、可信度三档、违规阶梯和七态机沿用，不重写。

## 结论

把便利店当成规则怪谈的“舞台”来设计，而不是工作模拟。真实店务压缩成几个按住即完成的工单点，省下的复杂度全部用在门、灯、水、声、镜、纸、人这七类会被怪物利用的东西上；玩家每小时在“守住安全格”和“出去做店务、接客单”之间取舍，再用实物核验去判断哪条规则、哪个人此刻能信。怪物按原型挂到店里的某一套系统上，每只只用一句禁令和一个关键动作，全部可用十个族群模板加通用状态机表达。

全部是设计提案，数值待实机调参；标“本作原创”的是游戏改编，不是民俗原文。

## 八条关键决定

1. **店务抽象成工单点。** 每小时一张主店务卡，拆成2–3个“走到那里按住2–4秒”的工单点；扫码对准、找零计算、配方顺序等真实流程全部删掉，只有规则需要时（称重、核验）才进特写。店务存在的理由是把玩家拉出安全格、拉到怪物的地盘。
2. **夜班只盯四样：理智、电、店务进度、违规灯。** 精力和饱腹留在白天层，只决定当夜体力上限和理智恢复；夜里不再管理吃饭。
3. **电是一夜共用的一池，12格。** 快照、锁门、核验侧灯、强冷都从这里扣；可以“借冷链的电”换3格，代价是冷链损耗。预兆提案里“每夜12格”和“每小时12点”两种写法统一为每夜一池。
4. **营业状态是第一号取舍。** 正门有营业、暂停、上锁三态。暂停能挡住所有“以顾客身份进门”的怪，但每30秒少一单；一夜要完成8单合法交易。上锁再挡门外，耗2格电。
5. **安全格看得见，但不能久待。** 柜台内侧（加活板门）、员工室、干格各挡一部分族群；店务都在安全格外，主店务未完成的小时会留下“店务债”。
6. **日常就是基准。** 每周4位熟客，固定时间、固定商品、一个整格可读的外貌特征和一句口头禅；冒名者只能学其中三样。开班时自动存一套“正常店”快照，小异常靠和它对比发现。
7. **文字分四层可信度，并写出“第0条”。** 店规墙和盖章工单永真；前任笔记永真但只写禁令；今夜的手写便签可能是假的；人说的话最不可信。冲突时按“实物 > 笔记 > 店规 > 工单 > 手写 > 人言”裁决，这条直接印在店规墙顶上。
8. **不是所有怪都要防。** 家宅精灵、契约类和报信者处理对了会给回报（店运、代做杂务、库存保护、电量）；把它们当威胁去驱赶，回报没了还扣理智。认怪的意义从“怎么挡”扩展到“该不该挡”。

## 一、设计原则：店是舞台，不是模拟

**三层结构。** 日常层是熟悉的店、熟客和店务，给玩家一个“正常长什么样”的基准；异常层是预兆和怪物，偏离基准的地方就是线索；规则层是禁令、店规和便签，告诉玩家能做什么，但其中一部分可能是假的。三层都要在同一张地图、同一套物件上发生。

**一物三用检验。** 地图上每个可交互物件至少满足下面一条，否则删掉或降为装饰：

- 制造诱惑或本能反应（门外叫名、催你去后院、空椅子、坐下休息）。
- 提供核验（秤、快照、排班表、温度条、示踪粉）。
- 制造取舍（耗电、占时间、挡客单、占用同事）。

**真实流程删减表。** 用户的方向是“方便规则怪谈的游玩”，所以下面这些真实流程降级或删除：

| 真实流程 | 现设计（V0.3/V0.4） | 本文改为 | 理由 |
|---|---|---|---|
| 扫码结账 | 特写对准 QTE | 站收银位按住1.5秒；只有交易型怪才进特写 | 结账是噪声和客单来源，不是挑战 |
| 现金找零 | 现金与找零工作 W02 | 删除；只有图尤尔等以零钱为题的怪带出“找零袋” | 算钱和规则无关 |
| 验收称重 | 每次到货都称 | 普通到货按住即收；狐精、海亡灵、鲛人才要离手过秤 | 让“该不该称”成为判断 |
| 补货 | 搬箱、上架、逐格 | 一张卡2–3个货架点，每点按住3秒 | 保留“走到货架间”的位置意义 |
| 热食制作 | 2–3步配方特写 | 热食台按住3秒出一份 | 雪女、托姆特、雾笛需要“有一份热食”，不需要配方 |
| 垃圾封袋与外运 | 两项工作 | 合成一张卡：封袋点＋后院投放点 | 保留“必须开后门、去后院”这个风险 |
| 盘点批次记录 | 面板工作 | 改成“异常巡检”：对照基准快照报告变化 | 把盘点变成规则怪谈里的找不同 |

保留并放大的是：门的开合、灯的回路、水的连通、声音的开关、镜子与监控、纸面文字、人的身份。

## 二、核心循环

### 2.1 一周与一夜

沿用仓库的日夜表：一周7夜；22:00–24:00 验岗（读天气、店长工单、交接本，选装备）；00:00–06:00 六个游戏小时，每小时120秒；06:00 交班结算。白天六个行动格不在本文范围，只通过“带进夜班的东西”影响夜里（见 3.5）。

### 2.2 六个小时的节奏曲线

每小时的主店务决定玩家被拉到哪里，也就决定了这小时最适合出哪类怪。导演按这个对应关系选怪，等于给每只怪一个“主店务”，顺带解决审查 D4（卡片没有出现时段）。

| 时段 | 主店务卡 | 把玩家拉到 | 适合的族群 | 情绪 |
|---|---|---|---|---|
| 00–01 | 开班收银与交接 | 柜台、正门、核验台 | 门槛诱离、冒名、交易 | 熟悉，教学，不追人 |
| 01–02 | 验货补货 | 库房、后门、货架间 | 交易计量、冒名送货、第一只追逐 | 上升 |
| 02–03 | 热食冷链 | 热食台、冰柜、水槽 | 水系、契约、家宅（灶与粥）、生肉追逐 | 复杂，好怪可能出现 |
| 03–04 | 清洁与倒垃圾 | 湿区、后门、后院 | 水系、追逐、声音、火蛇 | 最深夜，压力峰值，假兆最多 |
| 04–05 | 盘点与异常巡检 | 货架、失物柜、员工区 | 寻物、家宅、契约、冒名（记录） | 喘息，回收理智的机会 |
| 05–06 | 结账交班 | 柜台、员工区、休息椅 | 冒名交接、天亮诱导、休息 | 疲惫，诱你提前收工 |

第1–2夜每夜4只主怪，另外两小时只有异常巡检和小事件；第3夜起5只；第5夜起6只并开始重叠（见 7.5）。

### 2.3 一小时120秒

| 秒 | 发生什么 | 玩家在做什么 |
|---|---|---|
| 0–20 | 发本小时店务卡和2位客人；上一只怪善后收尾 | 规划路线，补上小时的店务债 |
| 20 | 本小时主怪到场（T0）；远兆和近兆已在上一小时末给完 | 站到安全格或继续店务 |
| 20–90 | 对峙：守禁令、做关键动作；店务和客单照常 | 在安全格和工单点之间来回 |
| 80–120 | 下一只怪的远兆（第80秒）和近兆（第95秒）开始 | 一边收尾，一边勾交接本、花电做准备 |

开班00:00那只怪的预兆放在22:00–24:00验岗里（预兆提案 2.1）。

### 2.4 玩家的五个动词

看（巡检、快照、凸面镜）→ 判（在交接本勾预兆、核便签、对熟客卡）→ 备（花电和时间押一项准备）→ 守（守禁令、做关键动作、该暂停就暂停）→ 结（交班时写下今夜的怪名和异常）。所有怪物交互都落在这五个动词里，玩家不需要为每只怪学一套新操作。

## 三、资源

### 3.1 夜班 HUD 上只有四样

| 资源 | 范围 | 用途 | 怎么减少 | 怎么回来 |
|---|---|---|---|---|
| 理智 SAN | 0–100 | 发作门槛：低于某只怪的阈值且原型条件成立就会发作；低理智缩小特写判定区、加黑视 | 预兆−1、违规警告−3、发作−8、被催促−1 | 熟客寒暄+2（每人每夜一次）、认对怪+5、员工室短休+6、定心茶+20、好怪回报 |
| 电 | 每夜12格 | 快照、锁门、核验侧灯、强冷 | 见 3.2 | 借冷链电+3、换备用电池+3、芭芭雅嘎回报 |
| 店务进度 | 本小时主店务卡 | 完成才算本小时合格 | 被怪打断、绕路 | 同事代做、布朗尼代做 |
| 违规灯 | 3盏 | 第1次警告、第2次发作、第3次安全撤班（预兆提案 2.5） | 触犯禁令 | 不回复，按夜重置 |

体力只在冲刺、搬重物时出现在角色脚下，不常驻 HUD。

### 3.2 电：一夜一池

| 用途 | 耗电 | 备注 |
|---|---|---|
| 监控快照（员工室采集） | 1 | 采集是1秒世界动作；之后在核验台只读终端看图不耗电 |
| 锁一扇门 | 2 | 维持到本小时结束；暂停营业不耗电 |
| 核验侧灯 | 1/小时 | 画皮鬼、阿斯旺等现形；雪女避开亮处 |
| 冷柜强冷 | 1 | 飞头女鬼、冷链事件 |
| 保温柜 | 1 | 雪女、雾笛 |
| 广播、门铃、应急灯棒 | 0 | 广播和门铃本身是规则元素，开关免费 |

- **借冷链电：** 配电位一键把 C2 冷链热食回路切给前场，立得3格；冷链停30秒，本小时冷链商品损耗（营业额−10），飞头女鬼的肉箱升温更快。每夜一次。
- **电量见底：** 电≤3格时 HUD 变红；0格时前场 C1 降为应急档，黑视半径−1格，标“喜暗”的怪发作阈值+10。
- 一夜大约能做6–8次有用的准备，不够每只都双保险，这正是取舍的来源。

### 3.3 理智：门票，不只是血条

沿用预兆提案的个性化阈值（默认50，激进型55–60，害羞型35–45）：理智高时，大多数怪只有你触犯禁令才发作；理智低了，怪自己的原型条件成立就会发作。所以“保理智”等于“扩大犯错空间”。

两条新恢复途径专门服务规则怪谈的情绪：熟客寒暄（真人的温度对抗异常）和认对怪（理解让人安心）。员工室短休是第三条，但05时段马拉和托科洛舍正好守在休息椅上。

### 3.4 时间与店务债

本小时主店务没做完，剩余工单点变成“店务债”，下一小时开场多一张卡。连续第二次欠债，当夜评级降一档、工资−20。这样龟缩在安全格不是免费的，但一次失手也能补回来。

### 3.5 白天资源怎样进入夜班

| 白天资源 | 进入夜班的方式 |
|---|---|
| 精力 | 决定当夜体力上限（沿用 `50 + 0.5 × 精力`）；精力低于25，搬重物更慢 |
| 饱腹 | 低于25时，夜里所有理智恢复减半 |
| 工资币 | 白天买消耗品、装备、店铺加装申请 |
| 学习与图鉴 | 决定开局手上有哪些禁令页和预兆提示 |

### 3.6 客单与营业状态

每小时约2位普通客，一夜12单，完成8单合法交易才算完成夜班（沿用 balance.json）。正门三态：

| 状态 | 谁能进 | 代价 | 挡住什么 |
|---|---|---|---|
| 营业 | 所有人；自动门说“欢迎光临” | 无 | 无 |
| 暂停（翻牌） | 没人能进，门外客人等15秒后离开；服务窗仍可交易但每单慢2秒 | 每30秒约少1单 | 所有以顾客身份进门的怪；关闭迎宾语音 |
| 上锁 | 没人能进出 | 2格电；本小时不能走正门 | 门外怪的推门、撞门 |

暂停营业对门外叫名的古尔无效（它本来不进门），对借顾客外壳进门的怪有效。这让“该不该暂停”成为判断题，而不是万能答案。

### 4.3 水：三片湿区

审查 J6 指出水怪都挤在后院一条带上。改为三片互不连通的湿区，各配一个“断开”手段，分给不同的水怪：

| 湿区 | 范围 | 断开手段 | 主要住客 |
|---|---|---|---|
| A 前门门槛 | (13–17, 28–30) | 门垫+拖把位（只能擦，不能断源） | 鲁萨尔卡、哭泣女、凯尔皮的交接格 |
| B 冷链水槽 | (26–29, 10–13)，水槽与水阀分到两格 | 店内水阀 (28.5, 11.5) | 河童、诺肯、伊阿拉 |
| C 后院沟 | (23–30, −6 至 1) | 后门排水拉杆（ATT12/ATT15） | 海坊主、塔尼瓦、凯尔皮 |
| 椅下短湿线 | 休息椅南侧 (1–3, 7–8)（避开班表位，审查 D7） | 拖把擦断 | 托科洛舍 |

湿格是格子状态，不做流体模拟。关水阀会让水槽不能用，清洁和热食类店务要先做或改用净水瓶，这本身就是取舍。

### 5.4 伪装载体

| 外壳 | 能伪造 | 伪造不了 | 核验工具 |
|---|---|---|---|
| 普通顾客 | 外貌、口头话 | 实物痕迹（湿脚印、爪印、无影） | 示踪粉、偏振灯、交接垫 |
| 熟客 | 外貌、所买商品 | 四项基准里至少一项 | 熟客卡 |
| 同事 | 外貌、声音、工牌 | 排班表上的位置、私人口令、同一时刻的快照 | 只读终端、口令 |
| 店长电话 | 声音、语气、来电号码 | 工单印章 | 工单夹、回拨 |
| 手写便签 | 署名、近似字迹 | 写入时间、作者此刻是否在班 | 快照时间戳、排班表 |
| 物件与货箱 | 外观、标签 | 重量、容量、温度 | 秤、量杯、温度条 |

规则：实物和快照永远为真（预兆提案 2.3），所以每种外壳都至少留一个实物破绽。

### 5.5 店况基准与异常巡检

开班时系统自动存一套5个摄像区的“正常店”快照。夜里导演每小时可在8个巡检位放0–2个小异常（价签变了、钟慢了、冷柜灯变色、门垫朝向反了、失物柜门开着）。玩家在交接本上报“哪个区、什么类型”，2秒：

- 报对：理智+1，交班奖金+2。
- 报错：理智−1。
- 漏报累计3个：“店在不安”，下一只怪的近兆缩短10秒。

很多小异常同时是“物”类预兆，所以巡检既是04时段的主店务，也是全夜的情报来源。这一层直接借《8番出口》和《I'm on Observation Duty》的“记住正常、找出不对”，内容成本低。

## 六、店规与守则的呈现

### 6.1 四层文字

| 层 | 载体 | 可信度 | 写什么 |
|---|---|---|---|
| 1 | 店规墙 H01–H20、盖章的店长工单 | 永真 | 措辞像普通员工守则；工单每夜附一条“今夜补充守则” |
| 2 | 前任笔记 | 永真，但只有一句 | 每只怪一句禁令，不解释原因；初见的怪在近兆时自动翻到它那一页 |
| 3 | 交接本、便签板 | 今夜写的可能是假的 | 同事留言、交接事项；冒名类怪会在这里写字 |
| 4 | 人言（当面、电话、广播） | 最低 | 顾客传言、店长来电、同事口头话 |

前任笔记的作者是谁可以作为跨周的主线谜题；规则契约很简单：假的只会出现在第3、4层。

### 6.2 第0条：冲突时听谁

店规墙顶上印一行：“两条要求冲突时，先信亲眼看到的东西；墙上的字高于任何人说的话。”完整顺序：

实物（快照、秤、温度条、痕迹）＞ 前任笔记的禁令 ＞ 店规墙 ＞ 盖章工单 ＞ 今夜的手写字 ＞ 人说的话

故意设计的冲突（让玩家用第0条裁决）：

| 冲突 | 表面矛盾 | 正确做法 |
|---|---|---|
| H01“柜台要有人” × 吸血鬼禁令 | 流血的同事是唯一能守柜台的人 | 禁令优先；H01 本身允许暂停入店 |
| H13“熟悉的话先确认是谁在说” × 古尔催你出门 | 来电号码显示是店长 | 查工单夹：没有盖章工单就不算 |
| 店长工单“今夜后门锁坏，走侧巷倒垃圾” × 图恩达便签“去后院帮我” | 都让你去外面 | 工单有印章，便签没有；侧巷是工单写明的路线，后院不是 |
| H20“交了账与钥匙才下班” × 假陈姨“天亮了可以走了” | 熟客说的话很像真的 | H02 只认本班的钟；人言最低 |

### 6.3 假便签怎么做

便签是一个实体：`{claimed_author, true_author, written_at, location, content_key, flaws[]}`。每张假便签至少有一个可核的破绽：

- 署名的同事在 `written_at` 时刻不在员工桌（只读终端快照可证）。
- 写入时间晚于署名者下班或离开该区（排班表可证）。
- 内容要求“一个人去”“别告诉别人”“把钥匙放在……”，这类措辞本身就是可疑信号，但不作为唯一证据。

第1–2夜只出现真便签；第3夜起每夜最多一张假便签；交班时识破的假便签进入图鉴，解锁“笔迹样本”，以后核验少一步。

### 6.4 今夜补充守则

借《Papers, Please》每天加一条规则的做法：每夜店长工单附一条补充守则，例如“今夜只收现金”“后门锁坏，倒垃圾走侧巷”“冷柜维修，生肉放备用冷柜”。它改变当夜的基准，也给冒名类怪一个伪造对象：没有印章的“补充守则”就是假的。

### 6.5 界面

规则本是屏幕侧栏，三个页签：店规、笔记、交接本。打开时世界不冻结（审查 R4），角色原地停下，推理本身也花时间。人言气泡带头像、来源标（当面/电话/便签）和“未核实”角标，核验通过才变绿（预兆提案 2.6）。

### 7.4 跨夜成长

- **图鉴四层：** 见到→禁令页；认对一次→三条预兆全显；白天研究一格→关键动作提示和“错误准备”提醒；达成好结局→解锁驱离、协商或救助等替代结局。
- **店铺加装：** 每周用营业额向店长申请2–3项，每项改变一个决定，而不是加数值：前门第二水阀（湿区 A 可以断源）、门铃提醒器常驻、电池扩容+2、凸面镜帘轨、柜台防护垫、第二台只读终端（放员工通道口）。
- **装备和宠物绑定预兆标签：** 建议把宠物能力统一成“对某一类预兆提前或放大”，例如猫对“镜·影”提前5秒、犬对门外声音、壁虎对湿痕；宠物仍不能单独证明身份（店规 H18）。
- **同事信任：** 信任高，可以把更危险的店务交给他，私人口令也更难被偷听；冤枉真同事（未核验就驱赶）会掉信任。
- **周目：** 新一周换主题怪池和一位熟客，店规墙不变，前任笔记多一页剧情。

### 8.2 每只怪的五个槽

1. **挂点：** 它劫持哪张店务卡或哪个物件（决定出现时段和地图锚点）。
2. **外壳：** 以什么身份出现（无、顾客、熟客、同事、店长电话、便签、物件）。
3. **禁令：** 一句“不要做什么”，禁本能。
4. **关键动作：** 一个，用通用动词和店里已有物件完成。
5. **回报与后果：** 处理好给什么，处理错（含“当成威胁去驱赶”）付什么。

### 8.3 五条约束

- 关键动作只用店里已有的物件和十个基础动词，不为单只怪做专属小游戏。
- 至少一个免费解（不花电、不靠抽奖和宠物），保留仓库的公平契约。
- 关键锚点之间的路程不超过该小时的路线预留（审查 J5、D10）。
- 每只至少一条实物预兆和一个实物破绽。
- 认对有奖励，认错不立即失败，只是准备白花。

## 九、代表怪完整设计（14只）

挑选原则：覆盖十个族群，包含预兆提案切片里的8只，再补家宅、寻物、休息、视线和“假便签”各一只。预兆三条见预兆提案，这里写的是它们怎样用店铺机制。

### F37 古尔（门槛诱离）

- **原型取材：** 伪装熟人，夜里叫出住户名字，再一步步后退，把应声的人引离屋子。
- **时段与挂点：** 00 开班收银。它把“门外交接”这件日常事变成陷阱。外壳：门外声音和店长电话。
- **交互过程：** 呼唤（门外叫你的名字，电话里“店长”让你出门拿忘带的工单）→ 后退（你每朝门走1格，声源后退2格，交接点越拉越远）→ 收场（你把东西放上交接垫并留回执，它无人可引，离开）。
- **禁令：** 门外有人叫你名字，不要应，也不要朝声音走一步。
- **关键动作：** 物品和回执放交接垫（放置）。
- **发作：** 点了回应气泡，或越过正门内侧安全线；理智阈值55。发作：门槛现形，理智−8，本小时前门交接作废。
- **店铺博弈：** 暂停营业对它无效还丢客单；锁门白花2格电；查工单夹就知道“店长”没发过工单。你躲在柜台里，它每10秒叫一次，理智−1，所以拖不得。
- **回报：** 认对理智+5；整小时没应声，图鉴解锁“叫名类”通用提示。
- **逐夜变化：** 第3夜起模仿熟客的口头禅；第5夜起来电显示真店长号码，只有印章能证明。
- **实现：** 门槛模板 CALL→LURE→LEAVE；条件词 answered、crossed(front_line)、item_placed(OS01)、receipt_exists。

### F02 画皮鬼（冒名同事）

- **原型取材：** 以画皮伪装成人，能换成不同年龄身份。
- **时段与挂点：** 05 交班或 00 开班。外壳：同事；第3夜起也可扮熟客。
- **交互过程：** 换装（员工柜少一件围裙，水槽边一摊颜料水）→ 入场（门口进来“同事”：“我回来了，你去休息吧”）→ 待核（你冻结它的高权限，它在访客区等，每15秒催一次，理智−1）→ 核验（侧灯下特写看双层轮廓＋只读终端看到同一时刻真同事在库房，两样独立证据）→ 收场（围裙交给真同事，冒名者留在访客区，天亮前离开）。
- **禁令：** 没在灯下看清的同事，不要把围裙和钥匙交给他。
- **关键动作：** 核验侧灯下特写查看。
- **发作：** 侧灯关着完成交接；阈值50。发作：拿钥匙进员工区，本小时库房店务作废，员工柜丢一件装备（当夜）。
- **店铺博弈：** 侧灯和快照都吃电；扮熟客时，熟客卡四项里错一项（例如老周的表戴在左手）；示踪粉是错误准备，它的脚印正常。
- **回报：** 认对且没冤枉真同事，同事信任上升。
- **实现：** 冒名模板 PRESENT→PENDING→VERIFY；evidence_count_ge(actor, 2)、light_on(verify_lamp)、handed(apron, actor)、regular_trait_mismatch。

### F43 图恩达（门槛诱离，假便签）

- **原型取材：** 化作亲近的人，引人远离熟悉的地方；所选版本有一只木足，变不了。
- **时段与挂点：** 03 倒垃圾。后院本来就要去，这正是陷阱所在。外壳：手写便签＋同事背影。
- **交互过程：** 便签（交接本出现“同事”手写：“垃圾太多，你一个人来后院帮我”）→ 引离（后院快照里“同事”背影往东侧巷走）→ 收场（让它在交接垫留脚印，再对排班表）。
- **假便签破绽：** 写入时间 02:58，但排班表和快照显示这个同事 02:50–03:10 一直在收银。
- **禁令：** 便签让你一个人去后院，不要去。
- **关键动作：** 和真同事一起去（指派同行），或在它到场前就把垃圾倒完（准备），或交接垫撒粉核验。
- **发作：** 便签未核就独自进入后院；阈值50。发作：镜头跟着“同事”走向侧巷3秒，理智−8，真同事岗位空20秒。
- **店铺博弈：** 禁令和店务正面冲突。叫同事同行，柜台没人，要暂停营业丢客单；提前倒垃圾，要挤占上一小时的时间。
- **回报：** 识破便签，图鉴解锁“笔迹样本”，以后核便签少一步。
- **实现：** 便签实体；note_author_on_shift=false、with_colleague、in_zone(player, rear_yard)。

### F05 河童（水系·拖拽）

- **原型取材：** 栖于河池，把人或马拖下水；“爱吃黄瓜”的说法流传很广。
- **时段与挂点：** 02 热食冷链或 03 清洁。外壳：无；被拖的是货物。
- **交互过程：** 渗水（后院沟到库房一条湿痕连起来）→ 拖物（一个购物篮或货箱沿湿格以0.8格/秒移向水源）→ 断水或交换。
- **禁令：** 东西被拖走时，不要伸手去拽。
- **关键动作：** 关店内水阀，或铺吸水隔离垫断一格，再从干侧取回。替代解（本作改编）：在水槽边供物台放一根店里卖的黄瓜，被拖的东西会被“还”回干格。
- **发作：** 站在与水源连通的湿格上碰被拖物；阈值50。发作：拉锯，被拖向水源1.5格/秒，按住反方向3秒挣脱，理智−8。
- **店铺博弈：** 关阀后水槽不能用，清洁和热食店务要先做或改用净水瓶；关阀会妨碍诺肯的找源；暴雨假兆让门垫也湿。黄瓜要花营业额和一次往返。
- **回报：** 没失货＋认对，图鉴解锁“水系断开”提示；用黄瓜解决的，下次河童来时预兆多一条。
- **实现：** 水系模板 SEEP→SPREAD→DRAG；wet_connected(item, src)、valve_open、offering_on(sink_offer, cucumber)。

### F12 不可杀伊（追逐·诱饵）

- **原型取材：** 吃铁，越吃越大。
- **时段与挂点：** 01 验货补货，文具架和罐头货箱。外壳：无。
- **交互过程：** 啃食（每吃一件金属，体型升一档，追速+0.1）→ 追逐（默认追玩家，2.3格/秒；你手里有金属时2.7）→ 引出（逐点撒回形针，引出正门外）→ 离开。
- **禁令：** 它追你时，手里不要拿铁器。
- **关键动作：** 撒回形针（放置）。
- **店铺博弈：** 补货卡里的罐头箱带“金属”标签，先补非金属货就能避开；收银钱箱要锁进柜。体型到第3档时挤不过货架间缝，只能绕外圈，货架环路成了你的掩护。预锁后门是错误准备，它会把门啃坏。
- **回报：** 引出时金属损失少于3件，营业额不扣；认对加工资。
- **实现：** 追逐模板 STALK→CHASE→LURED，已有 rule_core 原型；holding_metal、decoy_emit、size_stage。

### F32 夜返吸血鬼（追逐·门槛）

- **原型取材：** 死者夜里返回侵扰生人，一些传统强调取血。“没被邀请就进不了屋”在后世叙事里很常见，本作采用。
- **时段与挂点：** 02 热食冷链：热食台小事故让同事划伤。外壳：门口一位不进来也不走的苍白客人。
- **交互过程：** 受伤（同事头上常驻伤口图标）→ 守门（它站在门外朝伤者方向，等自动门对它说“欢迎光临”）→ 包扎（伤口处理好，它失去目标，离开）。
- **禁令（建议改写）：** 门口站着不进来的客人，不要让门对他说“欢迎光临”。预兆提案原写“流血的人不要守收银台”，这里改成邀请型，因为迎宾语音是便利店独有的“邀请”，更像规则怪谈；流血改为发作条件。
- **关键动作：** 正门切到暂停（关掉迎宾语音），给伤者贴急救贴。
- **发作：** 被“邀请”进门且店里有人流血；阈值50。发作：追伤者，你要把同事带进柜台活板门内。
- **店铺博弈：** 暂停营业丢客单；包扎要走到热食台；如果同事是报丧女妖点名的人，两只怪会连锁。
- **回报：** 无损送走，同事信任上升。
- **实现：** 追逐模板加门槛前置态 WAIT_INVITE；greeting_on(front)、bleeding(actor)、counter_gate_closed。

### F42 哨声亡灵（声音预警·反向）

- **原型取材：** 边走边吹哨的游魂；哨声听来远时实际近，听来近时实际远。
- **时段与挂点：** 03 倒垃圾（后门）或 01 卸货。外壳：无。
- **交互过程：** 循环（字幕如实写“听来远/听来近”，每段约8秒）→ 卸货窗口（“听来近”时真身在远处）→ 收场（三批卸完或它走过）。
- **禁令：** 哨声听着很远时，不要开后门。
- **关键动作：** 看卸货闸旁的机械压力牌，分批开门。
- **店铺博弈：** 倒垃圾和卸货共用后门窗口；停电时压力牌照样可读，是“读仪表不靠耳朵”的教学怪。预锁后门是错误准备，店务就做不完。

### F21 报丧女妖（声音预警·报信者）

- **原型取材：** 哭号预示特定家族成员的死亡，报信者不是施害者。
- **时段与挂点：** 02 或 03，设备最多的时段。外壳：无。

### F06 雪女（契约·保密）

### F01 狐精（交易计量）

### F07 座敷童子（家宅精灵）

- **原型取材：** 幼童形灵体，它住在哪家，哪家兴旺；离开则衰落。
- **时段与挂点：** 04 盘点，保留座和排队带。外壳：无，看不见的孩子。
- **交互过程：** 落座（保留座坐垫凭空凹陷，员工区孩童笑声，小票机多打一张儿童零食单）→ 留座（挂“保留”牌，把排队改到第二排队格）→ 陪伴（本小时不让人坐那张椅；可选把小票上的零食放上供物台）→ 留下或离开。
- **禁令：** 不要把那张空椅子让给别人坐。
- **关键动作：** 挂保留牌并改排队槽（放置、开关）。
- **违约：** 有顾客坐下，它离开：店运−1（下一夜少一单客、随机小故障+1），理智−5。不追人。
- **店铺博弈：** 熟客老周习惯坐保留座等关东煮，要在他01:10到店前挂好牌，或先把关东煮做好让他拿了就走；排队改道让结账慢一点。撒定界盐、开侧灯照它，等于把它当威胁，它会哭着离开。
- **回报：** 守满一小时且放了零食：店运+1（下一夜多一单高额客、奖券+1）；连续两夜留住，本周不出随机设备故障。
- **逐夜变化：** 后几夜它会换座（休息椅、收银台后的小凳），预兆少一条。
- **实现：** 家宅模板 SETTLE_IN→OBSERVE；seat_reserved、seated(other, FX20)、offering_on(offer_table, snack)。示例 JSON 见 11.4。

### F23 塞尔基（寻物归还）

- **原型取材：** 借海豹皮在人与海豹之间转换；故事里常有人藏起她的皮，让她回不了海。
- **时段与挂点：** 04 盘点失物柜。外壳：门外光着脚等的人；另一位认领者是普通人。
- **交互过程：** 遗落（失物柜多一件湿皮衣）→ 认领（两人来认领：一个是塞尔基，一个是藏皮的人，后者拿着一张小票）→ 核对（翻看皮衣缺口形状，问两人缺口在哪）→ 交还（皮衣放提货架中立台，留出离店通道）。
- **设计点：** 这次怪是受害者，说谎的是人。小票是纸，可以伪造；缺口只有真主人知道。
- **禁令：** 说不出皮衣缺口的人，不要把皮衣给他。
- **关键动作：** 特写翻看缺口，皮衣放中立台。
- **违约：** 交给错的人：她回不了海，店前门槛湿区整夜不干，理智−8。

### F31 马拉梦魇（休息）

### F60 马面引路者（门槛诱离·视线）

## 十一、通用状态机与条件词

### 11.1 七态加族群子态

外层沿用预兆提案的七态：DORMANT → OMEN_FAR → OMEN_NEAR → ARRIVE → ENGAGE → TRIGGERED → RESOLVED / WITHDRAWN。族群只定义 ENGAGE 里面的子态和两条出口条件：

| 族群 | ENGAGE 子态 | 进入 RESOLVED | 进入 TRIGGERED |
|---|---|---|---|
| 门槛诱离 | CALL → LURE | item_placed(OS01) 且 receipt_exists | answered 或 crossed(threshold) |
| 视线（门槛子型） | APPROACH → TURN_WARN → TURN | 转身时 curtain_closed 或未朝向 | 转身时 facing 且 in_cone |
| 冒名同事 | PRESENT → PENDING → VERIFY | evidence_count_ge(actor, 2) 且钥匙交给真身 | handed(key 或 apron, actor) 且未核验 |
| 水系 | SEEP → SPREAD → DRAG | 被拖物与水源不再连通且在干格 | on_wet_connected(player) 且接触被拖物 |
| 追逐 | STALK → CHASE → LURED | in_zone(actor, exit_zone) | 接触玩家或目标物 |
| 声音预警 | CYCLE(A/B) | cycles_ge(N) 且店务完成 | 错误相位时 door_open |
| 交易计量 | OFFER → MEASURE → SETTLE | measured 且 receipt_matches | signed 且未 measured |
| 家宅精灵 | SETTLE_IN → OBSERVE | timer_ge(T) 且 seat_reserved 且无人坐 | seated(other)、被注视或付了工钱 |
| 契约 | REQUEST → TERMS → HONOR | terms_shown 且义务完成 | breach（违约谓词） |
| 寻物归还 | DISPLACE → TRACE → RETURN | 物归真主 | 交给错人或毁坏 |
| 休息 | LURK → DREAM → WAKE | 坐下前 alarm_set | 坐下且未摆闹钟 |

### 11.2 新增条件词

在预兆提案的约30个谓词之外，店铺机制再加24个，全部是格子、枚举或计数判断，不需要物理：

- 店铺状态：store_mode(open|paused|locked)、greeting_on(front)、counter_gate_closed、power_le(n)、circuit_dark(c)、duty_active(id)、duty_done(id)。
- 人与身份：regular_trait_mismatch(actor)、verified(actor)、with_colleague(player)、named(actor)、station_of(actor)。
- 文字：note_author_on_shift(note)、note_written_before(note, t)。
- 物件：handed(item, actor)、measured(item)、weight_mismatch(item)、claim_detail_ok(actor, item)、offering_on(socket, tag)、seat_reserved(socket)、seated(actor_kind, socket)。
- 空间与节奏：crossed(line)、cycle_phase(id)、gauge_reading(id, range)、anomaly_reported(zone, type)、dream_active。

## 十二、落地顺序与试玩验证

**先做店铺骨架，再接怪。** 顺序：

1. 门三态与营业状态、电量池与借电、三回路灯闪、柜台活板门、交接垫、店务卡（6张）、客单计数。
2. 文字层：店规墙、前任笔记页、交接本与便签实体、工单印章、今夜补充守则。
3. 人：4位熟客、同事指派与口令、店长工单。
4. 预兆导演＋七态机＋十个族群模板。
5. 切片10只：预兆提案的8只（F37 F12 F05 F24 F02 F42 F06 F21），加 F07 座敷童子（好怪）和 F43 图恩达（假便签）。
6. 异常巡检、店铺加装、好怪回报，再按族群批量接其余怪。

**试玩时看这六件事：**

| 问题 | 期望 |
|---|---|
| 玩家会不会主动暂停营业，暂停后是否觉得亏 | 每夜1–2次，且能说出为什么 |
| 电在第4小时还剩多少 | 3–5格，至少一次因为没电而放弃一项准备 |
| 柜台停留比例 | 30–50%；高于60%说明店务拉力不够 |
| 第一张假便签 | 大约一半人被骗，第二张大多能识破 |
| 第一次见座敷童子 | 有人把它当威胁，结算时意识到错了 |
| 熟客特征 | 两步外能读出，冒名错项能被注意到 |
