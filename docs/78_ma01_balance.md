# MA01：塔、装备与机制窗口的配合

## 按八种既定塔行为复核

| 行为 | 新攻击带来的机会 | 保留的限制 |
|---|---|---|
| 狙击 | 冲空/撞墙、聚能、射线引导、缠绕源站定 | 真实射界与装填，Q25只择时 |
| 永久积毒 | 追逐和长仪式中累积，解机制前已有投入 | 不越死亡门槛，石击不造毒，Q33只催已有记录 |
| 广域烧伤 | 多只独立子体聚集、排队进攻时铺减益 | 尾巴、触须、假象不算多怪 |
| 小范围持续 | 收招、聚能、维持丝带增加驻留 | 真实身体须进合法区域，纸偶仅1秒 |
| 群咒 | 多攻击者减攻，提交时概率取消整招 | 每攻击一次失攻，取消不伪造I39 |
| 电器共振 | 引追逐者靠近真实电器、投石改变其路线 | 死亡/断电缩图，无全波电荷上限，石/托盘非AP |
| 连续跨区 | 实际冲刺、追逐、转角经过伤害区 | 普通dash不刷新单格冷却，空中不算地面接触 |
| 真实转场 | 已登记瞬移/影跃/镜穿沿既定公式缴区间伤 | 不新增传送，Q28/I38只准备现有格 |

## 数值定位

基础普攻以MD01为底，S07/S43等原泛用字段与特色时序的冲突由逐卡timing_resolution明确覆盖。新招用更长预告、固定几何、有限活跃和实际收招兑换更远覆盖或短控制，不同时占满高速追踪、长控、高伤、短冷却。

接触型必须公开武装，默认活跃≤3秒、冷却≥7秒。近身身体威胁会追逐，但无隐形光环或逐帧新伤。仪式默认6秒、最早16秒再起，打断后至少8秒追逐。投石花费拾取、走位和投掷时间，换取消脉冲与改变怪物行为。

缠绕最多0.6秒定身、2秒总寿命，按住0.6秒免费挣脱，释放后6秒免再缠。短跑只是额外选择，所有基础可达仍按0体力和无特定装备。

## 多怪与资源

MD01常见1–2威胁、后期有限群体和根预算继续执行。同场最多两套危险序列、一套仪式/缠绕的预约用于可读性和路线检查，不截断真实怪数或电网。独立残留区占槽但不额外冻结本体的原工作恢复节拍。

本轮不改塔、陷阱、装备价格、工资、奖励、抽奖概率、保底和周清。三枚仪式石是当夜共用、班前放置的可回收任务实物，无营业补货、购买、退款或击杀收入。

## 待实机校准

需要实测窄道对冲、搬运时投线、货架射线剪裁、转场与区域同帧、群体残留区拥挤、触控瞄石/挣脱与音画预告。有限模型不提供105个AI可玩或整周胜率结论。
