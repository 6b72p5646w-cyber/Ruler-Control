# 20条渐进店规

店规按里程碑在对应威胁出现前解锁，七天工作阶段不变。白天学习可以提前理解和扩展对策；必要的基础店规免费获得。基础岗位规程与各原型独有特征分别展示，不能把未知民俗弱点当作首次遭遇的隐藏即死条件。

| 编号 | 店规 | 执行与解除 | 解锁 |
|---|---|---|---|
| H01 | 柜台要有人，身份要确认 | 安排已核验员工守岗；无人可接替时先暂停新客入店。 解除：完成交接或店门切至安全暂停模式 | 首次上岗 |
| H02 | 下班只认本班的钟 | 店内普通钟、窗外天色与他人报时须与可信时间核对。 解除：真实时间与结算记录一致 | 首次上岗 |
| H03 | 顾客进店不等于获准进员工区 | 公共区域、仓库、柜台后各有独立权限，不随邀请自动扩大。 解除：通行范围已明确或来客退出 | 首次门禁教学 |
| H04 | 同事回来了，也要接得上这班 | 离岗返回者核对本班记录与独立行为证据，待核者先撤高风险权限。 解除：至少两类独立证据一致 | 首次人员离岗或假扮前 |
| H05 | 店长的声音不能改店规 | 经理指令须有当前工单与权限来源，不能仅按声线执行危险操作。 解除：来源与范围核验完毕 | 首次店长远程指令前 |
| H06 | 只报工号，不替别人应名 | 涉及姓名、回应与代理承诺时采用员工编号和明示流程。 解除：对话不形成未知代理或实名绑定 | 首次姓名型访客前 |
| H07 | 没写清的代价，先别答应 | 契约必须显示对象、范围、时限、代价与退出方式。 解除：条款核对后接受或明确拒绝 | 首次契约访客前 |
| H08 | 钱与货要对得上，额外代价也要对得上 | 核对付款、实物和票据，非金钱交换也需明确确认。 解除：交易账实一致或取消 | 首次交易教学 |
| H09 | 供物有自己的台，不能混进货架 | 按已核实方法分离供物、库存和个人食物。 解除：归属与用途清楚，污染隔离 | 首次供物型访客前 |
| H10 | 吃进嘴的东西，要知道从哪里来 | 只食用已验证个人补给；未知赠食先封存核验。 解除：食品来源与状态可确认 | 首次上岗与资源教学 |
| H11 | 失物不是无主商品 | 先登记归属与领取证据，不直接出售或占为己有。 解除：物品进入合规保管或完成核验交付 | 首次失物事件前 |
| H12 | 异常商品先停售 | 移动、变形或污染物先控范围，再按已学方法处置。 解除：异常停止且复检或退货完成 | 首次商品异常前 |
| H13 | 听见熟悉的话，先确认是谁在说 | 电话与广播只作为信息源；高风险动作需独立证据。 解除：信息来源经过核验 | 首次声音诱导前 |
| H14 | 看见一个影像，不等于看见事实 | 镜子、监控与自身感知都需用可控测试或实物对照。 解除：至少一个独立对照成立 | 首次影像类异常前 |
| H15 | 先留退路，再动水火门灯 | 改变环境前预览自身与同事的安全路线。 解除：目标与返回路线均可用 | 首次环境调度前 |
| H16 | 先辨来者，再选驱法 | 盐、金属、灯、食物等仅按已学适用范围使用。 解除：对象特征与方法匹配或选择保守暂缓 | 首次主动驱离前 |
| H17 | 撑不住就交岗，不要在危险工位睡着 | 低精力或恐慌时先接岗或暂停营业，再恢复资源。 解除：工位安全且资源恢复到行动门槛 | 首次资源低阈值前 |
| H18 | 宠物会提醒，不会替你作证 | 宠物提示须与其他线索核对，不能单凭叫声驱赶人员。 解除：获得独立证据或保持待核 | 首次宠物出勤前 |
| H19 | 街上来了一队客人，先确认营业方式 | 群体事件按预告切门禁与服务窗口，逐批处理并清点。 解除：群体离开且复店检查通过 | 首次大型群体事件前 |
| H20 | 交了账与钥匙，才算真正下班 | 真实六点后核对接班身份、账单与钥匙，系统确认交班。 解除：时间、身份与职责移交均通过 | 首次正式交班前 |

可信手册和已确认记录保持稳定。首周到最后一次交班时提供全部基础店规；尚未购买宠物等内容也能阅读对应备忘，不强迫购买才能解锁。
