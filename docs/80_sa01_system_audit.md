# SA01：全系统自洽审计

> 本页为SA01基线审计。后续独立复核发现的遗漏、限定修订和当前缺项见[SA02独立审计](84_sa02_independent_audit.md)；原检查结果不等同完整游戏已自洽。

审计基线：`961ccdbcdc5e8fb81b6cae534ab0317e64de4da5`。

## 1. 当前能得出的结论

**核心玩法方向可以成立，但还不能认定整款游戏已经全部自洽、平衡或接入完成。** 目前已经有营业、追逐、规则应对、塔与陷阱、装备、抽奖和七夜资产的主要合同；本轮发现并修正了若干跨版本冲突，也复现并修复了一个真实旧执行器门禁缺陷。剩下最关键的工作，是让这些规则在同一张地图、同一次连续夜班和同一套保存事务中共同运行。

便利店设备并非完全没有设计：已有营业动作、免费主机制工具、实体遮挡、固定塔挂点和真实电器节点。但设备本体、付费塔和带电节点是不同对象，不能因为名字相似就互相复制能力。本轮整理了**14类设备职责**，提出**5个未启用、待平衡的数值候选**；这不等于已经完成一套设施升级树。

以下分三类报告：

- **已修正并有证据**：数据、合同、有限参考模型，或明确指出的实际执行器修复。
- **设计已有、运行未接入**：仍需地图、世界事件、UI或保存适配，不能作为正式游戏已经具备的能力。
- **候选未定稿**：仅用于下一步试作与比较，当前不收费、不生效、不进入随机奖励或战斗计算。

各系统唯一权威与阶段权限见[system_authority_sa01.json](../content/system_authority_sa01.json)。旧V0.10练习与当前SA01设计使用各自执行配置，不能同时加载同一个物件的两份效果或两份奖励监听。

## 2. 已有机制之间能衔接的部分

当前105条目按22个“完成机制后解锁击杀”、45个“完成规则后离场”、38个“完成后削弱”组织。MD01负责生命、移动、防御与终态，MA01负责具体攻击时序；未被明确覆盖的原物、身份与操作条件继续保留。**塔压制、临时倒地和真正结束遭遇不是同一件事**，不能见血条归零就对所有怪物统一发击杀奖励。详见[怪物合同](../content/monster_contracts_md01.json)与[攻击合同](../content/attack_contracts_ma01.json)。

装备、原道具、宠物与设备辅助按来源白名单消费。同一装备不因旧目录和EQ01同时有条目就生效两次；搬运类辅助按对应覆盖规则取最强；设施的普通工作加速不能缩短主机制的真实等待、取放、封存或核验。监控信息、照明、声音和实体门帘也不能自动变成眼睛凝视、通用破隐或规则授权。来源边界见[装备合同](../content/equipment_contracts_eq01.json)、[原辅助效果](../content/auxiliary_effects_v010.json)和[设备职责](81_sa01_facilities.md)。

位移惩罚继续沿真实起终点之间的伤害分区结算；真瞬移、影跃、镜穿的计伤线不伪造中间实际驻留，也不顺带触发沿途地面陷阱。电网仍搜索真实合法连接，死亡或断电后重算；没有新增整波电荷总上限。区域、状态与电击的消费者由[TD05共享合同](../content/combat_contracts_td05.json)负责，不能由某一设施文案另造一套。

这些边界已经有明确设计来源，但还需要联合运行验证，才能证明玩家在追逐中有时间完成主机制并继续经营。

## 4. 便利店设备已经设计到哪一步

14类职责包括收银台、货架、热食台、主冰柜、饮料冷柜、身份核验台、监控、照明、迎宾与广播、门窗与遮线帘、水槽与阀门、验收分袋工位、员工补给区和抽奖机。每类的营业用途、怪谈/塔防用途以及不能附送的能力，已逐项列入[设备职责表](81_sa01_facilities.md)与[机器数据](../content/facility_roles_sa01.json)。

当前比较成熟的双用途包括：货架经营与塔挂点；冰柜冷链与同件任务物封存；门帘服务模式与真实遮挡；水阀清扫与特定水怪断路；核验工具营业授权与假扮规则应对。它们不必全部自带伤害或减益，才能成为有效策略。

五个优先数值候选分别是：**结账完成附咒、上架完成推进合格塔装填、热食完成附热、普通冷链完成附寒、核验台实际扫描给予短易感**。其中四种普通工作预约拟用1应急电、20秒窗口、同设施30秒冷却，工作耗时乘0.85并与装备同组取最强；核验扫描拟用1电和2秒实际动作。这些参数均为`proposed_pending_balance`，没有消费者接入前不产生任何收益，也不收费。

三条边界必须继续保留：

- 免费冰柜、手动门、任务原物、手压镜和必要路线不改成付费门槛；应急储备为额外优势。
- 当前真实电器仅热食台、主冰柜、饮料冷柜三台；AP_POS停用，灯、塔、导线和抽奖机不自动增加电网E数量。设备回路相同也不等于网络自动连通。
- 抽奖机的战斗价值来自实际取得的装备与道具；营业关闭，每次仍消耗1券和15准备分钟。准确机身坐标、独立操作格和界面仍待落地，机器本体不攻击、不挂塔、不成为电器节点。

独立设施升级树、价格、容量、安装、故障、维修、退款与周清合同尚未完整。门加固和保温仍禁用，不能把它们算作已经拥有的设施强化。

## 7. 建议下一步

先交付**统一地图、首版完整夜班排程、新组合白名单和第一周教学表**，连同必要的停火/目标管理与保存字段完成设计，再接入一夜、验证一夜，最后运行完整七夜。五个设施数值候选随这个阶段逐个试作，记录营业节省的真实时间、额外资源成本与战斗收益，再决定是否进入正式设施升级树。

首轮实玩应回答：玩家是否能读懂追击与预告、完成主机制并留出经营时间；塔与设备是否改变走位和目标选择；免费解法是否始终可达；失败是否能归因；暂停、后台、重试和周清是否保持同一资产事实。完成这些之后，才有证据把“主要合同相互衔接”提升为“完整游戏机制已经自洽”。
