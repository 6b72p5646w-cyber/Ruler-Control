# 全局机制、条件与趣味性复核

## 判断一个机制是否成立

条件闭环必须能回答七件事：谁产生、何时产生、属于哪个原物/人、玩家如何知道、能做什么、何时结束、结束后留下什么。若一个条件只能靠导演在抽中怪物后补写过去，或其“效果”没有任何读取者，就不算有效玩法。

当前60卡用具名状态与有限动作表达，72事件用真实来源和两种处理合同表达；组合还要复查实际路线、剩余时间、手持物、独占槽和已有承诺。完整机器输出见[验证报告](validation_v010_report.json)，逐卡流程见两份机制审计。

## 四资源如何参与而不制造无解

| 资源 | 真实变化来源 | 对操作的影响 | 保底与结束 |
| --- | --- | --- | --- |
| 精力 | 统一日夜时钟、实际白天行动、明确本怪奖励/成本 | 影响体力上限与恢复；休息和兼职产生真实机会成本 | 低精力不锁必要搬放、开门与撤离；不另加未定义睡眠债 |
| SAN | 有来源的恐惧、实际攻击、错误动作、消费品与完成奖励 | 公开缩QTE目标、压暗周边；不隐藏概率判错 | SAN0启动一次20世界秒恐慌，8秒步行安定允许中断保留进度；不要求先走回远处固定点 |
| 饱腹 | 实际吃下同一已核验个人食品、统一24小时时钟 | 低饱腹影响体力恢复；食品库存与已获得饱腹分开 | 任务肉、供物、保留瓶不可吃；商店/岗位保底餐有明确来源 |
| 体力 | 实际冲刺、明确可选较力等动作和世界时间恢复 | 帮助节约路线和抢窗口 | 0体力仍可步行、关键取放、基本开合；不让逃生道具先要求跑到满体力 |

暂停阅读同时冻结世界和班次，不恢复资源、不产生新证据。精度特写冻结世界但支付一次明确班次预算，只有安全准入后才能开始；活动追逐与百鬼夜行不启动新的暂停精度题。

## 时钟与截止

每小时120预算秒，整夜720。移动和世界内操作同时推进世界与预算；精度特写只花承诺的预算成本。订单耐心、流血、血迹、局部水状态和物件保留寿命读世界钟；相位与06:00读预算钟。

一个主遭遇的120秒截止从该阶段起点算，不能每次重新打开窗口重置；允许跨阶段的活动威胁也最多到原阶段起点+240，再取真正06:00的更早者。历史任务债最多一项、只跨下一阶段；过期痕迹、已被取走物件和失效权限不能继续当联动来源。

同一时刻先提交已经合法完成的动作，再处理到期和危险，再判断交班。晚0.01秒与恰好同刻不同。F53在720冻结资格，之前准备完的原地交付才能提交；不允许720后走去寻找店长，未来SAN奖励也不提前救恐慌。

## 实际血源、踪迹和消退

E003的实际玻璃接触，或F21明确激活的40秒后玻璃故障接触，才产生割伤。没有实际接触就没有流血；普通怪物SAN伤害不会自动附赠伤口。

流血持续90世界秒。实际移动每2格产生一份血迹，血迹30世界秒消失；原地不动不生成连续血路。2份常备敷料是有限真实物资，完成包扎停止新的痕迹，旧痕迹仍由擦除或自身到期结束。F26必须读取仍在的实际痕迹，不得在旧血消失后强迫新伤，也不因包扎把已存在的血迹瞬间清空。

## 物件、槽位与奖励

货箱、生肉、回形针盒、留水瓶、赠食、失物、合同和设备都保留实例身份。取走、放下、封存、归还和售出是转移，不能以一条“已处理”标记同时复制库存与收益。

接受合同先预留真实物件、有限槽和未来窗口，再交付收益。F53使用一个保留容器装同两瓶，一个售卖容器装其余同四瓶；F36租位另占第三槽，不能挪用保留瓶。礼物与怪物离场分离，背包满可以稍后领取同一件，不让已解决威胁无限活着。

F25退款认原购买回执；E066回收按实际付款与参考价较低者的20%报价，转交原物后不能再退款。E040同一I21报价42币，回收不会高于购价。E071本金20、应付25，最多三份在途、每绝对夜号最多一份，未来真实基础工资80足以覆盖最多75的预先约定抵扣；没有利滚利或凭改尝试号重复借款。

奖励必须有具体消费者。F07完成45秒空椅保护并收牌后SAN+2；F52实际6秒安全短休精力+2、当夜一次；F57可选限时送货SAN+4。三者都不是虚构的“以后更轻松”令牌。旧卡多余成本/收益归档，不能与当前动作重复结算。

## 20条店规的生产者与解除点

20条规则继续免费逐步教学，在第一项适用危险之前出现，不要求玩家先死一次或购买学习。学习提高方法理解与可选效率，不购买基础生存许可。

| 规则 | 可发生的条件 | 玩家操作与可检验结束 |
| --- | --- | --- |
| H01 柜台要有人，身份要确认 | 当前柜台无人且开放入店 | 已核验员工真实接岗，或切窗口暂停新入店；原客仍需处理 |
| H02 下班只认本班的钟 | 屏幕、声音或来客声称提前天亮 | 查本班不可被怪物改写的班次钟；720前不结算交班 |
| H03 进店不等于获准进员工区 | 公共区实体请求跨员工门槛 | 明确有限授权/保持门槛；撤权不让实体或实钥匙瞬移 |
| H04 同事回来了也要接得上本班 | 实际离岗、断视或出现第二同脸实体 | 对当前身体核验；局部连续见证失效后限权，旧单据只证明历史 |
| H05 店长声音不能改店规 | 电话或门外声音索取权限 | 用原核验流程验证当前到场者；声音不取消既有规则 |
| H06 只报工号，不替人应名 | 真实姓名型呼叫 | 保持不应名并完成安全交涉/撤离；宠物提示也不替人应答 |
| H07 代价不清先不答应 | 当前有实物/权限/未来时间要求的提案 | 看清固定条款、预留后接受，或未承诺时退回原提案 |
| H08 钱、货、额外代价对账 | 同一订单处于实际交易 | 同物件与原回执匹配；不能用点击“记账”生成钱或另一件商品 |
| H09 供物使用独立台 | 供物任务有真实库存和指定槽 | 搬入供物槽，不能并入可售/个人食品；完成或安全撤回同一份 |
| H10 食物有来源才能吃 | 持有一件可食候选 | 查同物批次/封装后实际吃；任务肉、材料水和保留品不因核验变可食 |
| H11 失物不是无主商品 | 有原登记失物与申领者 | 对照具体细节交回原物，错误归还按实际窗口追回或登记丢失 |
| H12 异常商品先停售 | 真实货架异常或错上架 | 封停该格、取回同件核验，正确槽恢复后结束局部影响 |
| H13 熟悉的话不证明说话者 | 真实声源可重复但身体未确认 | 观察当前来源与有限授权，不能用同源重放凑第二证据 |
| H14 影像不等于事实 | 镜面/照片/监控提供线索 | 与当前实物或独立记录核对；快照有时间与视域范围 |
| H15 先留退路再动水火门灯 | 玩家准备改变已有环境控制 | 先算当前门与实际水图可达路径，再切开关；保底冰柜/手动门不被随机断掉 |
| H16 先辨来者再选驱法 | 观察到可辨识异常且免费基础方法已提供 | 对应实际机制采取操作；保守等待/拒绝只在该怪明确允许时有效 |
| H17 撑不住先交岗 | 低资源且拟在工位休息 | 先实际接岗或暂停入店清空当前工作，再完成有限休息 |
| H18 宠物提醒不作身份凭证 | 宠物有真实目标读点与剩余次数 | 反馈具体现象或辅助动作；玩家仍完成核验和原物操作 |
| H19 群体来临先定营业方式 | 已预约的大型群体事件真正进场 | 同阶段只执行对应世界动作；有限过门窗口或安全暂停营业 |
| H20 交账与钥匙才下班 | 真实720、当前店长、原账与原钥匙均满足 | 提交已准备好的交付，再领取同战役/夜号唯一工资与履约收益 |

## 不让安全解吞掉乐趣

安全解保留，但不承诺相同收入和效果。F57干路花时间较少，限时维护换一次额外SAN；F07保护椅位会影响同一浏览客的座位安排；F38保持短观察链换回同事的有限工作能力，转身处理远端工作则可能失去这次委派；F59只在真实设备损坏时用材料和不注视时间换回其原有可选功能。

F12的引诱与F13的追肉依旧要求实际操作，不能靠关店或拒绝对话解除。SCP扩展也须沿用这一原则：原型负责改变工作方式，玩家通过看得见的物件、位置与时机完成处理。

## 编程复杂度与剩余验收

优先实现有限状态机、原子槽转移、少量倒计时、已有网格路径、有限范围朝向/遮线、原订单和奖励回执。风、水、气味只用明确触发区和状态边，不做连续物理仿真。辅助防御延迟、提醒、遮线或替代一次耗材，但不产生通用射击与伤害血条。

本轮通过有限流程检查仍不能回答手机是否操作舒服、初见玩家能否读懂、六波是否紧凑和一周经济是否有趣。这些需要实现后的实机与玩家测试。已发现的来源/逻辑矛盾在合同内修正或归档，尚未实现的适配器不会因为文档检查通过而自动开放投放。
