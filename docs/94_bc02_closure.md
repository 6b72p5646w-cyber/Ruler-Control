# BC02：整场支援、条件来源与Codex落地

本轮继续检查后，确认上一版还有会影响游玩的前提缺口。最明显的是设备开战后8–12秒太短；其次是环境标签没有完整生产链、部分步骤窗口互相矛盾、历史订单与当前行为混用，以及终态产物被误写成入场条件。本轮先修这些规则、补实际有限反例，再编排可直接交给Codex的实现任务。

**当前唯一拟实现入口为[BC02权威表](../content/system_authority_bc02.json)。**它限定覆盖同一字段，保留BC01、MD01、MA01、TD05、EQ01和SA02未被修改的规则。当前运行网页仍是旧两怪练习；正式BC02客户端将在[落地计划](98_bc02_codex_delivery_plan.md)中逐批实现和验收。

## 1. 设备成果能保留到怪物来，也能覆盖整场战斗

BC01已有“顾客真实使用并付款后，先储备、实际开战才启用”的机制；因此营业等待不会消耗原token。问题在于启用后的8–12秒不足以承担一场几十秒至数分钟的战斗。BC02将生命周期改为实际本场结束。

| 支援 | BC02有效方式 | 有限预算与例外 |
|---|---|---|
| 防护、移速、交互效率、搬运、软减速抗性 | 本场全程有效 | 同组取强，不相乘刷高；依设备电路即时停用/恢复 |
| 冷柜怪物缓速、广播普通塔装填 | 本场全程，仍需真实距离/遮挡/合法消费者 | 不把装填增益套在所有DoT、弹匣或状态时间上 |
| 热食回血 | 每有效秒恢复最多0.2%最大HP | 每场该来源实际恢复上限20%最大HP；满血不扣额度、停电不补发 |
| 幸运小票回血 | 同速率，原随机结果在顾客使用时固定 | 该来源最多10%；与热食顺序共享速率而非叠成0.4%/秒，合计最多30% |
| 自动临时陷阱 | 成功落地后保留到一次触发、实际被毁或场末 | 一次充能、同时1个、每场最多2次、间隔6秒，仍占真实8件/16格容量 |
| 存活奖励 | 真正存活的RAID时间计酬 | 先有真实付款离店提供额度，每15秒1币1XP，每夜最多12次，720秒后不再计酬 |
| 公共饮用的体力恢复 | 启用一次恢复最大体力10% | 同源本场只用一份，另一份留下一场，不制造免费个人饮料 |

每个可奖励来源存2份，12个来源最多24份独立储备，收银和离店不会挤掉其它设备。持续/恢复来源一场最多启用一份；第二份留本夜下场。待战无计时衰减，跨夜清掉未用储备并在结算明示，没有暗中兑换金币或永久资源。

开战时断电的来源先预约原token，本场首次来电才消费；全程未通电留本夜下场。已经启用后停电则立即失效，来电只恢复同一来源和未耗预算。怪物MAIN断电仍禁止电器buff、所有过载、新电荷和反馈；独立任务灯/手摇主解不供战斗电网。

详见[设备完整合同与实际回血ack](95_bc02_facility_duration.md)。

## 2. 每台能奖励的设施都有真实顾客使用链

除原有商品、付款、离店外，新增公共核验、叫号回复、就地饮用/空瓶派生、自提包裹、公共供给面、小票扫描的路线规格与有限执行器。12个路线profile覆盖全部12个可奖励来源；FR07监控和FR08照明保留真实控制与信息作用，不虚构顾客使用奖励。

核验台旧员工操作面虽然导航可到，也不等于可以给顾客用。本轮用独立北侧公共面`[25.5,24.5]`，旧员工位保留员工权限。

空瓶回收的前提尤其需要补全：同笔原饮料真实喝完2秒，产生同材质、唯一派生ID的空瓶，再实际走去归还。FR05＋FR11只有两种奖励服务，途中普通饮用不冒领FR13；走公共饮用台的FR05＋FR13另有路线。包裹为班前真实雇主库存与袋子预包装，付款后核验再取同件包裹，FR06＋FR12也恰好两种服务。

已付但尚未领取的顾客遇到预兆时先安全撤离，原货在customer-owned槽保留领取权。不能凭顾客离开就补发未完成领取或FR10；同夜回来只补原单缺失服务，不新建付款。跨夜只免费履约，不凭旧付款发新夜buff或新订单奖。原领取权不是已交付历史，不能供F19/F25偷过前置门。

详见[顾客路线、物件与中断处理](101_bc02_customer_routes.md)。完整随机导演还需接这份执行器；本轮有限路线通过不替代真实客户端NPC调度。

## 3. 水渍、镜面、影子、血迹都由真实来源生成

本轮把23类条件和生产者目录登记成来源→真实对象/地格→消费→撤销的链，并为105条遭遇列出实际消费者。其中51条需要额外环境条件；目录含26个有效来源定义及1个明确撤回、不能生产条件的历史候选。

### 水不再是一句wet_connected

| 来源 | 实际生成门 | 有限性与反制 |
|---|---|---|
| 雨水 | 夜初独立20%雨夜；第20秒提示，3秒后正门开才入水 | 第140秒停雨；关门/实际吸水设施阻止新水 |
| 冷柜漏水 | 第三次真实冷柜服务后独立10%接头事件 | 真实源、3秒预警、修复停源，同episode不复造 |
| 顾客洒杯 | 真实饮料服务且原杯沿路径到实际地格后10% | 原杯液量最多6格，一次灌完即停；不持续供水180秒 |
| 员工洒杯 | 实际员工饮水完成后5% | 有限4格，来自同一杯，不能为已抽怪补写 |
| 后渠 | 班前巡检者真实开独立主阀 | 可真实切流，和冷区水阀分域 |
| 指定任务浅盘/滴水管 | 已预约原载荷实际到货、搬运、安装完成 | 公开源与割点；未部署完成就不入场，不能直接写true |

水只沿已注册合法四邻地格传播，每秒一条边。180秒指停源后残水寿命。擦割点即时断边，脱源水两秒排干，同一次水源事件不会自动长回切口。普通清洁只在安全期给一次源事件奖，水自然干燥不会发工资；战斗中的本根切路是战术反制，不强迫玩家清普通地板。

F05水路移动按真实路径和速度计时，不等同瞬移。途中断路时停在实际已到的位置，按原显形/收招恢复，不瞬回、不另选落点。水的存在也不自动增加电网AP、赋予镜穿或跳过地层限制。

### 当前105条没有正式镜穿消费者

`registered_mirror_node`原来只是预留接口。F60使用镜面观察、S23使用反射射线、S25使用反光板补光；这些都不授予镜面穿越。当前登记的真实镜穿物种数量是0，不能因为名字里有“镜”就默认会瞬移。

候选镜穿接口已定义：两个不同原物分别实际搬运安装、同根同层、反射率至少0.65、未遮盖未破损、两端有合法落点，并且物种有明示能力。现有物种最后一门全部不成立。固定凸镜来自原地图ATT02，普通水膜和玻璃只按光学用途处理，不能偷偷升级成传送口。

### 光、影、血、声、视线要查当前世界

S22的暗节点要计算真实MAIN常照与任务灯总照度，不能关三盏任务灯就假定世界全黑。F60的帘子只能遮实际穿过帘子的视线；怪物绕到同侧、灯灭、低柜台或高货架都要重新算。声音沿实际门/路径传播，字幕是表现，不是另一个声源。

真实伤口仍90秒、每走2格留下30秒活迹；包扎停新迹但不抹旧迹。F13尸血只为清洁，普通HP受击也不凭空产伤口。F21结束后到默认下一场至少`35＋60＋20＝115秒`，超过伤口寿命，所以不能当作下一场血怪的默认有效来源。F26/F32改为读取当前营业段真实玻璃接触等合法来源，按预兆、实际路程、动作、恢复和离场动态预算；24秒反制示例至少要剩53秒，F26还要到场时同事故血迹仍活。

必要任务灯原900秒能量也补了加时恢复：玩家真实到同模块安全控制端手摇2秒，给原任务灯组60秒能量，不供MAIN或buff。只在满足原物、位置、旧攻击结束等条件时有同能量周期一次3秒操作保护；取消不刷新，世界/毒/旧任务期限继续，过期任务进入原失败或撤销流程。没有用更大的固定时长掩盖无限加时的前提缺口。

详见[环境来源与反例](96_bc02_environment_sources.md)。

## 4. 105条前置不能只靠一组真假标签

本轮逐条补齐105条、406个主步骤的来源、原物、免费工具、模块、实际动作依赖、任务NPC、错误恢复和终态规格。重点修订包括：

- **入场前提与后续产物分开。**F13不先要尸血，F03不先要呼气，F30的水由实际误用才产生，S25无影圈由玩家之后转板形成。需要先存在的是能力处理器或源装置，不是提前完成主解。
- **历史与本次行为分开。**F19/F25必须有真实销售及交付；F16首偷、S26咬痕等要在实际到场后真实发生，不能由抽选补写历史。
- **身份步骤按阶段拆开。**F38对当前A的双证必须在B到场前完成，放在预兆前置阶段；B真正走到后才提交异常根，后续当前身体连续性仍按原8秒。
- **短窗口算实际动作和路径。**F03原1.85秒已含搬运路程，不能再叠算；F34环境休拍6秒和攻击收招2.5秒分开；F39迁牌按真实3秒；F42一轮转运7.25秒；F46退1格至少1/3秒；F17沿真实退步和领取保护。
- **原物到期不等于销毁主解。**S30的8秒只结束危险活性，同ID残丝还能收；F58没有热食仍可挂牌0.5秒、实走3格、退出提交0.5秒封区离场，不靠凭空续热的备用包；S27/S32现存子体实际返池/返舱，已死编号用真实回执闭合；S45真实回盘放械后才能收，不从远处删除手中武器。
- **普通交班简化与怪物原物资格分开。**F53原双瓶封签用于战斗，夜结用持久原物快照履约，普通玩家不用在700–720秒搬账本钥匙、追店长凭证。
- **模块和免费伤害是真前提。**每夜最多一个实际大型模块，班前装配冻结，导演只从已装清单选；不能把所有笼/车道塞进同一门店。机制解锁后的必要敌池还必须能被真实免费T02合法命中，不能只写“有塔”就当可击败。

普通顾客、任务同事/帮手、异常交易者和冒名者有不同身份。普通顾客真实撤离后才进入RAID；任务NPC只有按该条保护区域/响应规则留场，不能刷普通顾客支援。战斗中真正需要擦水、封血或收原物的动作属于该根反制，普通补货、卡车和清洁期限仍暂停。

详见[105条逐项审计与所有源链接](97_bc02_encounter_prerequisites.md)及[玩家共用前提](../content/player_loop_bc02.json)。

## 5. 广告位置已进入正式合同

暂停页预留标注清楚的广告卡片/横幅和可配置插屏接口，继续按钮独立；成功夜结可主动看广告再得一份本局金币；安全抽奖页可主动看广告获得一张额外普通券。正常收益先结算，关闭或无填充正常继续。第7夜旧周金币立即周清，不展示没有实际消费价值的金币翻倍入口，保留跨周有用的额外券。

暂停持有者、独立广告墙钟、稳定offer/nonce、完整观看、提前关、取消/迟到回调、一次性领取、跨夜/周归属和存档中断都写成接口。广告不重抽FR14、不延长存活计酬、不让等待广告恢复HP，也不把未结束怪物算作成功一局。平台SDK与账户奖账在落地计划最后接，当前没有真实投放。

## 6. 现在可以交给Codex什么

落地计划有22项带依赖、目标文件、实际交付和验收的任务。先做独立客户端和共用世界，再串顾客/环境/四怪的一整夜；然后完成首发11主动＋1被动、七夜成长存档、抽奖和广告模拟；余下93项按九个真实能力批次实现，最后扩完整塔陷阱装备与真实广告。

[100_bc02_codex_start.md](100_bc02_codex_start.md)可以直接作为起始任务。它要求交付可玩的M1完整一夜，不停在脚手架或自动演算；每项完成后继续依赖链，并保留实际录像、轨迹与实现开关证据。本轮未启动独立的外部Codex云任务，也没有生成微信发行客户端。
