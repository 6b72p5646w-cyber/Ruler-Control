# MA01：攻击判定、时序与控制

## 十二种攻击行为

| 类型 | 真正危险的位置 | 玩家应对 | 塔的机会 |
|---|---|---|---|
| 近袭 | 原朝向扇区/短线 | 起手后侧移、转角 | 落空收招 |
| 危险体表 | 发亮后有限时间内的真实身体 | 拉开、等熄灭，避免贴身穿过 | 远程、减速压住身体 |
| 冲刺 | 锁定直线路径的连续扫掠 | 横移，引向合法障碍 | 撞墙/冲空后的停顿 |
| 跳跃/俯冲 | 原卡真实高度和落点 | 离开落点，按高度配对空 | 落地与回升间隙 |
| 投射物 | 实际飞行路径 | 躲到遮挡后、走出弹道 | 发射停顿 |
| 固定射线 | 公开射轴与宽度，遇墙截断 | 侧移或遮线 | 施术者站定 |
| 扫射线 | 提前显示的扇弧及方向 | 顺序走位、绕背、遮挡 | 固定转轴的持续窗口 |
| 丝带缠绕 | 真实带头命中后的短控制 | 躲开带头，命中后按住挣脱 | 维持缠绕时源站定 |
| 仪式 | 本地仪式区，聚能结束才伤害 | 投石、合法控制或离区 | 聚能与打断后引怪 |
| 范围脉冲 | 已标示范围/有限残留区 | 提交前离开，保留出口 | 长前摇与区域外射击 |
| 凝视 | 原朝向、视线与连续观察条件 | 按本怪规则转身/遮挡 | 原机制开放的攻击面 |
| 连段 | 整套已公开子段 | 完整躲完，不在第一段后误入 | 整套收招 |

## 时间线

攻击冷却从原起手算，但下一次起手必须晚于实际本体动作结束＋收招，也要等控制与同族冷却。延长预告不会积攒多次攻击。

独立弹体/地面残留区可在发射动作结束后继续存在，本体按原收招恢复追逐；若全场另一危险槽空闲，也可重新普攻。残留仍保留原攻击ID并占危险槽，完整闪避要等它结束。需要本体持续维持的射线、丝带不能这样脱离。

I37给当前公开且未提交攻击增加1秒；同次攻击只接受一次I37，与I21等总共最多延长3秒。提交、活跃与恢复实际顺延，已射出的弹体不可回到枪口。

诅咒在提交第一伤害/弹体前抽一次失攻；全套子段共享结果。失攻后正常收招，不能立即补普攻。减攻在提交点快照，后加咒层不改已发攻击。

## 连续碰撞

高速冲刺和弹体须扫过帧间实际路径，玩家也会动，采用相对运动扫掠。不能两帧之间穿过人物却漏算，也不能隔着先碰到的墙伤到后方人物。宽度为完整宽度，人物半径0.25格；边缘接触算碰撞。

普通冲刺以真实连续位移经过地面，按实际格计塔区伤。真瞬移、影跃、镜穿仍按真实起终点之间有效格数乘单格伤害并刷新期限。空中跳跃不把整条路径当踩过地面陷阱。

新地面圆形危险区半径最低1.5格；射线和丝带窄宽度是另一种可读几何。塔排除货架占位并补足有效面积的旧规则不变。

## 控制与终态

冻结取消未提交攻击并锁位置、朝向和高度。已经启动的冲刺/俯冲在真实位置停止，后续具身伤害关闭；危险体表默认熄灭。普通定身仅限位，站桩施法可继续；需要平移的冲刺不再扫出新的路径伤。

已发独立弹体/残留区在非终态冻结后继续原有限寿命；持续施术的束与带被合法打断则结束。主规则真正离场或根全部终结后，显式消散该根异常派生伤害体积。真实石头、原物不会被复制或吞掉。

机制锁血到1、压制重构、死亡清算、永久毒分配、电伤实际扣血反馈沿MD01/TD05。新攻击不改变结局，也不让普通受击产生原来没有的流血血迹。

## 真正的闪避

I39等效果必须等全部弹体、连段、危险区结束后判断：攻击实际针对玩家，所有段都因玩家位置躲开，且全程零几何碰撞。受击保护挡伤、咒失手、控制取消、无效目标、背向凝视不能伪造走位闪避。之后仍检查EQ01的目标合法、可见、距离与道具时限。

## 多怪组合

初版同场最多两套危险攻击序列同时占用预告/活跃期，仪式或缠绕最多一套，其他真实怪仍追逐。实际缠绕发生后不再新准入第二危险招；这不是电击目标上限。

完整组合必须存在零体力解法，包括持续区、后续连段、人物半径与手数。两招各自能躲不等于同时能躲。原停食、服务、主机制工作窗优先；纸偶1秒不能当3秒无敌工时。

可达保证约束首次强制机制和导演新增组合。玩家自行进死角、错过完整预告或继续工作不躲，仍会被合法普通攻击命中；已经公开的攻击不会因为玩家后来走错而自动撤销。避免把公平准入变成躲在死角就令怪物无法攻击的漏洞。
