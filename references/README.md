# 来源目录与核验限制

本版登记 **57 条民俗资料与 2 条影视官方资料**。它们支持具体原型特征及参考作品识别；不为本作原创交互、资源数值或怪物组合提供史实背书。访问日期记录在 JSON 中。

## 怎样阅读来源

- 优先使用典籍、博物馆、国家文化机构、学术研究和有作者的民俗资料。来源质量不完全相同，弱来源及地方版本在条目里标明。
- 原型可能有多个矛盾版本。本版选定一个适合设计的版本，不能把某版本扩大成所有地区共有的禁忌。
- 特征摘要不等于已经获得现代影视形象、美术、译文或文章全文的使用权。本仓库不打包这些素材，只提供短摘要和出处。
- 对 Viu 的参考只来自所列官方介绍，未声明看完剧集；用户提到的中文译名仍需要具体链接才能完全确认。
- 驱离方法、道具效果和资源恢复统一标作游戏设计；只有“资料支持的特征”一栏用于描述民俗来源。
